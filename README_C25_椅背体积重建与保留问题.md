# C25：椅背体积重建，仍未验收

本轮从实际C23完整场景重建椅背与左侧体积。最终保留版本为v2b：弯曲薄壳、凸曲侧带、薄上沿及向窄支柱的过渡。它已有可见形体变化；不能据此宣布原型还原成功。C23也仍是条件性、未验收基线。

## 看图结果

- C23的左端是薄板的平面封口。v1把侧部做成立体，但椭圆扫掠的上端仍像圆帽支柱。
- v2改用凸曲带状体，随后v2b补齐上部背板与薄卷边之间的实际缺口，并清除体素连接产生的微小碎片。
- v2b不再有v1的圆帽端头，侧部与下方窄支柱的层次更明确；源图柔和的卷曲高光、准确上唇和连续收口仍未完全恢复。材质及光照没有改动，不把明暗差全部归因于几何。
- H/G/665均使用同一完整模型、原固定相机实际渲染，没有逐视角隐藏、warp、遮罩或额外图像配准。650/658/1103只作形态观察，不声称新相机已经匹配。

## 几何和完整场景检查

最终只改背板与左支柱/侧带两个网格。其他345个网格、35台相机及全部物体变换、材质、集合和可见性保持不变。白模与材质模型的385个物体、35台相机几何/变换/可见性一致；白模仅替换材质。

两个改动网格各为单连通、闭合、定向一致实体，体积为正；无退化三角形，数值BVH与三角形复核未检出非邻接自交。678组背板/侧带对非椅体物件的检查未发现新增房间或沙发碰撞。两支柱与椅座、背板存在连接重叠。这是数值检查和分离实体的接触重叠，不是焊接、制造强度或精确有理数无交叉认证。

v0真实自交失败、v1端头形体不足、v2初版缺口及23个微小体素碎片均保留。v2b删除192个碎片顶点并去除2个退化单元，没有用平滑修改主侧带来掩盖问题。
