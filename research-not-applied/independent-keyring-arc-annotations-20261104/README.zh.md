# 独立源像素曲线标注：条件诊断候选

本包只读取报道源图17/20/21及既有二维评审，并在原始1192×671栅格中人工挑选少量可见段点。没有读取/拟合三维模型，没有执行Blender、相机优化或浏览器操作，没有修改R06或其他模型文件。R06的冻结由主任务负责，本包不自称完成模型冻结。

## 文件与复核
- `manual-points.json`：每图源路径、SHA256、尺寸、每条边选择、人工整数像素坐标、主观误差半径、不可辨部位null及原因。每张核对图编号从1独立计数。
- `source-{17,20,21}.webp`：字节不变的源图副本。
- `check-{17,20,21}.png`：原尺寸原像素背景，仅叠加黄色小圆点和编号。未连线、拟合、补全、抠图或锐化；标记本身遮住少量像素，须与原图副本对照。
- 标注先看原图和放大裁片，后实看编号图复核，调整17的数个上缘点。没有自动阈值、边缘检测或模型预测点冒充独立地标。

## 类别严格拆开
17：蓝白点光带左右两段只取同一屏幕上缘，中央人物遮挡处不跨接。粉色可见长曲线归为中央内凹纹的细描边，不凭颜色归作外粉环。中央纹描边与其下方宽亮填充边分离。中央尖被人物挡，其他尖不可靠，均不猜。
20：只取蓝白远侧细带的两个短段，每段3点。低角、字幕、发裙、琴凳及琴腿使其弱于21；琴下较低的白曲线/内部高光不混入。外粉环、四尖纹可靠对应均null。
21：蓝白带选包住中心纹的最内一条点光带屏幕上缘，不选后方另一条较暗蓝光带。外粉环另列其屏幕上缘。四尖纹只选左凹分支的细描边，非下方实色填充边；上尖、左尖仅为可见收束区域，各给7像素主观容差，不声称数学尖点。右/下尖被琴遮或画幅裁去，保持null。悬吊演员完全未作为地面尺度锚点。

“上缘”是图像中的上侧可见亮带包络，不等价于已确认物理台面的上表面或某半径。单一带内的闪点位置不可作为跨帧同一LED对应。这里的3–7px仅为标注者对局部模糊/选边的主观容差，不是统计sigma，也不包括报道转码、时间不同、台面内容变化等系统不确定性。

## 是否足以继续
首选17与21：可较稳定观察到同类蓝白点光带的上侧包络，以及中央内凹纹细描边的部分分支。但跨图是否同一物理带、相同台阶/高度、相同舞台状态尚未确定，因此JSON的跨图身份均为null，没有强造共同点对应。21外粉环清晰，17未找到可独立确认的同一外粉环，不能用17前景粉色中央纹强配21外环。20只适合作弱辅助可见性检查。

**足够做固定假说下的条件可见性诊断；不足以建立已校准相机或唯一尺寸。** 若随后明确固定“某模型带对应某图边”的假说，可查看可见段是否大体落在候选边附近、遮挡是否相容；任何残差只检验该假说，不能自动确认身份，更不能通过调参把错误层级拟合成成功。不得由单椭圆推唯一物理半径/高度，不得把中心纹当精确理想四尖曲线逼相机收敛。

本包是已经看过源图、已受前置评审提示的条件训练候选，并非盲测、统计检验集或独立留出验证。图像是1192×671报道栅格，拍摄原生分辨率、镜头参数与具体时刻未知。T键、背景媒体、模型暗缝均未充当实体锚点。无推测隐藏点，无圆台事实断言。
