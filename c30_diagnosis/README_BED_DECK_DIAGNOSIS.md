# C30只读定位：床面组件高度

## 推荐对象与证据
首选“Bed • mattress and sheet”，检查其与“Bed • integrated side rail”及“.001”、“Bed • continuous base tray”的连接关系。不要首先挪床头板“Bed • observed endboard, consistent width”。
C28实际床垫mesh顶点/世界矩阵与C23快照逐项一致，hide_render=false；不是被隐藏。实际顶点导出：c28_actual_bed_objects.json。
当前床垫世界顶z=0.543773，远侧y=-1.966567；模型坐标未标定，不当作实测米。
G和N642原生前景有显著浅色床面，C28同区域露出地板/沙发，床垫面明显不足。原生两视角边线能给当前固定相机下的同类约束。像素证据为可见远侧床面轮廓，不是百叶影线、人物衣服或床头槽孔。

## 纠正后的原生对应点
- G: (1200,1057),(1400,1011),(1580,970)。末端到床头交界附近的细节不用作额外拟合点。
- N642: (1200,1024),(1500,959),(1750,902)。这些点均在人像右侧，床面轮廓无遮挡；阴影颜色会改变梯度方向。
- 像素不确定性约2–4px；H不参与本次定位/条件控制范围选择，留作检验。
- 原生1:1裁片及红点：G_bed_edge_source_native.png、N642_bed_edge_source_native.png；对应C28裁片也已保存。
- 此前消息的N粗标点偏上，已由此组替换，不能再用粗标点。

## 单自由度假设为何值得试
用现有相机投影反求各源点射线，仅与当前模型固定远侧y=-1.966567相交：
G三点得到z=0.669326,0.669750,0.669937。
N642三点得到z=0.685390,0.685160,0.687146。
每帧内高度近似一致，支持“同一条近水平床面远侧边”的辨识；两帧共同指向床面相对现模型偏低。两帧之间约0.016模型单位差异仍存在，必须保留相机/跨时刻家具状态的不确定性，不可强行融合。
这不是三角测量或尺度恢复。换动固定y或相机，z解释会随之变；不能把这些数值对外称真实床高。

## 保守候选范围
仅建立一个床面组件高度控制，先以当前z顶增加约0.10…0.16模型单位作诊断候选，保持X/Y外边界、床头板、相机和其他家具不变。这个范围包含上述条件射线解释，但不是批准某个精确高度。
床垫、两侧栏及托盘的可见连接要一致；不得仅抬床垫留悬空缝，也不得为填缝随意加厚床垫。支撑连接、床头板与床面关系需要随候选检查，若不能保守保持则先报告阻碍，不直接扩展到整床重建。
分别检查G与N642整条边的残差，不只看三个点，不以改变相机或其他物体补偿。若两帧变化方向不一致、床头遮挡回归或出现穿插则拒绝。

## 未拟合检验视角
H完整原生及固定现有H相机为预留检验：右下角有窄条浅色床面，可检查候选是否恢复该可见范围，且不额外遮挡沙发/椅子。不从H提拟合点或调参数。若H不通过，应报告而非再用H细调。665可另作后续冻结检验，但不与当前帘布检验混淆。

## 边界与缺失
两视图原生均清晰，但C26明确不允许把床/人物跨时间关系当静态建筑标定。故这只支持条件可见形体候选，不是严格跨时刻刚性成立证明。绝对床高、床宽、完整支撑结构未知。当前诊断未修改任何blend或相机。
帘轨暂缓：G有可见端部误差，但H/N/665轨顶画外；1801/1804没有现成可靠相机，不能拿来直接定轨道尺寸。
bed_snapshot_projection.json是早期未裁剪投影调试结果，包含相机后方点，投影bbox不能作可见屏幕尺寸/轮廓指标。最终只使用实际渲染、以上源点及corrected_bed_edge_observations.json的条件射线解释。
