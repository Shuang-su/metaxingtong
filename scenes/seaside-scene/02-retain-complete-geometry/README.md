一、范围
独立、有限范围、可编辑的海滨公路与步道场景。不是封闭房间，没有新建墙、顶棚、亭子，也没有与厨房、舞房、卧室拼接。道路、步道、路缘、岸墩、链条、灯具、棕榈、地被、坡地和起伏海面均为三维几何。
保留旧版前景布局与原创PBR材质；重点修复从背面、底面和近距离绕看才能发现的结构问题。模型单位已改为无量纲相对单位；7.2道路宽等旧数字是工作假设，不能解释成实测米制。

二、真实改动
- 道路、步道、路缘补侧壁、底面和端部；拆除旧重复竖直路缘贴面。
- 岸坡与陆坡补有限侧边及底面；新增有限路基支撑。原始路段与陆坡长度不同，未假装获知远处地形，远端仍明确展示有限截断范围。
- 1184个链环重新生成周期闭合截面，修复旧端环错向接缝；保持链条原布局；9个末端环朝岸墩平移0.005消除微缝，不把缺口用黑色材质掩盖。链环为静态互扣并允许微小表面相交，不是力学可运动链。
- 棕榈树干、叶轴和弯灯杆封管端；叶片、草叶和海面是合理双面薄面，不强行做厚板。
- 棕榈整体按真实模型地形射线接触修正；保持树干、叶轴与叶片为同一组移动。
- 灯具发光片合并重合点并清除退化面；检查外轮廓与灯罩关系，不只检查中心。
- 标线有微小实体厚度；路基与岸坡底面错层避免共面闪烁；新增侧面UV按正确方向展开。
- 所有普通相机使用同一套几何与相同可见集合；没有按相机移动、缩放或隐藏对象。

推断补全：路面及步道厚度、完整端面、地下路基、地形底面、被遮挡的背面、确切链环截面、植物细节及远处延伸。未见结构不能因闭合检查通过而变成来源事实。
