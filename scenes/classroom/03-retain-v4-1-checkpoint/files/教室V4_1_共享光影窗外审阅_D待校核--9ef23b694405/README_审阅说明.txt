教室 V4.1：共享光影与窗外审阅检查点

这次保存的是可继续修改的审阅模型，不是结构完成稿。
D角度桌面数量仍未对齐：来源至少14，当前12。

本次更新
1. 保留V4的共享教室、讲台、讲桌、六列课桌、窗扇与全部相机。实际窗框投影作为光影处理，没有把斜向阴影建成台阶或实体边。
2. 调整同一组太阳、环境光和补光，让窗框投影与空间层次可见。各镜头使用同一套参数。
3. 用常规材质颜色响应提亮现有木材、墙面、顶棚和黑板纹理。主模型没有启用试验中的“地板间接反射去饱和”处理；清玻璃仍采用已注明的阴影透射近似。
4. 右墙上窗改为较清晰的玻璃，下窗保留来源支持的磨砂效果。左墙玻璃保持清晰，没有把右墙磨砂外推到左墙。
5. 用共享的三维叶片与浅色建筑完善窗外层次。树冠、楼体距离、形状及室外地面高差均属推定，不是对真实场地的测量。没有按镜头放置图片背景或移动景物。

如何查看
- 打开Classroom_V4_1_共享模型_审阅.blend。文件由Blender4.3.2保存，18张使用的纹理已打包，无外部链接库或字体依赖。
- 场景相机SOURCE_A、SOURCE_B、SOURCE_C、SOURCE_D、SOURCE_4298、SOURCE_4300、SOURCE_4310对应七个来源角度。
- “01_主要角度对照”和“02_其他角度对照”包含来源、共享模型与实际50%叠图；另附各角度渲染及叠图。
- 对照图只作整幅等比缩放与最多1像素补边，没有单独扭曲来源透视。
- 本轮采用96采样、960×540的审阅渲染，保留少量噪点。可在同一模型中提高采样和分辨率继续出图。

已经检查
- 教室范围内原有1499个对象/相机的几何、位置与渲染可见性保持一致；外观调整没有暗中重排桌椅。
- 七个角度使用相同共享物体与灯光状态。窗外修改另有直接太阳光线前后检查。
- 4300与4310以完整桌椅、桌腿和道具轮廓复核，在已标注的明确空地区域内，学生桌椅遮挡像素仍为0。该选区不等于整张画面，也不包含人物及不确定区域。
- 当前共有20张学生桌。D实际可见桌面编号仍为12，来源至少14，因此该角度的数量与远处桌带仍未通过。

拟合点与检查点
几何数字沿用V4，不把本次外观改善当成结构误差下降：
- 讲桌/讲台实体标记，V3到V4：4310约96.4→9.5像素，4300约113.8→2.5；C约1.7→1.9，D约0.7→7.7，4298约0.3→0.8。改善与退步一并保留。
- 主体桌面C拟合约2.9像素；未参与同一拟合的C右侧检查约7.3。D局部木边约10.8，但不能替代桌数和远桌位置检查。
- 共享椅背指定轮廓拟合约1.7像素；中排另取可见轮廓检查，C约7.5、D约14.7。
- 4300窗扇保留检查点约3.2/5.2像素。
- 空地、可见桌数和B前景家具也参与过候选选择，因此不是完全独立的新数据。

仍需改进
- D角度桌面数量仍未对齐：来源至少14，当前12。只缩小椅子或只移动D相机不能解释已经验证的缺失。
- 顶棚仍比来源偏暖，4310受光地板仍偏浅。材质、室外细节、反射、黑板图案和光强均为近似。
- 太阳高度角不能唯一确定；约16–29.5度范围可得到相近的局部投影误差。窗影精确位置仍有偏差，不能把候选自身阴影对比度当成来源同位置拟合通过。
- B的窗段长度/窗间墙身份仍含推定；隐藏的桌排数量未因对称性补满。
- 来源人物未制作。视频段落/黑板内容不同不能直接证明桌椅布置发生变化。
- 所有尺寸以推定标尺为模型坐标基准，并非实测米数。

下一步结构试验
在保留相机、单桌尺寸和已确认布局的前提下，对两组当前被D画面裁出的侧列桌椅测试小范围前后错位。先要求出现两个新增且确实对应来源木边/围板的单元，再检查实际遮挡、腿架连接、碰撞、C的六段横向桌带以及4300/4310空地。若这些条件不能同时成立，就放弃该分支，不扩大范围硬凑数量。
