# 森林重放与远林参数试验：独立只读审查

结论：这是可复核的失败诊断，不是修正成功，也不是原件恢复。拒绝采用2倍远林半径有充分的当前模型反例。此次没有重跑Blender、重新渲染或改写生产文件。

## 实际核对
- 读取三份试验脚本、原R07与重放R09审计、统计JSON，并实际查看B/E/G×1倍/2倍全部六张640×360图。
- 重放R09模型SHA与其审计一致。625同名mesh中608个世界顶点/面序列hash与原R07逐项相同；17个不相同，正是11个花蕊和6个石块。17项顶点/面数、bounds完全相同，但体积不是字节/数值精确相等，最大绝对差7.78e-16，属于极小数值差。不得以bounds/近等体积证明相同表面或顶点排列，也没有证据将hash差原因确定归为顶点顺序/浮点版本。原BLEND字节尚未恢复。
- 重算每个试验所有视角的计数与记录相符。G的远树首先命中数为6/4/10/0，非单调；全部被计远树命中都在目标假设点之前，未发现distance=target+.3导致把目标后方树算成遮挡的现有样本。
- 地形JSON逐行重新计数为0/2/9/20，无统计错误。证据文件SHA列于 evidence-check.json。

## 计算方法及边界
远树分组正则包含同编号树干及后缀枝/冠。脚本按基部低于最低点+.3的顶点平均位置算XY中心，对完整家族加同一径向平移，非缩放。敏感性脚本每轮从原matrix恢复再施加偏移，最后恢复；预览脚本每个因子重新打开原重放模型。没有保存模型、隐藏树或逐相机改物体的代码路径。7个SOURCE相机和11个假设目标点固定。

此静态代码审查没有重新运行并取得独立前后全场快照，故不是对运行时所有对象不变的第二次实测证明。射线稀疏、点身份近似，own_flower_first也只是名称前缀命中，不代表来源花蕊或整冠表面正确。A–F远树计数0只覆盖这些点，不能排除岸林布局、照明、背景及其他像素回归。

地形测试是在指定 TERRAIN_finite_working_domain 上，沿每个树基部代表中心XY自z=100向下的单射线。无命中仅说明该中心射线没有碰到该有限terrain；并未测树根完整足迹、其他支承对象、接触高度或全场碰撞。可表述“2倍时20个基部代表中心均无该terrain命中”，不宜无范围地宣称“全部树根彻底无支撑”。有命中同样不是接地验收。

## 图像与决策
六图实际可见G中心树干遮挡在2倍显著消退，B/E背景树分布亦改变。低样本有明显噪点，不宜据其比较微小材质/轮廓误差。没有恢复原生源图，所以本轮不能进行实际来源直接叠图，也不能把G露出花冠视为来源一致。

拒绝2倍参数可基于代表基部离开有限地形、未约束的树位以及跨视图背景改变；不应为掩盖反例无证据扩地形。该试验有效地排除“仅把远树整体推远即可视为完成”的论断，未证明其他参数成功或不可能。17个非同hash对象与缺失原件还限制了将此重放试验等同于历史原场景的程度。
