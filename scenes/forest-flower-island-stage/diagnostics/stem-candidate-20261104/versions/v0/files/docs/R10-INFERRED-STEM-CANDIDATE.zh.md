# R10结构增量候选：补齐既有小花的推断花茎

本阶段在本机Blender4.3.2真实修改脚本重放模型，不是已归档原.blend的字节恢复。原文件仍在私有Git，当前跨执行器原件交接技术受阻；本阶段与原历史分开记录。来源整场匹配仍未通过，原生帧未恢复，不制作伪装原生叠图。

## 可核实的改动
既有9组SMALL_FLOWERS_patch对象由627个五瓣花头组成，没有对应独立花茎。逐头从花头底下中央向下的代表射线中，428条先落到推断苔床，494条间隙大于0.05模型工作单位。此计数不是完整表面无接触证明，也不是实际尺寸或来源花朵数量。

新增9个网格组，共627根封闭8边细茎，半径0.009工作单位。每根由苔床上表面下0.015延伸到既有花头中心上0.012。新增茎只为连接已存在花头和推断苔床，全部明确为隐藏结构推断，不能声称从截图测得细茎的长度、形状、数量或半径。

原625个网格世界顶点/面哈希全部不变，原15相机不变。材质与白模各634网格，逐项相同几何/相机。新9个网格组均无边界、非流形边或零面积面。627根茎与各自五瓣花头，以及627根茎与苔床，实际三角BVH表面相交测试全部为真。这是单独实体间的有限交叠连接，不是Boolean焊成唯一实体、全场无碰撞或物理承重验收。

新增内容所依赖的9个旧小花网格及苔床，与归档R07 audit的世界几何哈希均精确相同；R08/R09记录显示它们后续没有改变。重放中的17个花蕊/石块hash差仍保留，不因该局部吻合宣称全模型恢复。

## 视觉检查与剩余限制
两张800×600、12样本无降噪白模近景使用相同人工诊断相机。旧版花头下缺独立细茎，新版可见连续茎到苔床。相机仅在内存追加供诊断，未改保存模型的15相机。图片有噪点，不是来源机位或原生50%叠图。

现阶段不修改大花、岛高、树位、源相机或原有失败项。被拒绝的林圈试验没有写入此模型。隐藏直茎是否与实际源一致未证实；原625网格不变，新增9网格。没有以源曝光不足为由捏造细节验收。

原有A–G来源匹配、原生最高画质的本机回读、后续同场回放、动态时态及完整隐蔽接触仍待处理。本阶段是技术结构补全候选，不能宣称整场复原完成或用户已验收，也不以旧R08的8角图片冒充本次已重新拍摄的全套图。
