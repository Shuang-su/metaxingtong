# 板根02—主干距离矛盾：独立实际辨因

本机Blender单线程实际打开同一R15材质原件，分别用主干原polygons及实际calc_loop_triangles构造BVH；遍历板根02全部402顶点，并针对胜出顶点/面做float64特征距离复核。未改模型。

结论：本例旧0.05272585与新0.05333253来自同一非共面quad的不同三角表面定义，不能交叉当作同一表面的上下界。已实证，不是仅凭猜测归因。

- 两种BVH最近的板根顶点均为335。原polygon查询得到0.0527258515358，目标polygon203，四索引[1051,1052,263,262]。
- 该polygon最近点落在候选三角[1051,1052,262]上，点到该三角距离1.04e-8；板根顶点到该三角的float64距离0.0527258429991，重现旧poly结果。
- 实际loop_triangles在该quad采用另一对角线：406=[1051,1052,263]和407=[1051,263,262]。同顶点到两三角距离分别0.0533325311206和0.0538906388093；原poly最近点到loop406面距离约0.00060915，并不是相同三角面上的点。
- 用实际loop造BVH得到上界0.0533326230943，与float64结果差约9.2e-8，为当前BVH数值量级，不再存在旧上界矛盾。
- 对胜出顶点335逐全部主干loop三角复核，最小仍为0.0533325311206、loop406；对包含该顶点的全部板根三角逐全部主干三角运行完整feature法，最小同值，板根triangle546/主干406。

本轮只解决板根02的特定矛盾，没有重新认证八根的全局最小值/包含关系，也不因此称真实源断根。今后距离、接触和候选验证应明示使用actual loop三角或poly内部分割，并保持比较口径一致；不同面定义的数值不能无说明混用。保留旧poly结果及本次loop结果，不静默覆盖历史。

实际模型SHA、坐标、面索引与所有候选三角距离详见buttress-discrepancy-check.json。该结论不授权任何新建模或生产文件改动。
