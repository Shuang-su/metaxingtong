# 板根连接与非共面quad三角化诊断

本包不改变任何模型，不算新场景或修正版本。绑定R15明确非原字节恢复的脚本重放模型SHA，不能代替原始直播来源证据。

实际Blender loop三角网格中，8个板根对主干的三角表面最小欧氏距离以float64特征对/边面相交法和AABB安全下界剪枝计算；04为0，另外7项为0.01556至0.07906工作单位。数值与每个胜出三角索引全部保留。代表每个板根顶点0对主干实际三角的实体角绕数均接近0，只有这些点被检测，不扩成全场体积或支承结论。

发现并保留一个方法差异：旧BVH.FromPolygons得到板根02顶点335到主干quad203距离0.0527258515，而实际loop三角距离0.0533325311。独立实际核定位到非共面quad的不同对角线：polygon对应最近三角(1051,1052,262)，真实loop为(1051,1052,263)/(1051,263,262)。旧polygon最短上界不能约束另一个loop表面，不能把这一差异说成原模型已损坏或数值函数已修复。后续几何距离与前后比较应明确采用一致的实际loop面定义。

small-triangulation-witness.json直接保存了确切世界点和quad四点、模型hash。reproduce_small_witness.py无需大模型即可重现这两距离，三角距离自测也保留。完整八板根研究仍需已归档R15模型，不把本小包冒充整场恢复。独立审查只对02辨因复核，没有把七个正距离升级为源场景断根。
