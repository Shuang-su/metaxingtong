# R15：倒木与有限地形的局部接触候选

本版接续R14的明确非原字节脚本重放基线，不改旧版本。板根02和倒木没有直接地形表面交叠，逐顶点又都在地形上方。为避免仅检查顶点漏掉跨面穿越，进一步对实际三角网格做XY投影交集裁剪；每对交集多边形上的两表面高度差是仿射函数，在其顶点求极值。独立审查用另一种“双方内含顶点加边交点”算法重算，得出相同结果。

板根02最小垂直间隙0.017042615913、倒木0.073702967775工作单位。全部投影三角均非退化，分别849与2444个非空投影面配对。这里只是有限地形上朝三角表面的垂向距离，不是欧氏最短距离、真实米制或来源测量。板根与主干连接仍不明，本版不动它。

R15仅将LOG_left_fallen整体世界Z下移0.076702967775（倒木最小垂直间隙加0.003数值余量）。不改变局部网格形状、XY、UV、其他633对象或原15相机。材白用同一位移。实际地形BVH出现4对面交叠，表示局部浅相交，不是Boolean焊接、全足迹接触或物理稳定支承证明。内存试验检查全部AABB重叠候选，只有地形新增为相交对象，原植被关系未增删；交叠对数量会变化，不能称整个碰撞情况不变。

保留首轮完全暗的近景失败图。第二轮用较高人工相机和相同诊断补光，8样本预检看到局部暗缝变窄，仍有草叶遮挡与噪点。最终对照使用800×600、32样本、同一人工相机和45W AREA补光，无降噪；这些是接触诊断，绝不是原直播机位、源光照或来源50%叠图。新相机与补光只在渲染时加入，没有保存进模型。

来源A–G依然FAILED；整场原件本机恢复、源机位匹配、后来同场复用状态和本增量的新原生叠图/全套8角均未解决。不能凭局部接触修正声称重建已通过。原R14树底有限修正、R13草根18+2边界、17对象重放hash差异及所有旧失败继续保留。

实际独立模型核验：898世界点只改变Z，float32实际位移范围[-0.0767029822,-0.0767029524]；材白634对象共享几何，其他633对象及拓扑不变。双GLB真实回导634网格、15相机齐全，世界顶点误差0；GLB原局部几何和UV数据字节不变，只有倒木节点变换发生变化。独立光照及最终图像报告同版保留，以确切文件hash为准。

整个倒木的位置变化也会移动源相机中的投影，不隐去此项回归。A–G中全部898顶点均在相机前，平均/最大位移像素依次为：A 4.183/4.269，B 5.573/5.757，C 7.766/8.079，D 2.756/2.847，E 8.874/9.336，F 7.128/7.395（以上1920×1080），G 8.251/8.413（3840×2160）。这是模型投影变化，不是源匹配误差，也未做逐点可见性证明。
