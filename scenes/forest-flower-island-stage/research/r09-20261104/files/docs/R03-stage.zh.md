# R03 固定悬浮态候选，非动画复原

新2992.479275与3047.185491真实原生明确悬浮且有倒锥状连续暗底，未见茎柱。加入有界暗色倒锥核与外部透空枝叶，不将整圈灌丛填实，也不凭相对深度推断实心形状。核心土/岩/密根材质仍不能从暗部确定，内部填充和截面是推断。所有花岛对象统一升3.3模型单位，顶面4.5是固定候选坐标而非真实高程；所有机位同一状态，未动画或按相机切换。

背景加32组程序化灌木、6大蕨、垂藤叶，主树/根表面曲化；502mesh。形态与叶实例仍近似，主/背景树的分叉过规则、树冠与林层密度不足、颜色光雾差异、花瓣轮廓和岛底高度都未验收。低成本双图已实看，远景有限地形边缘/空背景明显，不能当完整森林还原。
