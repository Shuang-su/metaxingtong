# 床端与浅色前景身份复核

此轮先核对实体身份，尚未修改床、桌或相机。C3/C4/C5已冻结原件保持不变。

## 逐帧结论

- **原生665.501733**：浅木纹、硬直板面可见，木桌面身份高置信；不能标作白床垫。相机尚未建立，因此没有对其做模型像素残差。
- **6063.423552视口**：木桌面上放置通话屏设备，后方绿椅与棕色沙发。它支持桌面物件的存在；只在1180×757视口坐标下标注，不换算成1920原生。
- **原生N640/H**：底边仅露出很窄的浅色前景条带。与桌面相容，但只凭这些条带不能确认完整桌形，更不能确认床垫厚度、双长边或床足迹。
- **原生G**：右下是亮平面和条状投影。它与床端板邻接，不等于整片就是床垫。端板与前景平面保持不同实体分支。
- **5663/5668/5693视口**：双横孔、中央长圆角凹槽、圆钝肩部的浅拱端板，与原生F/G及左窗、双杆、电视墙组合高度相容，可作同室同款床端的合理候选。没有证明床的另一完整长侧与隐藏端板。
- **5476.600449明亮低机位视口**：新增明确可见的软包床垫外侧、窄托边、纵向托架、斜撑、一处轮脚。只露单端板局部与一侧片段；同一资产实例/空间变换仍待确认。它是床外低机位，不能直接拿来标定患者躺姿。

采集上下文：5473–5475棕墙前护士正面，5476切到低机位床，5477–5479渐暗，5480–5481帘前演出仍有床局部；不是立即切到电视。约5630回明亮窗向病房。上下文支持“演出段的另一个机位”，但不能据此假定全部家具变换连续。

## 现有模型归属不等于来源身份

当前场景没有木桌面对象，只有 Bed mattress、base tray、bumper、side rail 等（另有小型输液架托盘）。独立来源内点对应的实际全场首命中见 `foreground_model_first_hits.json`：G/H大多被现有模型的床垫面覆盖，N640还命中推断的低端挡板。这个结果是**现有模型如何占据像素**，不是“来源已证实为床垫”。

模型中 `Cream foreground platform finish • identity uncertain` 的不确定标记应保留；不能把 Bed 对象名当证据，反过来升级来源身份。

## 原注释修正建议

`prior_annotation_correction_proposal.json`逐项记录需修正的旧措辞与哈希。N640沙发右扶手、H绿椅下沿的说明中出现的“pale foreground bedding”应改为“身份待定的浅色前景平面，桌面候选”。保留旧线点、遮挡排除及圆肩分支，不修改冻结原文件。A/B/G真正的端板轮廓分支继续保留为端板族候选，不能跟着改成桌面。

## 下一步可实行而不扩大假设的顺序

1. 使用本轮逐帧标注区分：确定桌面、明确床垫外侧、端板、身份待定前景，以及阴影/真实轮廓。
2. 只在真正可见的硬边上建立跨图实体连续性；未确认同一边之前，不把G/H/N640浅色边互配为桌边或床边。
3. 对木桌做一个独立、明确标为假设的薄板候选，支架与隐藏形状分开；先检验原生665与现有可匹配视角，不直接把厚床块改名成桌面。
4. 床下斜撑/托架作为低机位来源支持的结构候选，保持独立相机；不据演出低机位扩大床长，也不补出未露出的第二端板。
5. 患者眼位与床完整足迹仍需联合验证。桌面身份纠正不会自动解决C5相机位于粗床外的问题。

标注图及逐点置信度见 `independent_visual/`。全部视口证据都带非原生标记；本轮没有宣称新几何或相机通过。
