# 病房床挡板中央轮廓候选 C

## 结论与采用状态

C 是在冻结 B 上只改中央装饰轮廓的局部候选，不是已验证的真实凹槽结构，也不代表病房整体还原通过。B 原件与所有失败相机试验保留，CURRENT 不变。

两张原生来源都支持“连续大圆角轮廓”这一可见差异，但不足以唯一判定暗边来自整片凹入、窄环形沟槽，还是带阴影/暗色边缘的凸起嵌片。因此 C 只把旧模型两层小圆角盒体的正面轮廓改成长圆形；原有厚度、前后关系和材料都是继承的未确认假设。

## 直接查看的原生证据

- F：BV1GqXMByE1s，1823.678156 秒，1920×1080。中央特征连续上缘和两端上部圆弧可见，下缘在画幅之外。可以确认上角不应像原 B 那样近乎直角；不能仅由这张图量得整体高度或凹入深度。
- G：同一视频，1116.180816 秒，1920×1080。中央特征并非完全不可见：画面右侧保留左端完整圆弧和少量上下边；右侧主体被画幅裁掉。这个左端支持长圆形的端部候选，但不能确认整个轮廓的宽度、完整对称性或截面符号。
- 两图的明暗边缘均不能单独当作有符号深度。没有把帧外轮廓、暗影或旧物件名称当作真实凹槽证据。

2. `Bed end • cream inset face`

上述名称沿用旧模型，不代表此次已证实其语义。每层 YZ 外轮廓改为半圆端长圆形；保留各自的 X 厚度及包围盒、中心、对象变换、材质、可见性，保留厚度方向的圆滑过渡包络。数值半径采用现有高度的一半，属于约束候选参数，不是从图像标定出来的真实半径：

- 材质版与白模版全部357个网格的几何和变换一致。白模只替换材料。
- 材质/白模GLB均实际重导回Blender，全部世界三角形在1e-6取整下相同。两个目标的导出前/重导后双向最近顶点最大偏差均0。

## 渲染与叠图规则

为了让前后对比使用同一采样条件，重新渲染 B/C 各自的原 F/G 相机：全部1920×1080、Cycles固定16 spp、关闭自适应采样和渲染内去噪、seed=0、2线程。运行使用统一渲染锁。每张的实际设置和相机矩阵见 render_manifest.json；没有采用先前被拒绝的F/G新相机。

B源BLEND保存的预设仍为24 samples且自适应打开，不能把保存预设冒充这次图像的实际采样数。本次四张比较图明确覆写为固定16 spp。旧B图片不覆盖，亦不与本次受控前后对照混用。

正常观看副本使用OIDN2.5.1的CPU/LDR/sRGB/high模式，2线程；原始渲染PNG保留不变。直接50%叠图使用原生来源和原始未去噪渲染，逐通道计算 floor((source + render)/2)，已做像素精确核对。没有配准、透视变形、缩放、平移补偿、screen warp或裁剪后重新对齐。

同坐标局部板使用：F裁切框(750,900,1920,1080)，G裁切框(1530,720,1920,1000)。每块以原像素1:1放入带标签的接触板；行序为原生、B前、C后、原生+B原始50%、原生+C原始50%。标签和留白不参与来源像素。

## 本轮实际看图结果

F/G的原相机全帧及局部前后图已经实际查看：B近直角端部在C中变成连续圆弧，方向与两张原生的可见轮廓一致。但C仍呈较厚的边框观感，真实凹凸与边缘过渡没有被证实；F中央特征仍明显偏左、偏上且投影宽度较小，G露出的左端仍偏左、偏低。直接50%叠图保留了这些矛盾，没有为了“对上”移动相机或物件。本轮仅能确认圆角形态的局部改进，不能验收截面与空间匹配。

## 尚未解决与下一步最小输入

全帧仍存在原先的相机/尺寸错位，不能因为圆角更接近就判定床整体位置、宽度或病房场景已通过。F源槽下部不可见，G仅见左端；C的完整轮廓及两层结构仍未获完整验证。

要从“轮廓候选”进入真正截面修正，最少还需要一张完整露出中央特征上下边的原生近景，以及一张能看见板面与该特征边缘厚度阶差的静止侧斜原生近景；必须能复认同一物件、排除运动模糊和UI遮挡。没有这类证据，不应靠阴影猜凹入量、切穿孔或改动背面。
