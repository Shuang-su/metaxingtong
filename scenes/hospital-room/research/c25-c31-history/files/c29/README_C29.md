# C29：中央帘布内部折频修正候选

## 实际改动和范围
在C28上只修改一个帘布对象的网格。原对象名仍含“eight-fold”，作为历史标识保留；新候选是7个名义横截面周期，能在已观察区域形成H/G/N642约5/4/4个可见主亮脊，不能把它称为完整帘布真实总褶数。
前层两端各一个原周期保留，中间用单一平滑相位映射调整折距。高度、绝对端边、世界外包络、相机、柱、帘轨、椅子及其他对象不变。背层为了消除穿插另作重建，不能声称保持原法向厚度。

## 失败方案和采用依据
真实试渲染比较了5/6/7全网格周期。5周期过疏，6周期中间出现明显宽折、可见主脊数不足。7周期的可见折序更稳定；但最初直接给前后两层相同X位移会产生穿插。因此所有hospital_C29_TEST_*文件均为拒绝的诊断版本，不能作为交付模型。
原C28背层本身存在重复小自交回环。修正版保持前层轮廓，内部背层采用局部X正偏置，偏置由源配对厚度长度中位0.00406776局部坐标单位取值，在两端过渡并桥接原背层小回环。修补后同索引前后距离并非常数，约0.00254–0.01862局部坐标单位（物体统一缩放1.25，世界坐标长度为此值的1.25倍）；既不是恒定法向厚度，也未标定为米。真正交付的两个模型名称仅为hospital_C29_curtain_MATERIAL_CONDITIONAL.blend及WHITE_CONDITIONAL.blend。

## 真实区域渲染量化
在原生1920×1080坐标固定ROI、同一灰度平滑/峰检测方法下，修正版32采样区域真实渲染的内部亮脊间距为：
- H：C28 [17,17,18,18,19]；C29 [21,23,23,21]；原图 [24,27,26,27]
- G：C28 [14,14,15,15]；C29 [19,18,17]；原图 [20,21,21]
- N642：C28 [15,15,16,16]；C29 [20,19,18]；原图 [21,24,21]
中位间距H 18→22px（目标26.5），G14.5→18px（目标21），N64215.5→19px（目标21）。主亮脊数量由6/5/5变为5/4/4，与这些固定ROI原图一致。
亮度峰依赖材质/光照，不是逐点3D地标，也不是整个帘布总褶数。这些值支持内部折频同向改善，不能宣称精确对齐。H各脊位置仍有向左残差，G/N642方向不完全相同，未用整体平移掩盖。
H/G用于主要候选比较；N642以前已看过，且本次也参与候选审查，不能称它为盲测或完全独立验收集。1801/1804只复核折序拓扑，没有用未标定相机强行合并空间尺寸。

## 几何核验
两版重开后，仅帘布网格状态改变，所有已记录其他对象几何、可见性和相机状态保持。
两版实际导出顶点的65层横截面，前层/背层自身及相互的严格线段穿插计数均为0。拓扑不变：29250顶点、29248面、58496条边，每边恰有两面，无新增开放边。此项不等于物理布料仿真通过。
H/G/N642/665在完整有效图像行的投影凸包外边变化为0px；只保证这个几何外包络量，不等于完整遮挡、阴影、材质或所有图像像素不变。未用该指标替代实际渲染审查。

## 保留问题
G原图帘顶/帘轨端可见，而当前模型顶部仍偏高、部分出画；其余已有固定视角无法共同约束这一高度，本轮保留。右侧回折面的内部形状和原有左边软阴影偏差也未调整。厚度、真实尺寸、完整总折数、画外连接、房间标定均未解决。本候选只作为可回退的局部几何改善，不是全场景验收。

## 渲染和恢复
区域诊断图32采样且边界以外为空，文件明确标REGION_ONLY，不能当全场景成品。最终完整图使用Blender4.3.2/Cycles CPU、1920×1080、16采样、seed0、无去噪；保留原相机和原照明。原生50%叠图为逐像素平均，不配准、不变形、不补遮挡。低采样噪点及较亮白模照明沿用，不声称视觉品质完成。
Git保留C28、所有失败试验、有效壳层修复和最终渲染；交付索引区分有效模型和拒绝试验。没有推送未经认证远端。
