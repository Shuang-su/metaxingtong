# C23：支柱轮廓局部改善，完整绿椅与房间仍未验收

## 实际结果

沿用C22完整房间，实际只改变两根绿色椅背支柱。345个其他网格、35台相机、材质分配、物体变换与可见性保持不变。没有逐视图隐藏、相机再拟合、配准、缩放或warp。

- 19个可明确区分图像左右侧的支柱原采样点：C22为0/19，C23为18/19同时满足原3px带和全场首击可见性检查。
- 665左支柱的8点全部入带，最大实际保存网格误差0.795px。
- H右支柱内侧靠接头的首点[828,991]仍约7.895px，未入原3px带。
- 背板本身未改：49个原采样的最近正确分支足点仍49/49可见，仍只有36/49在原容差内。G上缘最大8.691px、H上缘7.327px、H下缘7.193px旧偏差继续保留。
- H左侧卷回/支柱复合轮廓单列8点，2/8入带，最大10.657px；没有把这条复合边硬说成单根柱边。

## 几何选择与未知项

两图的可见绿色支柱边界支持一个共用椅体假设，但不能证明跨片段椅子完全没有移动。左柱下段用H短内侧和665两侧共同约束；右柱仅有H直接支柱证据，深度保留一个明确的构造先验。G只提供背板回归，支柱在画外。

C22把整个支柱强制放在无限延伸的背板平面后方，这一额外构造限制与新的支柱源轮廓不相容。C23改成简单的侧/下缘接入假设，允许下方支柱位于该无限平面前方，但并没有测出真实接头。椅座端点、截面、隐藏弯段和接头均是假设；665暖色斜面不能认证为椅座。

初始连续扫掠在急弯处产生实际自交，已作为失败中间件保留。最终交付版本只对两柱执行0.0007场景单位的体素表面并集，随后在实际保存网格上重新测量。体素尺寸不是实际米制尺寸，不能把closed/manifold、正体积或低像素残差称为制造/强度/真实尺度认证。独立数值检查发现最终两柱的全网格BVH自重叠对均为0；同一检查仍能检出v1的115/157组失败交叠，因此对原先急弯折叠有响应。接触候选限制在假定的卷边接头和椅座端点邻域，未见房间壳体交叠。这是数值诊断，不是精确无交叉或真实物理接法的认证。稠密网格的穷尽精确有理数检查耗时过长，已停止并保留未完成日志，不能宣称通过。详见independent_review目录中的版本化报告。

## 原生图、真实渲染与主视图

使用BV1GqXMByE1s已保存的原生1920×1080 PNG：H=1101.728114s、G=1116.180816s、665=665.501733s。source_native目录同时提供三张未修改源图。它们是本地可验证的最高原生分辨率；本轮没有新采源，也没有声称恢复更高清的隐藏信息。

review_renders内每视图均为同一个最终保存模型的实际Cycles CPU RAW，16samples、seed0、关闭降噪；与C22设置一致，噪点保留。direct50严格逐像素floor((sourceRGB+RAW RGB)/2)，无配准/缩放/warp或遮罩。椅部位联系图只作原生1:1裁切展示，完整RAW与直叠才是主证据。H是主视图。

白模文件保持同一完整几何/相机/可见性，仅室内不透明材质改成哑光白，玻璃和外部背景保留。

## 仍未解决

- 人物和原视频HUD不属于房间模型。原来被人物/画幅/前景遮挡的区域没有补作测量。
