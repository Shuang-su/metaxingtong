# C24：三种形体假设均未通过视觉核对

结论：没有一个C24替代C23。C23本身也仍是条件性、未验收模型。本轮停止继续拟合；保留三份实际模型、白模、原生渲染和真实提交，供复查失败原因。

## 新源图确实说明了什么

650、658与无遮挡1103都重复出现“亮的卷曲上唇、较宽的凸曲竖带、其下较窄的支柱”。这支持实际需要一个曲面/重叠结构，不能只把直支柱加粗。但背板回卷、覆盖式立柱和融合接头的隐藏连法仍未被唯一确定。

四张新原生1920×1080图已在几何修改之前单独提交。1103不是H1101的同一帧，不冒充已对齐相机。658的保存前readyState未记录，仍明确保留为空。N642本轮按要求打开，已成为开发观察，不能继续声称它是未见留出。H与665相隔约436秒的共同静态椅子位姿仍是条件假设。

## 范围与检查

每个变体都从冻结C23 v2出发，只改“背板/左回卷”这一网格。其他346个网格、35台相机、所有物体变换、材质、可见性、集合及世界设置保持一致。两支柱不变。白模与对应材质模型的几何一致。

保存后独立数值复核：三个背板均为单连通、闭合、定向一致网格；BVH未检出自重叠。两侧支柱仍有局部连接重叠，未发现脱离、第二个远端接触或新增房间/沙发碰撞。v2扩大了隐藏重叠区域，不能说接头完全不变。这些是数值检查，不是穷尽精确无交叉证明，更不是源形体、制造或真实尺寸认证。

## 为什么不继续局部折边

继承背板依赖一个拟合平面、薄板截面和曾由构造先验闭合的左侧轮廓。冻结这组平面/相机/支柱连接关系后，单纯在左边局部弯折，能够改投影边线，却没有同时恢复源图较宽的凸曲表面与自然收口。增加凸起幅度又把错误带到下左轮廓和隐藏接头。

这说明本轮局部变形方案不足，不证明源图只有某种唯一结构。光照/材质并未重新校准，明暗本身也不应被当作隐藏拓扑的证据。

## 下一步建议，仅计划、不执行

从完整椅体的低复杂度体块重新组织背板、宽侧部、窄支柱及其过渡，而不是继续给既有薄板追加小折痕。先并列两个可解释的粗模分支：连续回卷壳体；背板与成形侧框重叠。让部件体积、朝向与过渡自然协调，再检查可见轮廓。椅座、落地和隐藏安装继续标未知，不能凭构造补全就声称测得。

在这一重建之前，应独立处理新视图相机和椅子—房间位姿的一致性；不把相机或椅子运动误差藏进形变。当前没有开始该重建，也没有继续采源或修改任何相机。
