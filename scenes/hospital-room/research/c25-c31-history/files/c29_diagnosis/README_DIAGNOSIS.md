# C29只读诊断：中央帘布内部折频

## 结论
优先做“5个可见前折的低频帘布候选”，并与6折保守候选对比。当前八折的内部周期过密，有H/G/N642三个原生视角约束。不能由亮暗条数推断完整帘布总褶数；G/1801的顶轮廓支持5个可见前折尖，左侧背面回折可能被自身或柱遮挡，右侧宽末端面不另计第6折。这里的5/6是候选，不是验收结果。

## 保守改动范围与拒绝条件
1. 只操作当前帘布网格内部横截面周期，5可见主折为主要候选，6为对照；优先目标是内脊距增至当前1.4–1.5倍，不要求完全等距。
2. 锁定现有世界外包络、两端边条、底边及当前顶边高度；保留双面厚度和拓扑闭合。不要整体缩放、平移、动柱、轨、家具、相机、灯光或材质。仅保留包络数值仍不能保证投影轮廓，必须比较H/G/N642逐像素轮廓。
3. 保持两端至少一个过渡带，不把均匀五周期简单塞入全宽后拉动端点。各高度层使用同一低自由度截面变换，避免为单视角局部掰网格。
4. 这一步不改顶高。G原生帘顶在y31…76可见，C28顶缘到画外（整体投影bbox最小y=-122）；属于另一个明确误差，但H/N642顶缘画外，需另找合格相机/证据共同约束，不能混进折频修正。
5. 验证要求H与G内部周期同时向原图靠近，N642不退化；任一视图外边界有新增可见偏移则拒绝。用几何/白模和材质两种检查，避免把光照变动当几何改善。
