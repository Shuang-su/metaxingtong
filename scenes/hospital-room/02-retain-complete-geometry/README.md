观察与推定
直接参考部分：窗墙排列、百叶、窗帘及轨道、沙发和椅子的可见外形、电视墙及显示器、输液架和挂袋、床端板主要形式。
推定部分：房间未见的左墙与后墙、地面范围、门洞位置及门扇、墙体厚度、门窗构造、家具背面、床底和脚轮。相关对象和集合均有inferred或推定说明。
床的完整长度、宽度、高度是依据多视图和可用空间正则化的近似值。它们不是原资产参数。参考只展示床的一部分，不能唯一恢复整张床。

仍有差异
• 参考来源是低清播放截图，不足以恢复精确材质、家具制造结构或窗外城市。
• 病床在F和G中的残差仍明显，原模型相机与床端板对应点不能严格三角化到同一空间点。本次没有为了让某一张图好看而重复使用沿视线放大端板的办法。
• 新房壳可能让光照与旧版不同；窗外是几何示意，电视为替代屏幕内容：无文字的抽象线条，不代表复原了医疗监护仪或原视频节目。人物、播放器UI和节目画面不参与几何复原。
• 床与沙发相邻侧不是主要通道；从后入口沿后方大通道可以绕到床的电视墙一侧。净空数字是几何检查值，不是医疗或建筑合规认定。
• 叠图是同尺寸参考与真实渲染各50%直接混合。没有透视变形。人物与窗外差异不可解读为室内几何误差。
