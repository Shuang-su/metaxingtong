## 有限技术核验
- 材白215mesh世界几何与13camera一致；实际GLB回导215mesh/13camera齐，世界顶点最大差≤5.332e-7工作单位，画幅相机射线差≤1.192e-7。
- 单体非流形、退化面和负体积均0。14窗148554网格点按计划孔域分类，未计划漏孔/应开却挡均0；16接缝×5高和96屋盖射线样本有实体命中。这不是连续全壳无缝、全场碰撞或整窗视线净空证明。
- R03同构检查曾有67520错误漏孔点与1280误挡点，原件/图/日志保留；R04起改为真实实体Boolean孔，非隐藏墙。
- 8直接叠图独立全RGB数组重算为0通道差、所有源/渲染/叠图SHA匹配。这个0仅指混合算术，不是源图与模型误差为0。

## 仍未通过
1. 原生帧、精确片内时间、最高可解码质量、后续原生多角与连续同状态都未闭合。
2. 四尖/金环条件比例已修正，但13/21同训练点最大投影残差仍11.75/22.08px，超原约4px人工界。门窗位置、壁高/开孔节奏、穹顶剖面、外台/拱架关系有明显双影。14/15相机未标定，四源全部FAILED。
3. 16分区/14窗、后侧布局、厚度、门槛与支撑截面为假说。支架在部分视角挡窗，不得把墙板孔域通过当整窗无遮挡。100根植被是代理，不是源实例计数；纹饰、星空行星、动态光效和细节材质不足。
4. 8模型角局部有效，但部分台缘、屋尖/星尖被画幅裁切，左右对称视角相近，未展示完整底面和内部屋顶。它们不是8个来源角。
5. GLB无外部贴图依赖，使用常量PBR代理；不带完整Blender灯/World/Cycles，跨软件外观不承诺相同。高采样主图仍可见代理造型/局部噪声，非照片级完成。
