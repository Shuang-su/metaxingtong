# Stage 03 — 接触、边缘与占地复核

本阶段使用现有四张同 BV 原生源。母线程所述另一 BV 反向帧尚未接收，未用于本阶段改形。当前为待来源复核候选，不是验收通过。

实际修正：有限铺地延伸至当前四机位可见前景区域；长凳加接触脚垫，并按铺地/草地实际顶面落位；蓝场灯/篮架和绿场篮架、树池按各自场面顶面落位；楼梯加推断底板；两处花池避开入口台阶和蓝场；后沿长凳避开树根；入口三级台阶由互相重叠的盒体改为一体连续截面。新花池位置、底板做法、地面隐藏延伸仍是推断。

本阶段没有改窗格/立面或跑道几何，没有采用角色尺度。冻结几何的相机试验加入独立复核者读出的门框和篮板角点：SRC02 推到136.6mm焦距/15单位高度边界；SRC04 改善板角却扩大未参与拟合的门口误差，因此未采用。原四来源机位保留，试验实际 BLEND 和图保存在 research/camera-only-trials。

真实来源中存在红橙篮下涂装和额外弧线，当前标线候选仍不准确。平面涂装试验已实际渲染，但其猜测范围与尚未解清的树池/楼梯占地冲突，故未纳入本阶段主候选；见 research/paint-layout-trial。反向源到达后应先锁定本阶段几何，仅定新机位和留出关系，再联合解决该区域。

独立旧候选复核见 qa/independent_review_stage02.md；本阶段作者的实际几何/像素检查、同机位前后图片与逐条支承数据另保留。所有渲染继续共用一套几何、材质、照明和可见性。未 push、未建 PR、未重试 Library401。
