# Evidence interpretation

`object_evidence.csv` contains one row per actual mesh assembly, including stable repeat-window, bench, lamp, tree, goal and hoop IDs. Repeated window correspondences are provisional; the source-category column never certifies every repeated instance is visible. `stair_tread_instances.csv` identifies each of 72 candidate tread solids by flight, dimensions and mesh vertex range. Count, hidden flights and dimensions are inferred, not source-counted.

All positions are arbitrary model units. Character body/height was excluded. Source images remain unaltered. Source01–04 are four native images from one BV and not later-replay evidence. An image crop is not an independent view. Every local compare uses exactly the same source camera and unmodified shared scene; no per-camera visibility changes.

Dense ground rays test only the finite slab. Aperture rays test wall shell clearance through intended openings; glazing is a separate real pane. Limited foreground clearance probes do not certify all routes. Assembled solids overlap at designed joints and are not Boolean unions. Exterior stair is a visual candidate, not a structural design or code-compliance assessment. Hidden rear shells and roof closure are inferred finite extents.

Source image residuals, camera calibration, canopy shape, material/lighting similarity and later-replay identity remain separate unresolved gates. Geometry/file checks never imply source acceptance.
