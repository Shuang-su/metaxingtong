# 候选核验与剩余门槛

当前状态：**重建候选 / 待来源复核 / 未经用户验收**。本报告将几何、来源和文件交付分开。

## 已实际实施

- 四张原生来源图均在本环境用官方 Library 流程物化，核对 bytes/SHA256/PNG 解码尺寸，并实际查看。均为 1920×1080、同一 BV。采集清单原件保留。实时直播渲染还是预录未知。
- 最终材质与白模有 128 个相同几何组件；材质白模坐标、拓扑哈希一致。树为体积几何，窗为带进深的实际洞口、窗框与玻璃。动态角色不建模，不以角色高度定尺度。
- GLB 由 Blender 实际导出后在清空场景中重新导入，保存 `glb_actual_reimport.blend`。回导组件名称和三角面数逐件核对，原/回导顶点做双向最近邻检查。GLB 两张嵌入纹理与原 BLEND 的解码像素哈希一致。
- 11,520 条地面覆盖射线无漏检，684 条窗洞壳体射线未发现前墙堵洞，限定前景区域 287 条净空射线未碰到所测高度的障碍。原始逐条结果保存，不以此推断整场通行都已通过。
- 原始网格零面积面 0、非双面邻接边 0；逐闭合基本体有向体积未发现反向组件。组装构件允许相交连接，并非整场已作布尔并集；这不是完整自交认证。
- 72 个候选踏步都有稳定实例 ID、实际顶点范围与位置核对。立柱、斜梁、踏步、平台及栏杆回接均为真实几何。具体踏步/楼层数量、隐藏接头及结构承载仍为推断。

## 来源仍未通过

四机位最终静态手选锚点平均残差约 SRC01 49.6 px、SRC02 56.8 px、SRC03 57.2 px、SRC04 51.8 px，最大分别约 69.9、129.9、72.9、111.1 px。精确记录在 `source_landmark_residuals.json`。这些点被用于相机拟合，不是留出的独立验证点；SRC02/SRC04 的拟合触及高度/焦距边界。不得以残差下降宣布相机已标定。

已知需要继续修改：窗列实例对应和比例、近树池/路面投影、跑道曲率与终止边界、有限运动面范围、设施相对距离、树冠密度/分枝/遮挡、光照阴影、窗玻璃和地砖材料。窗角、台阶端部局部暗斑需要进一步排查接缝/重合面；有限检查不能替代逐处接触复核。建筑背面、楼体完整范围、真实尺度、隐藏设施和支撑没有来源确认。

最终图像检查还暴露了两个具体未完成项：SRC04 条件机位右下方露出有限地面边缘，需要在后续联合解中重新确定可见地面范围；四张长凳最低点约高于铺地 0.0126 模型单位，需要下一阶段修正接触。栏杆连接组件本来由楼梯上部支撑，不能把其不落地当成错误。以上保留在候选，不把有限几何探测全过写成完整几何验收通过。

后续其他回放同场验证仍缺；四张同 BV 的真实方向变化不满足跨回放要求。并未观看整部回放。母线程的连续运动观察作为回报保存，不冒称本环境重新观看。
