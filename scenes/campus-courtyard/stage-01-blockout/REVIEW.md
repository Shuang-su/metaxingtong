# Initial shared blockout — retained trial

Four native references read and decoded. 117 inspectable mesh assemblies. Source camera positions remain manual, conditional guesses. This is an actual intermediate white model, not a source acceptance result.

The first render attempt failed because the installed Blender build has no OpenImageDenoise. That log and the actual saved BLEND were retained under research/. Denoising was disabled using the existing renderer; no installation or security change.

Visual inspection of SRC01_white_initial.png revealed black patches at coplanar overlapping pier/spandrel fronts. Next material candidate splits the spandrels by bay to remove those overlaps. Foliage is a sparse volumetric approximation; crown density and branch topology are not source-confirmed. Ground/track curvature, lamps and benches still require joint camera refinement. At this stage the preview is 960×540, clearly a render diagnostic rather than a native source frame.
