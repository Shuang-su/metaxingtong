本包是可检查、可继续修正的候选，不是“像素还原验收通过”的成品。几何完整性与GLB往返检查已单独验证；来源匹配仍有下列可见残差。

## 场景范围与推定
视频可见折角背墙、实体顶板、吊杆、反光地面、圆形台面、左右墙饰和道具。候选建成一个有顶、前侧开敞的有限舞台壳体：厚墙与顶板/底板搭接，圆台有完整边缘及底面，吊球与顶板相连，画板有背撑，霓虹有实体孔洞和连接杆，桌腿落地。

视频没有证实观众厅、前方封闭墙或舞台外房间，未把其他场景拼接进来。隐藏墙厚、背板、底面、前角柱、安装背撑及小坡为构造推定。尺寸采用比例单位，单位设置为None；不是测绘米，也不能用作施工尺寸。

## 一套共享场景
所有来源机位和普通视角共用同一几何、材质与灯光。没有按相机隐藏物体、移动道具或换材质。白模文件只统一替换材质及白色照明，顶点/面/世界变换哈希与材质版相同。

“显式剖切”是单独派生的x=0.10截切检查图，用于看墙、顶、底板厚度和隐藏连接；不是用相机显隐伪装完整模型。原模型保留完整实体。

## 仍未解决的来源残差
1. 星形外围条带、折角透视、内星宽度仍不完全重合。当前人工稀疏星轮廓点平均像素误差约A 22、B 32、C 13（1180×663裁图）；它们不代表全图误差或验收指标。
2. A/B相机加入了共用吊球和台面约束。部分灯位仍有约十余至二十余像素误差，遮挡处和未拟合小球的三维位置、数目仍属近似。
3. 圆台边缘、地面金属球、霓虹和海报在不同机位仍可见偏差，必须以三源直接叠图判断，不能仅看单机位漂亮渲染。
4. 反光、渐变灯带、透明/镜面小球的材质与直播效果有差异；没有原始PBR贴图。海报使用未经透视校正的来源局部截图，保留了视角烘焙误差，分辨率有限。
5. 演员、表演动作、临时画面、屏幕台标和字幕不是重建对象。未匹配这些内容不说明结构本身通过。

## 检查项目
- 实体网格、退化面、非流形、法线与UV检查。
- 墙顶、墙脚、折角与底板后缘密集射线检查；全部源于锁定文件重新计算。
- 面光的完整发光面与结构交线检查，而不只检查灯中心点。
- 实际将GLB重新导入Blender，比较对象数、世界顶点和内嵌图像。
- 三个来源机位分别给出原图、材质、白模和50%直接叠图。
- 九个普通检查视角，包括外侧、背面、顶面、底面；另有显式几何剖切。
