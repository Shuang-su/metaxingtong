可见构件：奶油色八角大理石地面与深色菱形嵌块、两侧凹槽柱及柱脚/柱头、蓝色夜景窗、中央拱形窗、宴会甜品桌、层叠蛋糕、花束、礼盒、气球、壁烛灯。
人物、字幕、播放器 UI、水印不属于模型。前半段花园/入口不混入本厅。

不确定部分
相对尺度按桌与建筑常见比例推定，使用名义米制，不能用于施工或测量。
柱列数量、间距、墙体向镜外延伸的长度、柱后遮挡部分、桌上小物数量和细节为近似。
夜景采用蓝色材质与几何亮点，没有把参考截图当作房间平面。窗外真实环境未恢复。
柱头雕刻、拱窗装饰、花朵、糕点与缎带为简化几何；没有捏造看不清的文字。
没有添加无证据的后墙、后门和完整天花；因此正常全景或侧视可以看到开口，这是有意保留的可见组件范围。
参考 B 的人物遮挡较大，相机仅手动近似对齐；叠图用于暴露偏差，不代表精确注册。
气球位置和道具摆放可在节目中变化，采用代表性静态布置；不含人物或动画。

交付
Xingtong_Castle_Hall_Textured.blend：可编辑材质版，默认正常水平全景相机。
Xingtong_Castle_Hall_White.blend：完全相同几何与相机的白模；白模使用中性光，便于看结构。
对应的 .glb：真实网格、UV 与 PBR 材质，图片内嵌，适合通用 DCC/查看器。
textures/：原创平铺 BaseColor、Roughness、Normal，不是直播整图投射。
预览包括全景、A/B 参考机位及侧视的材质/白模成对图片。
QA 包含源图/渲染并排、50% 叠图、白/材质对照、实际 GLB 回导验证 JSON。

验证
真实回导比较物体名称、三角面数、双向顶点坐标、边界、表面积与 UV；检查使用图片是否内嵌。
另检查原生白/材质文件和两个回导 GLB 的几何一致性。
镜头、灯光、世界背景和色调映射不作为 GLB 的跨软件外观保证，请以附带 Blender 预览检查当前校准结果。
所有结构和主要道具均为可编辑网格；没有用一张参考照片伪装成立体场景。
这套资产是参考驱动的重建练习，原节目、角色和设计权利归各自权利人。
