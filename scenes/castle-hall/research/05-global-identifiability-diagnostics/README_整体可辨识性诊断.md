# 城堡厅整体比例与相机：可辨识性诊断

状态：本轮诊断关闭；不改整体白模，不作为来源验收。QAr2 模型与冻结清单未改。

## 结论先行

1. 现有宽正面数据不能唯一拆开相机焦距与厅体比例。2713→4509 仅用同后墙灯具26个局部特征，固定主点(590,332)的旋转+变焦模型，在源焦距800、1000、1400、1900、2350px这五个采样值下均能得到约0.37–0.45px中位残差。这不是26个独立深度约束，低误差不能证明柱距、柱高、窗高正确。
2. 新连续片段提供真实多深度运动证据，而非错列/重复地砖造成的假视差。042→049近柱方台角相对拱面点映射的残差26.13px；该角没有参与拱面拟合。它支持运动含平移分量，但未恢复平移向量、米制基线或柱高。
3. 整体改形仍应停止。高区覆盖缺失、窗口焦距不稳定、完整柱列不足，尚不能将现有4509的整体投影残差唯一归为“窗应更高”或“柱应更矮”。本轮没有优化或导出新的几何/相机。
4. 4426仍为独立留出，仅检查覆盖，不抽地标、不拟合、不检验后回流训练。

## 三种运动区别

- 同轴缩放：中心不变时不同深度都服从相同径向倍率；不能仅凭物体变大/变小认定走近/远离。
- 近邻旋转并变焦：理想针孔成像时同一整体点映射可作用于各深度；需要多深度固定点检验，单后墙的小残差不够。
- 真实平移：一般产生与深度相关的残余视差；必须先排除错柱列、重复纹理、动态物体、切镜和追踪漂移。本轮近柱方台角是这类证据，但不是米制测量。

理论依据仅用于解释：[OpenCV官方单应性教程](https://docs.opencv.org/4.12.0/d9/dab/tutorial_homography.html)说明平面场景与绕投影中心旋转都可能产生单应关系；局部单应拟合成功本身不能证明一般三维结构。上述本场诊断数值来自随附脚本，不来自教程。
