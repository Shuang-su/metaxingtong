# 下一阶段：同一厅体的共享白模修正方案

## 顺序
1. **右墙真实拱口与有限可见楼梯**。先把4528/4529/4530源帧中的近柱、中柱、右墙窗、地面交线建立对应关系，确定拱口所在柱跨与尺度区间。不能凭单帧硬填模型Y坐标。统一修改右侧墙网格，开真实通孔，接入有实体厚度的券拱、侧框、门洞回边和有限可见踏面/踢面。楼梯井在看不到的终端和上部可作明确标注的推断围护，使模型保持完整可检查，不把推断段说成已证空间。通往哪里未知，不连接花园。
2. **地面布局**。先用不同深度地砖中心、缝线和柱脚接地约束相机姿态，再确定共享节距、八角切角和菱形尺寸。不能把反光亮带、石纹或阴影变为凸起，也不能只用数个点误差作为全场通过。
3. **后窗细分与柱脚轮廓**。4426.224496/4509.252180可见拱顶图案，1729/2713补下部分格。建立固定实体窗梃/拱顶必要轮廓，来源不能判定真浮雕的细饰留待材质层。柱脚真实外轮廓与接地优先于叶形雕刻。
4. **桌体与陈设**。按真实左右不对称关系整理共享布局，再加桌腿横撑、桌布角部垂落。移动餐车/角色不并入常驻静态陈设。

## 镜头与验证
- 先冻结一份几何，再分别解算/近似匹配1729无人、2713无人、4426宽景、4528右拱口、4529及连续采样中的非重复帧。
- 原图只作固定裁切；禁止参考透视warp、按机位隐藏墙、按机位移动桌子/柱/礼盒。
- 每轮输出同一白模、同机位原始渲染、50%直接叠图；材料/灯光误差与结构残差分表。
- 把最清楚的一帧作为拟合输入，其他实际视角作留出检查。若跨视角无法保持同一几何，回到相机/结构假设，不强行消掉残差。
- 逐区报告拱口/台阶/柱脚/窗/地面/家具状态和遮挡范围；不能“局部误差低=全场通过”。
- 白模结构验证后再做材质贴图；最终默认正常主视角，不用剖切作为主交付。
- 每张图记录模型SHA、相机参数、渲染设置、源码时间和裁切；每次GLB重新导入检查几何与图片可携带性。
