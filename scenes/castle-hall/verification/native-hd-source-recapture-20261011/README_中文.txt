城堡厅 原生1920×1080参考帧

本批为B站正常播放器暂停后，通过浏览器原生“将视频帧另存为…”导出的1920×1080 PNG。原始PNG未做重编码、裁切、放大、AI处理或提亮。
每张保存前后均检查为暂停、readyState=4、解码1920×1080，且currentTime不变；文件尺寸、字节数与SHA256另行核验。
请求参考时刻来自旧记录；实际时刻来自本次暂停状态。正常界面使用整秒跳转后暂停，因此是近邻新帧，不保证与旧图同一帧。source-manifest.json分别记录两者，文件名使用本次实际时刻。
原生保存步骤：
1. 在源BV页面选择1080P，使用播放器时间输入框输入邻近整秒。
2. 等待新画面完成缓冲并暂停，观察场景内容，排除跳转前的旧画面。
3. 只读检查暂停状态、currentTime、readyState和视频原始尺寸。
4. 右击视频；如出现站点自定义菜单，在另一处未遮挡视频区域再右击，打开浏览器原生视频菜单。
5. 选择‘将视频帧另存为…’，保存原始PNG。
6. 再次只读检查时间及媒体状态，核验保存前后不变；检查PNG实际尺寸和SHA256。

分辨率合格不表示新增独立机位，也不代表已覆盖整段或整片视频；人物遮挡、原片光照及内容限制见逐图说明。
