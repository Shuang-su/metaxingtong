原图20:28的L形角度与50:56的正面角度，存在真实观察方向差异，作为两组共享几何约束。70:09和85:33有人画面用于固定电器位置复核，不宣称新增独立基线。视频播放器界面不属于模型；源文件为旧包保留的360p截图，上采样并不增加实际分辨率。
原图可支持L形柜体、玻璃上柜、咖啡机、壶、烤面包机、边缘高柜和独立画框。画面墙上的斜暗区按照明阴影处理，没有造出假斜墙。只有有厚度画框中的画芯采用源截图裁切，房间不是图片板片。

【完整几何与推定部分】
围护为连续实体厚墙，四角通过布尔合并；门窗通过实体布尔差集形成真正通洞，配有贯穿墙厚的洞口及两侧框边。实体地板、天花、踢脚线、固定开启85°门扇、窗台及有厚度玻璃均可转到背面检查。
新增房间边界、门窗位置及尺寸、门扇样式、地板、天花和辅助照明没有直接源图证据，均是为了形成可用完整房间的合理推定，不称实测或已证实原貌。门洞通向模型外，没有声称其后是某个视频房间。
本版净空间约5.4×5.6，高3.25模型单位；墙厚0.18，地板及天花厚0.16。Blender单位为无单位。台面高约0.923、主台面宽3.68是继承的相对比例，不能解读成测量所得米数。使用者可按自己的尺度基准整体缩放。
保留既有柜体比例和物件位置，仅将咖啡机、壶、烤面包机与高柜分别整体下移约0.0015–0.005单位，使底部接触其支撑面。上柜固定于墙，非落地家具。
修复旧模型回转体重合极点、退化面、管件端部开边；画芯增加真实薄厚度。杯碗保留其内外回转表面，未用平板替换。403个网格逐项检查无开放边、无非流形边、无零面积面。

【统一场景与机位】
完整材质版与白模版共享同一几何。所有正常视角、源图对应视角、外部背面和GLB使用固定完整场景；切相机时不移动物件，不隐藏墙，不做图片形变。白模仅替换材质，玻璃保留透光。
原先长焦参考机位约72/73.1mm，位置超出本版围护。因此保留原始相机参数在相机自定义属性中，另将两参考机位重拟合到房间内部。只调整相机参数，不针对单个视角改物体。外观不承诺逐像素复刻。
qa/Reference_Residuals.json记录11个旧源图近似结构锚点的重新投影，最大约21像素（1188×668源图裁切基准）；这不是全场景误差界限，更不是尺寸精度。角度差异、低清图、被遮挡边线、局部投影和照明仍有不确定性。重拟合对柜侧可见量、透视深度和阴影可能产生可见变化。
references保留完整原截图；裁切主要去除外围播放器栏；残余关注图标、水印及进度条不计入拟合。qa/Source_Comparison分别给出源图/材质/白模；Overlay50为统一尺寸下50%叠图，无非线性变形。
正常视角01–08都是普通透视检查，约25–28mm，主要观察高度1.6模型单位；09是模型外部背面。完整天花和墙会正常遮挡外部视线，没有为外视角隐藏它们。
