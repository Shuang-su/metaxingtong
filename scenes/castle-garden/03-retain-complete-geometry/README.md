## 空间理解和本次真实变更
- 保留开放花园、有限城堡入口立面，不增设屋顶、外围围墙、虚构城堡厅连接。
- 原薄基础改为有底面和四边的有限承重板，覆盖立面底部；有限截止处明确可见。
- 门、窗从零厚面变为向后 0.20 单位的实体；有限立面布尔切出三个对应尖拱真洞口，保留墙厚回边、关闭门扇和玻璃背面。背面可见门窗，不再是完整实墙遮挡门窗。洞口背后保持开放，不杜撰任何室内。
- 源图可见门前浅阶；添加三级踏步衔接道路和门槛。级数、厚度和隐藏部分属比例推定。
- 侧栏增加连续承托基座；栏杆杆件和装饰管件封口；花盆增加封闭底部、内壁和凹入盆底，保留盆口凹腔。
- 花床后缘增加挡土收边；花架添加埋入式柱脚。未将画面暗影误做任意墙体。
- 独立射线检查后，统一修正54根栏杆顶、6个盆底、门窗石框、柱边饰、窗台、窗梃与门饰悬空；仅向承托方向伸长，保持正面轮廓。
- 所有非植物实体统一法线并检查退化面、开口边和体积符号；独立世界空间三角交叠检查确认186非植物实体构成一个连通分量。
- 叶片、花瓣依然是可编辑双面薄片，这是合理植被表示；不宣称植物叶片本身是封闭实体。植物可从反面看到，GLB 材质保留双面。
