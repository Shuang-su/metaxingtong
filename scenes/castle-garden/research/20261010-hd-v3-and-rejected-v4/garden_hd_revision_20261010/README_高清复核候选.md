## 相机诊断与验收边界

v1尖V花架、v2过倾斜HD相机均没有作为最终来源验收通过。独立窗竖边检验发现v2在约200像素高的竖线上预测横移22—26像素，而源图近乎竖直，因此不能使用其低稀疏误差支持更多改模。

最终v3把三根来源窗竖边方向纳入约束，采用Blender真实相机shift_y得到一组可行诊断，不对源图或模型图做图像扭曲。解析投影与Blender实际投影的最大差约0.00018像素。

重要：这不是已恢复原机位。三个主点推定为画芯y≈−30、4.5、135；前两图接近/超出画芯上缘，没有来源相机或裁切元数据支持。它们只用来说明“存在怎样的相机假设”，不能证明全场共同标定通过。HD渲染、叠图、sidecar均标明这个限制；正常水平主图使用普通零shift相机。

三图留出点RMS约12.9 / 15.4 / 27.7像素；独立右窗外竖边还存在约3—19像素位置残差。第三图门底水平端点差约7.5像素。方向更接近并不等于位置、数量、遮挡或整体几何已通过。来源人物、动态植物与播放器遮挡始终保留，不填补缺失证据。

窗上雕花、门板浮雕、盆体造型、栏杆金饰、花叶密度/姿态、铺地纹理及夜景照明仍显著简化。旧360p两张图沿用原相机，仅作共享修改回归，不冒充新精确标定。所有初期试算保留为诊断历史；没有覆盖既有正式交付。
