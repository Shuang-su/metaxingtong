## 实际查看深度后的有限观察

已逐张打开两份1920对齐深度（并非只看文件存在）：

### 2560斜视
人物轮廓比后方柜体明亮，脚前地面更亮；柜体大面、踏台前伸的大轮廓与右墙可分辨，整体前后层次有辅助参考价值。模型没有把屏幕云景或踏台发光箭头明显完整雕成立体物件，这一点在本图里比直接按亮度解释深度合理。

但踏台/地面均为高反射区，地面成大范围平滑梯度；鞋底与地面的过渡、台面厚度和柜底间隙已被平滑，**不能据此确认接触、悬空或厚度**。右墙灰度变化也不能用来恢复真实墙角/坡度。人物轮廓与细部有模糊，不用人物定标或复原身体。

### 2522低视角
前景人物比柜面亮，左侧claw机玻璃区域呈后退层次，机柜大面有可见分层。屏幕星形画面大部分归入连续面，而非将所有发光星线当实体深度。

人物手臂运动模糊、头发/衣摆、玻璃内玩偶/反射边界仍不可靠；模型的平滑大片结果不能证明玻璃内结构位置。人物遮挡后的海报、柜体、场外顶端均未知。屏幕左右亮度/灰度不可拿来判柜体间距或跨图深度比例。

`diagnostic_patch_values.json`仅记录选定图块的原值/每图归一化中位数，帮助复核上述现象。例如2560人物躯干约0.519、柜下前面约0.223、右后墙约0.126；2522人物头约0.721、柜下前面约0.411。**这些是模型输出，不是距离、误差或置信分数；不同图归一化不可相互比较。** 带warning名称的图块更不能成为可靠建模锚点。

## 使用结论

真实可用：来源大物件前后层次的辅助审阅与发现需排除区域；可与人工证据表并列，不可替代原生图。

真实不可用：米制尺寸、踏台W/D/G唯一解、相机标定、鞋/台/柜接触、物件背面与缺失海报、跨图统一距离，以及验收置信度。本批只有深度诊断产物，不产生新的3D几何，不以灰度冒充测量或完成验收。
