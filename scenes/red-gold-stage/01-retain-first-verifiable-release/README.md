证据及限制
- 有效来源帧：2416.456244秒彩色正面较宽；4217.039866秒彩色人物近景（菜单遮挡）；1220.755497秒黑白无人插播。

- 后续1080尝试能显示1920×1080解码尺寸，但跳转后readyState=1且画面滞留旧近景；未当作有效新来源、未伪造时间归属。
- 没有已证实独立左右相机基线。近景是同轴变化，不能当成多视标定。
- 黑白插播只辅助无人遮挡形体判断，不认为是同一灯光状态。
- 绝对尺度、舞台进深、背面/上缘/地面边界、灯泡准确数量、星饰未见尖角均为推定。模型单位米只是工作比例，未从来源证明。
- 没有找到本场旧发布模型；此包是第一个可核实建模版本，不伪造历史版本或历史对比。

文件使用
models/ 含材质版与白模版 BLEND / GLB。两版顶点坐标完全一致。GLB内嵌红漆微闪纹理，可脱离原目录打开。
灯泡为实体发光材质，不是穿过构件的发光平面。GLB不含Blender拍摄灯，查看器的曝光/环境会改变外观。
所有普通视图使用同一固定几何；没有因相机移动隐藏墙面、移灯或改变几何。明确剖切图只用于诊断，不作为交付完整模型。
三段候选台阶/台基实体由级差表达，精确踏步数量受低清源限制；金色鼻口是饰条/高光，不另算台阶。未将每道亮线误建成一级。

检验
qa/geometry_validation.json：闭合拓扑、退化面、法线、UV、密集接缝射线、灯泡装配接触、材质与白模真实GLB回导数据。
qa/ 中保留真实回导BLEND与单独剖切诊断模型（若在检查包中）。
注意：每件是闭合实体并可装配相接；部分构件有必要的安装嵌入/交叠，不是整体布尔成一块，也不是结构承载认证。
源图比对为原比例、同尺寸50%直接叠图，不做非均匀缩放/透视扭曲。人物未重建，遮挡区域不属于已观测细节。

独立几何复核：independent/geometry_checks.json。234颗全部灯泡前半球无结构侵入且背极都有实体支持；279件真实装配单连通；限定目标射线7,904条无漏。

图像处理：来源图未降噪/变形；QA直接叠图用原始渲染。单张浏览JPG仅对渲染使用OIDN降噪，保留相机与几何不变。

普通检查视角按全模型包围盒后退取景；底面用额外诊断补光，几何保持不变。剖切单独明确标注，不作为原完整模型。
