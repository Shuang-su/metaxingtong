# 列车 r06：单桌端部轮廓诊断候选

实际复核日期：2026-10-11 UTC。基线为 PR28 远端固定提交 7e28aa2e7c9bc900f59deca964d321f76294913e；恢复的 r05C 材质 BLEND SHA256 为 59f2cdfeb41d0aa7fd6c580b4233937a89f7a4b74e2a8fa85343acfc84f3a7ac。已读取本次 main 的重建规范。

## 结果与状态

本候选只测试一个已定位模型实例的桌端轮廓。不是已经确认的来源修正版，未替换 r03 CURRENT，未改写 r05C，来源仍待核。没有证据将 A/B/doorwide 三张图的桌子强认成同一绝对 bay。

1. **桌板端部，证据最强的形状问题。** 原生 A2（843.863376）、B2（925.690233）、doorwide（3593.084047）各自可见桌板有长直线端边和较小角部过渡。r05C 的 12 张桌板网格实际都采用半圆端，半径 0.36 模型单位。本次仅把 T-L-01（对象 `Booth -1 1 rounded wood table`，模型左侧 x<0、中心 y=-2.7）做小圆角矩形端部试验。具体原始像素标点、裁图和邻接关系在 object_evidence.json。半圆→直边的方向有来源依据；准确圆角半径、绝对 bay、支撑背面均未确认。
2. **座背冠线，下一项候选。** A2 前景绿色座背、B2 人物后方大座背能见柔软圆角及竖向分段造成的轻微冠线起伏；r05C 对应类座背偏平直、层状硬边明显。局部材质反光也会放大差异，不能把每条明暗边当成实体。本次未改变座背，先需要将模型 front/back 高背组件和真实朝向对应，避免把座背背面误当正面。
3. **行李架、近 bay、J 前景仍未知。** 行李架断面/焦距的旧耦合没有解决，D 近排可能误配一排；原生 empty-window 的前景灰物及黑把手不命名为桌。上述项目均不据新截图直接改几何。

## 单件变更范围

只改 T-L-01 原网格顶点坐标，拓扑、法线平滑设置、UV 数据、材质、物体变换不变。桌端改为直端边，试验圆角半径 0.025 模型单位；这是推断值，不是实测。厚度仍约 0.05，原 x/y/z 外包围范围保留，12 桌仍在位；没有隐藏桌、花瓶或其他物件，没有随相机切换几何。原支撑、与墙和座位的位置沿用基线且未被来源重新证实。新的角部填充仍在原包围盒内，走道最窄边界未外扩。

## 相机、来源与状态

A2/B2/D2 是旧参考的近邻新原生帧。此轮保留 R05_HD_A、R05_HD_B、R05_HD_D 和 R05_J_LOCAL_UNRESOLVED_BAY 的历史矩阵、焦距、灯光与材料，分别重渲染旧/新共享场景。直接 50% 叠图在 1920×1080 像素格上进行，不做配准、warp、局部拉伸或按镜头改物。

**这些相机尚未针对新原生帧重新标定，所以新原生叠图是条件性诊断，不是严格同机位来源验收。** 不把旧截图与新帧标为同一帧；不把相同型号或位置近似当成同实例证明。doorwide 与 side-rows 的原生图在逐物件观察中实际使用，但未伪造已标定相机或同机位叠图。J 来源绝对侧别和 bay 保持未解。

场景内所有镜头使用同一模型、照明和材质，无相机驱动状态开关。视频中的人物、文字、运动窗外等仍保留在来源原图里，不删除；不把动态遮挡的残差算成硬几何误差。八张 INSPECT 图是任意结构检查角度，不是新增来源基线。

## 几何、材质和导出核验

geometry_regression.json 核对旧/新 1989 对象：1937 个网格中仅一张桌的顶点哈希改变，所有物体变换、拓扑、材质分配、相机、灯光及可见性不变。单桌网格非流形边=0，零面积面=0，有符号体积为正。导出及真实 GLB 重导入记录见 glb_reimport_verification.json；不把技术核验等同于来源接受。

材质贴图保持原字节、原节点和原 UV。端部改型使原 UV 的物理拉伸量改变，因此“UV 未损坏”不代表木纹比例已验收。没有为本候选修改材料或纹理去掩盖形状问题。性能以模型数量/三角数、文件大小记录，不冒称运行时帧率测试。
