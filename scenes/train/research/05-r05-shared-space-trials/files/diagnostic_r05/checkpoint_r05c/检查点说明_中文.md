# r05C 共享比例改进检查点（来源尚未验收）

此检查点保留 r03 完整房间，在共享窗比例、灯位置/长度、货架截面和横档位置上作有源试验。它不覆盖已交付 r03，也不更新 Library/CURRENT。整车长宽、bay 间距、座椅和桌尺寸未改变。尺寸是工作单位，非实测。

## 成立的局部改善与限制

J 空窗支持较宽矮的窗口比例，但侧别、绝对 bay、真实焦距/距离仍未唯一确定。焦距18–36mm下比例约1.912–1.918稳定，货架检查投影却相差约52原始像素，不能把24mm下较小残差当作独立确认货架。

J 横档和短灯已用于修正，不再计作留出；A/D灯长度提供跨图留出支持。全场来源匹配仍不通过：座背厚顶/完整左右遮挡、窗帘收束与褶皱、顶棚设备轮廓与节奏等仍有残差。J 前景带提手灰矩形面的实体身份未定，未新增或移动桌子。

## 文件语义

- material_candidate BLEND：与已审阅 C 冻结输入完全同字节，SHA以59f2cdfeb41d开头，贴图内嵌。历史Version属性可能沿袭旧制作阶段；以Candidate_status和checkpoint_manifest为本检查点状态。
- white_candidate BLEND：相同网格世界坐标、拓扑、UV；仅白色材质、灯色及检查用曝光改变，玻璃保持。几何拓扑UV hash与材质版完全一致。
- 两个GLB：原始Blender导出，已实际回导检查；没有减面、量化或压缩重封装。材质GLB内层文件18,064,800B，实际发送ZIP小于18MB。
- 当前贴图：所有19张实际冻结BLEND引用的图像与材质引用侧录；GLB19图资源与r03对应嵌入字节一致，本阶段未改纹理。颜色不因几何QA而自动通过来源验收。
- 正常主图是完整房间模型检查机位，并非一个声称精确匹配的来源镜头。

## 结构与回导检查

1937网格、175000顶点、174406面。闭合/非流形/退化/法线朝向检查、12窗采样、四面围护、顶棚和36支撑链通过。材质与白模实际GLB回导各1937网格，双向最大顶点差约7.64e-7工作单位，全部三角形计数与UV存在性一致，无非贴图颜色因子不一致。UV在1e-4比较精度下1937对象一致。

法线保留一个继承性例外：两端圆角门窗框在GLB实际回导后各出现4个零长度corner normal（源BLEND为0个），角度检查累计4个唯一法线90度指标；与r03同名同类例外相同，不写成全部法线逐值一致。详见normal_exception_detail与normal_angle_roundtrip。它不改变本阶段来源未验收的状态。

完整来源对照与独立报告见配套诊断包。文件SHA及输入关系见checkpoint_manifest。所有渲染均固定共享模型，无逐机位移动/隐藏/替换家具或图像warp。
