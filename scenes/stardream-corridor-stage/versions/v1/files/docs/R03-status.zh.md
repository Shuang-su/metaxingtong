# R03 地面程序贴图候选

在R02几何/相机/灯不变的基础上，增加明确的程序合成石纹颜色、粗糙度、切线法线1024×1024 PNG。固定seed8052024，未采样来源图，不是石纹原材质恢复，也不是深度图。地面UV按每面主轴二维投影、每2工作单位重复，仅UV变化不改顶点。材质BLEND packed并保留外部PNG，GLB纹理嵌入是否完整仍待独立读回。

同几何白模仍唯一WHITE_clay，不连接石纹；来源墙/灯/相机失败不因此解决。独立QA刚发现R01/R02 ONAIR_text的860条非流形边；本版保留同几何，因此仍有该失败，后续另版修正，不能称完整单体闭合。普通石纹候选不掩盖来源不匹配。
