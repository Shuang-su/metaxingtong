# 走廊 R06 顶格黑块独立诊断

结论：至少CHECK_05下方交点的黑块有强受控证据来自共面重叠几何所致的渲染伪影，不是该处真实开孔，也不能归因于仅32samples不足。未精确区分Cycles内部射线自相交/表面选择/阴影计算的具体环节，不泛称所有暗部原因相同。

## 几何定位
实际打开原白模型SHA256 3b97dcdabf0dcaa0891b72417e7a8aadd4a0b0f7eca80396ab33a1138eb4fee6。6根crossrail与center_rail的厚度、上下平面完全同高：z3.680000066757202至3.799999952316284。交叠x范围±0.06499999761581421，各横梁y厚约.1，存在有限重叠体积及两套共面底面。不是只有邻接的零面积线。
CHECK_05可见crossrail_4与_5交点底面中心投影分别(596,29.3656)、(596,255.7535)，正对应原图两个黑块。其他交点不在此图有效范围，不拿离画投影算可见验证。

## 最小受控测试
仅独立目录写图，原文件未保存/未编辑。实际加载R06白模，相同CHECK_05、灯、材质、1192×671原分辨率、不降噪、1CPU，只渲x[560,630]及目标y[220,280]ROI，Blender边界取整得到70×59 PNG。
1. 原几何32samples：黑块复现，全RGB≤2有91像素，固定中心子块平均0.4。
2. 原几何128samples：黑块仍在，全RGB≤2有85像素，同子块平均0.4。增加采样并不消除结构化黑块。
3. 仅内存center_rail沿世界Z下移.001，32samples：黑块消失，全RGB≤2为0，同子块平均101.176。该诊断改变几何，不作为成品修正或来源改善；只能隔离共面重叠因素。
三图均实际查看。原图正常噪声与周围阴影仍在，不能把它们全部归为同一种缺陷。测试后再次回读原blend SHA相同。

## 建议与边界
最小结构候选可将横梁拆为左右有限实体，由既有center_rail填中间区域，保留外部占据与外边界，消除重复共面外表面；不必以全中心梁改变高度来回避。
后继必须检查：切分后占据是否等价、左右端面与center的共面接口是否仍出现伪影、接缝/孔洞、材白/GLB及至少相同ROI。拆分多个闭合分量不是Boolean焊合，也不是全房无缝证明。当前未制作该候选，未改原R06、没有全套重渲或来源验收。

证据：geometry.json、pixel-check.json、baseline.png、baseline_128.png、center_down_001.png、check_and_render.py、check_samples.py及两日志。
