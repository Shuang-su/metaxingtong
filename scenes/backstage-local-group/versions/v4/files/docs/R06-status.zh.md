# R06 有限服装人台代理，来源仍未验收

这不是新场或完整后台房间。在此前已归档局部组之上，依据011/012报道图右侧可见的无发金属头颈、金属臂片、红上衣、黑腰带与分叉红下装，补了16个有限道具mesh。两图同物线索强，但无连续桥、原生解码或相机标定；源图1192×671，片内时刻未知。前景白发角色没有建成环境道具。

旧215mesh保持，新总231mesh；新增一个MANNEQUIN_local人工诊断相机，旧4机位/灯光/World不变。头面不刻画无法辨认的五官；分叉下装只作裤裙/阔腿类别代理，不断言衣版。深度、背部、关节与袖型、相对衣架位置及工作尺度均推断。没有补不可见脚、脚架、地板、墙或天花；人台下部支承未知，不宣称稳定站立。

R05新增物原件与两图完整保留，实际暴露裤顶平帽/硬阶突出。R06仅收窄两个下装mesh各24个顶部顶点XY，Z、下方三环、拓扑索引及其余物件不变，目的为把有限帽面接入上衣代理遮蔽区，不是根据像素精确拟合真实腰臀。当前材白同机位实看不再见该硬阶，但衣服仍十分粗化，头颈与袖型、整体比例/摆位均未按来源验收。

本轮R05/R06各材白一图，共4张1192×671、64采样、无去噪图，只有一个人工诊断方向。两张同原像素裁切前后对照没有缩放或修图。没有伪造来源机位、直接50%叠图或八有效来源角；既有局部组视角不自动验证新增人台背面。模型技术检查只能说明限定网格属性，不是来源或服装重建验收。

原件models/R06_*，旧R05_*保留；scripts/add_mannequin_r05.py与refine_mannequin_r06.py记录全部几何假说；图renders/R05、R06及R06-comparisons。无新增贴图依赖。尚需独立QA收口及Space/远端Git原件回读，本报告本身不证明已交付。
