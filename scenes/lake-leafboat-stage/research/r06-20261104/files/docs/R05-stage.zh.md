# R05：仅修复第一对越界支脉
R04的原尺寸近斜实看发现第一对二级支脉终点u=-1.02超出叶壳域，形成无来源依据的外露细刺。R05只将这两个闭合分支的参数终点约束到u=-0.96。实际世界几何hash比较确认1370个网格中只有这两个改变，其余1368个逐一相同，壳/岸/材质/照明/相机不改。中心线域测试全部-1<u<1、|v|<1，两支均闭合无退化。

以3840×2160原采样网格渲染ROI[250,600,900,1300]，输出650×700，不做放大或改角度。实际16 samples、2 CPU、无降噪；与同ROI的R04失败图并看，细刺消失。PNG和渲染参数保留在qa/r05。技术核验重复完成材白一致/GLB真正重导/壳射线。标准GLB的俯视shift限制仍存在，sidecar恢复后实际13/13投影矩阵通过1e-4阈值。
