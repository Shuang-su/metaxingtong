# 叶舟VD2追加回归：独立短审查

2026-11-04 UTC。本报告是新增followup，不替换或修改旧VD2验收范围。

已读取check_tube_regressions.py和tube-regression-results.json，独立汇总记录：19管非共顶点三角自交前后0；153支脉对象对中9对有交叉，共225三角相交对，前后集合无新增/移除。最大环中心折线段方向变化1.063120545度、弯折差1.301526697度；段长比范围0.9832144956–1.0032683772。脚本统计与结果一致。

疑点验证：实际在本机Blender4.3.2单线程建立两个不共顶点且交叉的三角面，测试同一个BVHTree对象overlap自身，并与独立构造的同几何BVHTree对照。两者都返回[(1,0),(0,1)]，说明同树查询并非恒空；原结果零自交不能仅因同树API而被否定。夹具脚本为test_bvh_self.py，结果详见regression-self-bvh-fixture.json。本轮没有重新执行整套管几何回归或修改生产模型。

局限：排除任一共享顶点的三角对，因此相邻面折叠仍未验。float32 BVH候选加float64距离阈值1e-9不是精确算术证明。三角相交pair集合不变不代表穿插深度或接触面积不变。中心线角度来自各环顶点平均点组成的折线，不是连续管曲率或来源误差。中心脉-支脉有意接合在本轮范围外，不能用此新增报告声称所有对象碰撞已检完。

结论：支持已列有限回归统计，不升级为生产原件恢复、源吻合或完整几何验收。
