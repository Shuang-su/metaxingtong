# VD2 管线回归补充：只读，不改模型

以 VD2 相同两个 BLEND 为输入，检查 19 管的非共顶点三角面自交、153 个不同分支组合的相交，以及离散环中线的方向、弯折与段长。既不重建也不修改模型。

实际结果：
- 修改前后 19 管的非共顶点三角自交对均为 0。
- 153 个分支组合中，9 对左右同根分支共 225 个相交三角对，修改前后完全相同，无新增或移除。这些同根相交并非本轮修复或移除的缺陷。
- 对应中线段方向最大变化 1.0631205 度。相邻段转角的最大变化 1.3015267 度。段长比范围 0.98321450–1.00326838。
- 候选原报告记录的各管带符号体积比为 0.99772203–1.00055187。虽然横截面点对距离近似保留，环间方向、长度和总体积并非全不变。

限制：共享顶点的同管三角对被排除，因此不检验相邻面折叠或它们超出公共顶点的重叠；主脉-分支的预期接合不在本轮 153 对中。BVH 候选与 1e-9 距离容差有数值边界。不是全场碰撞证明、来源验收或生产原件测试。原 VD2 二进制原封不动。

## 可复现性与补充边界

本目录 portable 脚本在相同两份 BLEND 上实际重跑；结果除运行时间戳外，与 `first-execution/` 原次运行 JSON 的全部字段完全相同。首次运行脚本和原日志均保留。原 VD2 冻结的 44 个文件逐个 SHA-256 不变，只有本 `followup/` 新增内容。

相交三角对集合不变，不代表穿插深度或接触面积不变。所报角度是截面环顶点均值形成的折线统计，不是连续曲率、源图拟合误差或制造公差。
