# 叶舟20体非精确重放：接合诊断只读审查

本轮审查脚本/JSON并实际查看前后两张局部图，运行三角距离单元测试及补充共顶点、共面边交叉、1e-6平行间隙测试；未重跑整个Blender几何试验，也未验证生产R06原件。输出仅限方法和现有证据审查。

三角距离包含点-面、边-边及边穿面，能覆盖非退化三角面之间的连续距离。以选定三角中心半径r和顶点到目标面的距离上界u，检索距离中心≤r+u的目标三角，排除界按三角不等式成立。但BVH检索为float32，添加1e-5 margin并不构成严格精确算术保证；内部float64也有固定相交容差/近退化阈值。避免称数学精确全场证明。

JSON记载19段选定末端面的整体最小距离全部为0，18支脉起段与主脉最小距离为0。这只证明每组至少有接触/交叠位置，不是每个末端三角或整环连续贴合，不是Boolean焊合。

451个移动环的选定最低采样点，整壳solid-angle winding与1之差最大约4e-15，五向parity为inside。三次1e-6步进失败均清楚记录同一triangle再次命中，改1e-5后的单次命中配合不同方法winding给出合理纠正，而非删失败。此证明只覆盖451点；不能推成整环完全inside、所有环间表面无交叉，或真实壳面最大嵌入≤.0005。该数值是采样参数目标，不是连续整体上界。

完整管-壳相交中法线z<-.01面无新增交叉，可按原判据报告；它不覆盖近竖直面、上向面、管自身/管间新穿插，也不等价“全底面无穿出”。建议保留这些未测项，而非为当前增量扩展成新验收。

两张相同局部机位前后图实际显示支脉下方浮离间隙缩小，后图呈贴壳状态。单视角、局部噪点与遮挡不能证明19管全部接合，更不是来源吻合。只移动环Z还可能改变环间斜率/弯折与全局投影，应以已记录projection_deltas保留变化，不以XY/每环半径不变声称整管形态不变。

结论：可归档为非精确重放上的有限技术接合候选，方法/证据支持局部改进，边界必须保留。不是生产原件恢复、源真实叶脉、完整碰撞或来源验收。
