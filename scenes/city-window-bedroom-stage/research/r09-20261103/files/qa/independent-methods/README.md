# Independent reviewer method snapshots

These are the exact read-only QA scripts used by the independent local worker, copied without rewriting the evidence. They retain the original absolute execution paths for the production checkout and separate review output directory. To rerun elsewhere, explicitly change those two path constants to your local checkout/output directory; do not mistake those historical absolute strings for packaged external dependencies. Blender scripts need Blender 4.3.2; the geometry nearest-point comparison uses the recorded local Python environment. Image integrity uses Pillow/NumPy. The input model bytes were not modified by the reviewer. Diagnostic GLB welding happens only in memory.

The corresponding JSON records identify exact model SHA256s. The final-image script is a full-array formula/hash check, not geometric acceptance. Shell-ray and manual projection samples are finite hypotheses, not proof of all-room topology or source alignment.
