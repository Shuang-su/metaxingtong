# KTV 历史可见性回归核验

状态：技术回归证据；来源还原验收仍未通过。没有创建新的几何版本，也没有修改 CURRENT、原模型、原渲染脚本或历史图片。

## 核心结论

1. 历史违例真实存在，但不在当前版本继续发生。旧 `finalize.py` 第34行将两个集合的 `hide_render` 绑定到每张图的 `empty` 参数。第45行的 `Final_Textured_Empty_Stage`、`Final_Textured_Telescope_Detail` 传入 True；第60行白模 Empty_Stage 也传入 True。旧 `build_ktv.py` 第304行同样在D图之前隐藏这两个集合。共涉及18个沙发网格与7个黄色星伙伴网格。旧A/B/全景保留它们，因此不能将旧图组作为单一固定可见性状态的多角度证明。
2. 旧 .blend 文件本体保存的默认状态也没有按相机隐藏；问题来自渲染脚本中的临时切换。当前完整舞台的 `render_export.py` 与 `exact_aspect_matches.py` 没有这种逐相机开关。相机历史名称中的 `empty` 或 `no_sofas` 不是当前实际可见性的描述。
3. 本轮只读实测当前材质版与白版：18个相机下，382个场景网格的几何指纹和可见性指纹均不变，材质版与白版的几何及可见性也一致。沙发与黄色伙伴始终保留。10个气球狗网格在所有相机中始终隐藏，作为独立动态道具处理；这个固定选择不表示与全部源帧一致。
4. 现有 GLB 在新建空场景中真实回导：372个核心网格、135756个三角形，名称和三角数一致；最大双向世界坐标顶点距离约5.63×10⁻⁷ Blender单位。两个推定无贴图结构（连续底台与坡道）回导前后均无UV，不是这次导入丢失。该结果只验证现有导出几何，不证明来源忠实度。

## 来源与时间状态必须分开

来源：https://www.bilibili.com/video/BV1ru41147sn/

保留的源裁图均为1188×668。实际视频解码分辨率、当时登录状态和独立相机平移基线均未证实。本轮没有操作浏览器，没有新增视频观看范围或采集记录。

- A，01:15:29：两张沙发可见，人物站立，部分遮挡左侧家具。遮挡并不意味着该处家具不存在。
- B，00:35:17：两张沙发可见，人物坐下；黄色星伙伴的呈现朝向与A不同，红色气球狗在右上方出现。
- D，01:58:39：人物、沙发与黄色星伙伴未见，右侧低处有红色气球狗。这是“不同时间的空场候选状态”。仅凭三张孤立帧以及未完成标定的D相机，尚不能最终区分家具撤场/搬移与机位取景影响。因此不强制把A/B/D作为同一个静态家具布局的三视图验收。
- 黄色星伙伴和红色气球狗在历史来源清单中被明确列为非固定道具；当前三帧也有不同朝向/屏幕位置。这里区分“源帧可见的变化”与“历史说明记载的持续运动”，没有声称本轮重新观看了其动画。
- 灯、望远镜、悬挂银星、棋盘及蓝带可作候选静态锚点，但其刚性、标定和场景身份仍需连续来源核实。城市目前是简化几何，无法据此确认其原本为真实远景或屏幕。

## 本轮图片如何使用

每个新渲染：Blender 4.3.2，CPU，2线程，48 samples，固定 seed=20261010，1188×668；按共享渲染锁逐图执行，图与图之间释放锁。原始PNG保留；另附 OIDN 2.5.1、2线程的LDR/sRGB去噪版本及其SHA。

两个相机均生成：旧模型历史隐藏逻辑重演、旧模型固定可见性、当前模型固定可见性、当前白模固定可见性。

- “旧隐藏 / 旧固定”控制图使用相同旧模型、相机、采样和灯光，只有两个集合的可见性不同，能够隔离这项历史问题。
- “旧模型 / 当前模型”之间还存在已经归档的结构和灯光变化，不能把它们的所有像素差异归因于可见性。
- Empty_Stage对应D的近似相机。附D原图与4种模型状态的直接50%叠图；所有图为相同1188×668，无裁切、透视变形、遮罩或局部修补。差异保留，不以旧空图更接近D就宣称单一完整模型还原通过。
- Telescope_Detail统一可见性后，沙发边缘进入右下角，望远镜主体仍可见。黄色伙伴维持开启，但全部顶点投影的归一化横坐标为1.236–1.376，均在画面右侧之外（画内横坐标为0–1）。这是真实取景裁出，不是隐藏，也不是用人物遮罩代替家具。详见 furniture_camera_projection.json。
- Telescope_Detail是脚本合成的斜侧诊断相机。未保留能够对应它的源机位截图，因此只提供旧/新模型的技术回归和渲染间50%叠图。绝不将D源图变形拼成所谓Detail源证，也不将该相机计作新增来源角度。
- 白版仍使用已归档白版的材质/光色配置，和材质版是同几何、同可见性；不声称两者光色也完全一致。
- 旧历史成品图原样保留，其采样/去噪与本轮控制图不同，所以不是像素级重演一致性的承诺。

## 实测显示差异

D相机恢复统一可见性后，两张沙发占据画面下部，左沙发遮住望远镜三脚架下段，黄色星伙伴回到右沙发上。旧空图能展示整支三脚架，确实依赖隐藏25个网格。当前固定渲染如实保留这些与D原帧的差异。Detail则只在右下角增加沙发边缘；望远镜主体仍可见。

8张叠图（4张来源叠图、4张渲染间叠图）均重新用精确50%混合逐像素核验，差异像素数为0。

## 进一步来源工作的合理边界

本轮足以核实并补齐“历史渲染图可见性不一致”的技术证据，不需要为此制造新几何版本。要继续提高来源忠实度，仍需经批准采集有登录状态和实际解码尺寸记录的连续高清片段：优先找到有沙发→空场的切换经过，再分别确定布置状态和相机；新增真实望远镜侧向来源后，才能测试该方向的还原程度。同轴缩放不计独立基线，跨BV同场身份仍未核验。

所有技术结果与来源验收分开记录。旧模型、CURRENT与历史图片均保留；GitHub及Issue写入由归档线程统一完成。

## 文件说明

- audit/：冻结输入SHA、Issue9快照、源码行证据、各相机几何/可见性指纹、源时间状态分类。
- references/：三个原始源裁图，不变形。
- renders/：新生成的原始PNG及去噪副本。
- comparisons/：原帧/模型直接叠图与标注比较板。渲染间叠图以 render_only 明确标识。
- qa/：每图相机/输入/分辨率/采样/可见性元数据、去噪记录、真实GLB回导与像素变化诊断。
- scripts/：本轮可复核脚本；历史脚本仅在audit下作为原样证据，不直接执行。

像素变化量只描述显示开关导致的图像变化，包括遮挡、阴影、反射、随机采样和去噪响应。它不是对象分割面积，更不是来源还原精度。
