### 沙发：同一KTV舞台的时间布置变化

在本轮自然1倍播放的连续片段中，人物先从沙发上站起，镜头拉远。拉远之后，两张沙发仍清楚处在画面内，随后两张沙发同时不再显示；黄色星伙伴、人物、灯、望远镜、悬星、棋盘和城市布景继续保留。

- 最后有沙发样本：6626.597822秒，即01:50:26.598。
- 首个无沙发样本：6627.319120秒，即01:50:27.319。
- 因此按截图前读数标记，只能将变化限定在[6626.598, 6627.319]秒的采样区间，不能宣称获得精确消失帧。截图过程本身也有时长：最后有图的前/后读数为6626.597822/6626.686632，首次无图为6627.319120/6627.396357秒。若把截图时长也计入，保守包络为[6626.597822, 6627.396357]秒；这不是视频帧PTS测量。
- 这不是人物遮住沙发，也不是拉远后被裁出画面。沙发消失后，原处地板与后侧设备区域被显露。
- 这段没有转入另一处布景或无关CG的视觉迹象。它支持“同一KTV场景中的有沙发/无沙发布置状态”。没有看到搬运；不推断后台显隐开关、移位过程或剪辑制作方法，也不把采样之间未保存的帧说成已逐帧看过。

连续片段的有效截图范围：6613.625823–6637.312808秒，共62张。相邻有效截图最大起点间隔0.753429秒。开始播放、结束暂停和每次截图前后的视频状态均有日志；区间内部没有seek。

## 三个应分开的层次

1. 静态共同舞台：棋盘、蓝带、灯、望远镜、悬挂银星、舞台设备和城市布景的共享候选几何。连续来源支持共享场景身份，但不自动证明现有模型的形状、尺度和相机标定已经正确。
2. 按真实时间记录的布置状态：有沙发状态与无沙发状态。未来可以在同一共享舞台之上建立显式状态变体；同一变体内所有相机必须使用相同几何/可见性，状态选择不能偷偷绑定相机。
3. 动态角色/道具：人物、黄色星伙伴、红色气球狗。其姿态和离画过程独立于固定陈设，不为了某张源图中的缺席去删除静态共同几何。

本轮只记录来源状态，不创建这些变体、不调整现有模型。后续是否建立显式变体，由新的模型任务决定。
