星瞳场景舞房／霓虹室内：完整房间几何版

本包依据视频中霓虹表演状态的同一房间，保留已有可见舞房特征，并补全有限墙体、地板、顶板、墙角和一个明确标为推定的入口。它是比例重建，不是建筑测绘，也不是官方原始场景资产。

来源：星瞳官方《与星瞳共度的一天》

三、结构补全与推定
原包在镜头后方敞开，顶板与墙顶有缝，许多曲线和文字网格未封口，黄带、地面箭头为单面片。
本版：
- 四周采用有限厚度的墙体，地板与顶板具有厚度，墙角和上下接缝闭合
- 既有可见后墙内侧和两侧墙内侧位置保持不变；隐蔽厚度和前向长度为推定
- 镜头后的前墙设独立门洞、门框与可单独旋转的门扇；入口位置、样式及尺寸均为推定，未声称源片出现此门
- 后部拱景仍有实心背板，属于装饰背景，不是通向第二个房间的门洞
- 管线和霓虹管端部封口，单面装饰有有限厚度，文字重合边焊接并清除零面积面；额外修复了 GLB 三角化时产生的共线文字顶点
- 为悬吊构件、黄带和收音机补上推定连接件及脚垫；未移动源图对应的主要结构和道具来配合单个相机
新增推定构件在名称或自定义 evidence 属性中标注。
另对室内灯光的整个发光圆盘/方形边界作约束，避免灯面穿出顶板或后墙；显式外部检查灯不属于室内设备。

所有数值均为模型单位，不是米；源视频无可靠标尺。Blender 采用 NONE 单位。GLB 保留相同数值比例，导入软件若默认以米显示，也不代表真实测量。

A、B 都是近似匹配，不是完全还原。可见残差包括：A 机位中源片可见的顶面字样在模型画幅中被裁掉；B 机位中的地面箭头偏小、拱景宽度/位置及顶面字框大小/位置仍有差异；两张图的舞台材质反光、局部墙面图案及荧光颜色也不同。源画面人物造成的遮挡不由模型“补人物”遮盖。
