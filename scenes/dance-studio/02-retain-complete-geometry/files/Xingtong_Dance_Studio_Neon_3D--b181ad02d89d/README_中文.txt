星瞳场景舞房／霓虹室内：完整房间几何版

本包依据视频中霓虹表演状态的同一房间，保留已有可见舞房特征，并补全有限墙体、地板、顶板、墙角和一个明确标为推定的入口。它是比例重建，不是建筑测绘，也不是官方原始场景资产。

一、来源与证据边界
来源：星瞳官方《与星瞳共度的一天》
https://www.bilibili.com/video/BV1mx4y1z7oY/
本次恢复了旧包中已保存的两张 960×540 源画面裁图。继承相机标记分别约为 01:00:10（A）、00:58:09（B）；截图没有可靠保留逐帧时间码，时间用于回查，不保证帧级精确。
两帧是不同位置/视角的正面画面，能交叉核对拱形背景、两组柱、顶面线框与 PERFECT、侧墙图案、地面三枚箭头及收音机。它们不是环绕房间的多视角测量，不能证明摄影机身后的前墙、入口位置或房间总进深。
旧说明提及的 00:30:16、01:02:10 清洁紫色状态没有单独源图随本次旧包交付，因此本版不把它们算作新增的独立图片证据。视频内的卧室、厨房、钢琴/沙发房和海边没有拼成同一户型。

二、保留的可见内容
- 霓虹拱形装饰凹景及其背板、DANCE STUDIO、上箭头
- 后部细圆柱、两侧凹槽粗柱与竖排 PERFECT
- 顶部管线、梁、风管、吊装霓虹线框与字样
- 左侧蓝色面板、右侧绿色像素图案、黄色交叉带与低清轮廓涂写
- 三枚地面方向箭头、右侧收音机
没有新建镜面、窗户、把杆、额外走廊或相邻房间。源图人物、平台图标、字幕和播放器进度条不属于模型。

三、结构补全与推定
原包在镜头后方敞开，顶板与墙顶有缝，许多曲线和文字网格未封口，黄带、地面箭头为单面片。
本版：
- 四周采用有限厚度的墙体，地板与顶板具有厚度，墙角和上下接缝闭合
- 既有可见后墙内侧和两侧墙内侧位置保持不变；隐蔽厚度和前向长度为推定
- 镜头后的前墙设独立门洞、门框与可单独旋转的门扇；入口位置、样式及尺寸均为推定，未声称源片出现此门
- 后部拱景仍有实心背板，属于装饰背景，不是通向第二个房间的门洞
- 管线和霓虹管端部封口，单面装饰有有限厚度，文字重合边焊接并清除零面积面；额外修复了 GLB 三角化时产生的共线文字顶点
- 为悬吊构件、黄带和收音机补上推定连接件及脚垫；未移动源图对应的主要结构和道具来配合单个相机
新增推定构件在名称或自定义 evidence 属性中标注。
另对室内灯光的整个发光圆盘/方形边界作约束，避免灯面穿出顶板或后墙；显式外部检查灯不属于室内设备。

四、尺度与几何检查
所有数值均为模型单位，不是米；源视频无可靠标尺。Blender 采用 NONE 单位。GLB 保留相同数值比例，导入软件若默认以米显示，也不代表真实测量。
内侧宽 10；前墙内侧 y=-8；后墙可见内侧 y=3.37；地面 z=0；顶板底 z=4.075。侧墙厚度 0.22、门框内净口 1.16×2.43 都是建模假设。
完整场景由多个独立封闭构件组成，接触或相交的构件没有强行布尔合成单一水密壳体。
详见 QA JSON 与“几何检查_中文.txt”：
- 544 个 Mesh 对象、580 个连通部件；非流形边、非正体积部件与零面积面均为 0
- 4,096 条球面方向射线：关门状态 0 漏出
- 50,544 条墙面、上下表面和近墙角/门框过渡射线：0 漏出
- 2,501 条门洞采样：墙体不堵洞，关闭门扇后全部挡住
- 后拱装饰背板 255 点均有实体承托
- 中央净空 943 个竖向采样、入口至舞台路线 1,378 个采样均未撞物
这些是模型的离散几何检查，不是实际房屋安全、疏散或无障碍认证。

五、相机与误差说明
两张源图匹配图和八张普通室内图均使用同一刚性场景；不按相机隐藏墙、移动道具、拉伸几何或投影源图。参考图仅按同画幅等比例缩放；50% 叠图没有透视变形或局部扭曲。
A、B 都是近似匹配，不是完全还原。可见残差包括：A 机位中源片可见的顶面字样在模型画幅中被裁掉；B 机位中的地面箭头偏小、拱景宽度/位置及顶面字框大小/位置仍有差异；两张图的舞台材质反光、局部墙面图案及荧光颜色也不同。源画面人物造成的遮挡不由模型“补人物”遮盖。
旧 camera_A_fit.json 的点坐标与本包裁图画幅未有完整登记关系，因此本版不引用其旧 RMS 数值作为最终校准精度。
八个普通视角用于检查模型完整性，不能代替八张独立源照片。外观图为完整封闭外壳；剖切图明确移除了前墙及顶板/部分顶面设备供检查，属于单独的结构查看图，不能当成源片机位或完整房间渲染。
白模与材质版的几何哈希相同；白模文件使用中性材质和检查灯光；随附的白模检查图片采用 Workbench 中性实体着色、阴影、凹凸与轮廓显示，保留全部墙体和相同几何，另附入口近景以看清门框和把手。
