# R10 灯口变暗判断的独立勘误

2026-10-30，本轮审查者重新读取已提交 R09/R10 原 PNG 和 Git 原字节，确认旧指定裁区 `(235,515,330,540)` 覆盖 N6318 S105 的灯口。2375 像素仅 46 像素有差异，最大通道差为 1/255，平均绝对 RGB8 差 0.006596491；R10 平均亮度略高。扩大为 `(220,500,350,540)` 后，最大差仍为 1/255。审查者另从 Git 字节做 8 倍最近邻显示，两版灯口外观一致。

原审查者正式撤回 R10 “由亮浅色变暗橙色／可见局部变暗”的判断，承认是视觉误判，不是已证实的 R10 副作用。`qa/r10/independent-final-review.md` 和旧图保持原样，此处追加纠正，未删除或回写历史。

本轮受控试验只替换 R09/R10 世界纹理和插值，在 ray tracing 开／关两组中差异均不超过 1/255；重复渲染 R10 为零差异。不能继续追认某个未复现的显著变暗原因。

这项勘误不取消原有纸灯亮核、星孔及接地暖光不足的来源残差。R11 针对后者修正，不以“恢复被云层改暗的灯口”描述本轮成果。
