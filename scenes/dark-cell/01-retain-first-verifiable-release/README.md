本模型是什么
以932.522162秒可见前景竖栏、暗蓝灰背板和地面为锚，制作有限完整围合布景。可见类型包括竖栏、地面和墙；绝对尺寸、房间纵深、前走廊、侧墙、天花、入口、门、支撑和灯具均为合理推定，不是真实监所还原。所有尺寸和距离均为相对模型单位，没有实测尺度。
完整模型内尺寸6.4×5.4×4.3模型单位，含栏内区域和前走廊。地板厚0.22模型单位，墙厚0.22模型单位，天花厚0.20模型单位。推定前入口为实际墙洞；右侧推定铁栏门固定敞开80度，铰链轴可在Blender内旋转。两处通道有实际空间，墙后、底面与顶部均有实体面。

证据和未解决的问题
- 932.522162秒：正面全身人物在栏后，为主要布局锚。
- 3626.477598秒：人物近景、背景两组亮色栏杆；与前段是否同场、连续空间关系均未证实。仅提供固定模型另向相机与来源的直接对照，明显残差如实保留，不称作已对齐反向视图。
- 1810.889295秒：人物和暗背景，无法增加独立几何约束。
- 618.569435秒新闻插播不作为本模型依据，不混入空间。
- 来源解码1280×720；交付截屏原比例裁切1180×664，绝非原生1080素材。
- 没有独立左右机位、空场完整宽景、平面图或可靠绝对尺度。不把阴影边界变成实体墙。人物、低处雾气和水印不重建。
- 入口位置、门铰链、顶梁、灯罩等只为使推定布景可进入且装配完整；不是从源图中发现的真实结构。

交付和检查
models内有材质版及白模BLEND、GLB，同一几何。材质版GLB内嵌自制微纹理；未把人物源图投影到墙体上冒充空间。GLB不包含拍摄灯光，外部查看器亮度可能不同。
8个普通视角加外部、背面、底部与明确标注的剖切诊断。普通视角不随相机隐藏、移动或缩放墙。剖切单独使用诊断副本，非完整交付模型。
源图、白模、材质版及50%直接叠图保持1180×664，不对源图作透视或非均匀变形。匹配仅体现当前有限推定模型，人物遮挡及后段空间关系均未解决。
每个构件为闭合实体，装配有必要嵌入重叠，不声称所有构件布尔为单一实体或满足实际工程承载规范。请看qa的真实GLB回导、拓扑与密集围护射线检查。
没有找到本场已有可核实旧发布版本，本次就是首版；不伪造历史版本和旧版比较。

画面注意事项
材质图与白模图均使用固定几何和灯位；完整封闭房间需配合灯光查看。预览降噪只作用于模型渲染，不处理来源截图；来源叠图为严格50%逐像素混合。暗部曝光、低雾、角色遮挡和源视频光照不作为可证明的墙面几何。
外部前右、外部背面、底面与剖切预览仅增加诊断环境亮度，便于看清实体背面；几何和内部灯的位置不变。八个普通视角保持原有光照。门可转动不代表自动绑定交互脚本；GLB保留分件几何，是否能交互开门取决于使用端。
独立核验曾发现GLB贴图乘色丢失；交付版已将目标色正确按色彩空间烘入贴图，使用直接PBR连接。最终同机位同灯回导对照见独立QA，不把早期失败图当最终渲染。

附加08同机位白模近景用于检查推定门铰链、门把支座及其接触；普通视图几何和灯位不变。
