本批通过正常网页播放器暂停后，使用浏览器原生“将视频帧另存为…”保存。PNG按导出时原始字节交付；未重编码、裁切、放大、AI处理或提亮。
每张均检查保存前后为暂停、readyState=4、currentTime不变，且视频原始尺寸与PNG IHDR/Pillow解码尺寸一致。逐张实际尺寸、字节数、SHA256及必要媒体状态见source-manifest.json。
请求参考时刻来自既有记录；实际时刻是本次保存时的暂停currentTime。普通界面跳转与暂停不保证旧参考的同一帧；差异逐张列出。不得把时刻接近直接当作逐像素同帧，也不得把同轴缩放算作新增独立机位。

原生保存步骤
1. 在源BV网页播放器选择可用画质，使用播放器时间输入框跳转。
2. 等待新画面缓冲完成并暂停，确认场景内容已更新。
3. 只读检查暂停状态、currentTime、readyState与视频原始尺寸。
4. 打开浏览器原生视频右键菜单，选择“将视频帧另存为…”。
5. 再次只读检查媒体状态未变；核验原始PNG尺寸、字节数和SHA256。
