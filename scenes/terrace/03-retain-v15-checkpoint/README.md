可选状态：画外推定井格（默认关闭）

开启方法：在 Blender 文本编辑器选择“说明_全局切换画外推定井格.py”，把 ENABLED=False 改成 True 后运行。改回False运行即关闭。这是同时作用于所有相机的全局开关。也可在大纲视图同时切换该集合的渲染和视口禁用状态。
纵梁前端到Y=-8.05，新增横梁Y=-3.20和-6.00，梁高/材质与现有井格一致。在当前固定太阳方向下，梁高产生约3.8单位的地面投影位移；横梁在Y=-6附近才会把影子落在来源前景Y≈-2.2的位置。为覆盖画面底部，推定前延伸约7.575单位。
这段长度较大，隐藏支撑和原始范围未确定，太阳方向与长度仍可互相补偿。因此仅保留为可关闭的实用外观假设，不是测量复原，也不是默认建筑事实。它改善真实地面格影，并同时真实投影到画架、椅子、栏杆，不能忽略这些连带阴影。
