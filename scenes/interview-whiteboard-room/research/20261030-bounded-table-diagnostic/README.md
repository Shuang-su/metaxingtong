# 有界桌子诊断（本地，R05 冻结）

本阶段不修改 R05、CURRENT、灯光、椅子、原始来源和既有失败记录，不产生新模型版本。原件基线 HEAD：`0c6280de6c33099d7b3cff8e2fe0103bc9ed0381`。独立审查归档提交：`93a894abb3471e8d33e47aa312fe8a6281f64c53`。

## 阶段一：仅相机

执行：`python research/20261030-bounded-table-diagnostic/diagnose.py camera`（在场景目录）。脚本只在本诊断目录写 JSON；不调用 Blender，不改图像像素，不使用角色尺度，不移动物体。

重新看两张原生来源，在拟合前固定 `annotations-and-method.json` 的点位和容差。白板框采用直线段中心延长线的虚拟角点，不把圆角尖端误当矩形角点。支架旋钮、夹具和墙角参与拟合；斜近景可见框边采用点到投影直线的距离。16 个空间分散的既有文字特征只以低权重约束同一个平面，另报告全部 177 点误差，不视作 177 条空间基线。

每个机位三次有界起点求解，另作五个固定焦距剖面（最优值的 90%、95%、100%、105%、110%，重拟合其余六个相机参数）。表顶四角、前脚端点下界、近景无遮挡区域完全留作独立检验。相机参数范围、所有成功／失败求解、拟合点和误差保存在 JSON 中。数值求解 success 只表示求解器终止，**不表示来源或相机验收通过**。

当前结果：两机位最佳解均未达到静态锚点门槛。前视旋钮误差约 14.5–17.5 px，斜视旋钮约 20.6 px、夹具约 10.4 px；不能把原模型中部分推断的支架位置当精确实测。冻结几何的仅相机求解令桌顶四角 RMS 从 2.67 增至 21.93 px，前脚距下缘的缺口从约 59 降到约 31 px，但近景明确无遮挡矩形中的桌子误遮样本占比从 71.07% 增至 74.46%。这些比例仅针对固定 140–780 × 795–1070 px 矩形，不代表全图误差。保留所有失败解，不替换 R05 相机。

不能据此断言实景无法存在共享桌子，也不能证明桌子移动；结论仅限于当前冻结几何、针孔相机假设及标注容差。

## 阶段二计划与停止条件

仅允许同一桌子共用的深度、x 位、y 位变化，宽度、高度、桌腿截面、地面、椅子及白板不变。先用 R05 相机及阶段一的失败条件解分别诊断桌参数的权衡；失败条件解不因此取得候选资格。保存有限参数范围与全部测试结果。

只有静态锚点、两来源检验和支撑／穿插都明确改善才可能进入局部模型修正。否则停止于本诊断，列出新来源需求，不增加猜测渲染或时间状态。上传、push 和发布均未获授权，不在本阶段执行。
