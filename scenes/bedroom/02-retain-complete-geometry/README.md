质量边界
网格闭合及射线通过，不等于完整建筑施工碰撞审查；通行只是指定路径抽样。尺寸不用于施工。整房几何完整与源片拟合质量是两项不同结果。
光照为近似室内设置，GLB不包含工作灯，外部查看器需配置环境光。所有普通图使用同一完整模型；唯一删墙图明确标记为独立剖切。

源图相机补充：在房间内部约束下，以旧版七个手工结构锚点做刚性相机近似拟合，稀疏点RMSE约30.1像素（1188×668裁边画幅）。这不是全图相似度，也不是独立多视角验证。脚本保留工作记录与原工作路径，复用需调整路径；不宣称脱离源资产一键从零再现。

深度选择：未知前墙保留为推定。对相机深度5.45/6.5/7.5/8.5/10/12/18.4做一次有界比较，七手工点误差依次约54.31/39.56/30.12/23.40/16.41/10.41/3.35px。采用房间内深约7.7、相机y=-7.5的有限折中，保留已知家具不变；未进一步加深来追逐低残差。原同轴机位视锥不能穿过偏左的真实窄门，不为相机强造大洞。旧5.5深版保留在工作记录，交付使用统一7.7深房间。
具体源片差异：画框高度、床面投影与原截图仍有偏差；右床柜存在相对位置偏移。植物轮廓/枝叶与源片不同。红色海报、床边画像是手工替代图案，不是原片贴图，也不是通过源视频恢复的原始资产。稀疏锚点误差下降不等于以上外观差异已解决。
推定前段铺装限制：房间加深部分沿用简化人字木条。与旧段在y≈-5.55的接界处可见锯齿状板端及局部木色基底；这是简化铺装的视觉接缝，并非楼板孔洞。实体底板连续，未把它宣称为完整细节级木工铺装。
