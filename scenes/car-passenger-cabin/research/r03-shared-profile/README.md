## 图像复核和实体检查

原尺寸 B1/D1 各三张渲染及六张直接 50% 叠图均保存为 PNG。叠图逐像素满足 `floor((source + render)/2)`，没有变形、局部重定位、遮挡掩码或色彩匹配。五列联系图仅显示为原图的 20%，单图仍是 1920×1080。源图/渲染/叠图和原尺寸局部四联图已实际查看。

独立本地像素脚本不读取拟合器或模型坐标，只读原生 PNG，在明确非人物 ROI 内做 sigma 1.4 高斯 + Sobel 边缘及双向距离检查。它是独立实现复核，不是独立来源或第二位评审。B1→D1 的风口区域 source→render 平均边距为 27.5→16.5、16.8→11.5、24.5→13.4 px；台面为 22.2→8.8、21.7→9.4、19.1→7.0 px。A 柱区域为 71.1→73.8、44.9→46.2、49.0→55.1 px，均退步。镜子 ROI 含相邻边缘与阴影，不能把局部像素变化解释成未改镜子几何发生移动。双向及 P90 全量在 `qa/pixel_readonly_qa.json`，没有整体相似度分数。

45 个实体均闭合、正体积、零退化面；208 个风口间隙射线均到真实腔体背板，面板无封堵。白模/材质两状态一致，GLB 真正导出后删除场景对象并重新导入，45 网格保留；闭/开状态最大双向顶点误差约 1.19e−7 / 4.92e−7。以上不等于装配连接或来源验收。

**新增明确缺陷：**倾斜的面板实体与水平台面底部之间形成内部间隙。在 X=0.4、前缘后方 Y 距离 0.05/0.10/0.20 的真实网格射线探针，B1 重叠约 0.0025，D1 却分别有 0.02290/0.04830/0.09910 的间隙。主图可见部分底部暗缝。故 D1 连装配连接门槛也未通过；按本轮停止规则保留缺陷证据，不另加隐藏填块把未证剖面装成已完成。下次若剖面假设获得来源支持，须连同台面内回边/支撑重新建立共同截面。

八张任意角检查是检查图，不能充作来源角度。CHECK02/04/07 为局部背侧/上方检查，存在自然遮挡或裁切；CHECK05/06 展示有限整体边界。没有为检查图隐藏顶棚、玻璃或门。

3. 材质与光照保持原诊断近似：合成织纹过粗、方向及反差不符；S02 暖色和青色反光未还原，S01/S03 的细密明暗及外部反射未匹配。未为单图改材质或灯光。

## 最需要补拍的角度

优先取得**同一关门状态、无人物遮挡的副驾前角斜视**：一帧同时看清完整圆风口、台面前缘上下转折、A 柱下接点、窗框与外镜；相机从现有偏侧视转向仪表台，产生明显横向视差，并记录连续运镜和片内时间。这比继续同轴缩放或孤立风口特写更能区分共同截面与相机错误。

其次取得同一固定机位开门前后的短连续段，明确切镜和门铰链状态；需要看清门槛、镜座和前窗框，验证是否能由同一活动门解释。S04 夜路画面不强行纳入该几何约束。
