# 汽车副驾局部候选检查说明

这是现代汽车副驾一角的局部研究，不是马车，也不是完整汽车、完整内舱或完整第三个已验收场景。`models/car_passenger_cabin_material.blend` 是可编辑材质模型，3 张合成纹理已打包，同时在 textures 目录保留外部 PNG；white 文件与材质文件在关门、开门状态共享一致几何。GLB 含同一门铰链动画，帧 1 关门，帧 2 开门；54° 是可编辑试验角，不是测量。

## 几何范围和推断

门板由有厚度的实体组成；储物槽具有真实顶部开口、底、前唇和端壁。侧窗有连续边框及独立薄玻璃假设，透明介质厚度未证实。圆风口在仪表台实体上布尔开孔，独立孔壁、深处终止面及三条叶片；没有用黑条替代孔洞。底板、局部脚部闭合、顶棚截断、门背、安装支撑和厚度都是明示推断。角色背后仅连贯延展已有门板假设，不补身体或完整座椅。

有限座椅只保留外侧边缘条；它不是完整靠背、坐垫或头枕。外后视镜与室内镜都是可见轮廓的近似，不包含真实反射环境。外部车身、车型品牌、后排、车外城市全部未建。白模中的玻璃使用白色诊断材质；几何与材质版不变，不把白色玻璃误当实体封窗。

中部和后部边界是刻意保留的研究截断面，不是完整车舱开放口的证明。内部检查视角、从外侧看到的截断边缘和俯视均是诊断视角；渲染时未隐藏任何网格。没有按相机变形或开关部件；相机与门状态分别显式设置。

## 检查和修正

初版检查发现曲线端盖分离顶点、两个风口环反法线和两处退化面，原失败报告 `geometry-report_initial-failed.json` 保留。后续焊接同位端盖、重算法线、清除退化边面并降低门槛，当前 45 网格均闭合流形、正体积、零退化面。400 条侧窗射线未撞到不应存在的实心填充，200 条储物槽射线均到达槽底，208 条风口间隙射线均到达凹腔深处而非面板堵塞。

主图结构复核又发现推断的室内镜支撑没有真正触到局部顶棚，已延长并移到顶棚体内。修改前的渲染保留于 qa/r02_support_gap_trial，不能当当前交付图。最终全部渲染重新运行。门槛与门底的静态间隙已修正，但没有进行完整铰链运动的连续防碰撞验收，也没有把未知安装机制当真。

GLB 实际导出后清空所有原物件，再调用 Blender glTF 导入器。关门和开门都验证几何，逐物件双向最近顶点距离与三角数见 glb-roundtrip-report；由四元数转换造成的亚微量误差与精确量化集合比较失败分开记录。重新导入的 45 个网格，UV/法线缝在一次性 bmesh 中焊接后均闭合、正体积、零退化面；不改写导入原文件。回导保存为 qa/glb_actual_reimport.blend。未声称在另一款 DCC 软件中测试。

材质采用合成的编织、细纹和 PBR 参数，没有从来源纹理提取，也没有以源图作假背景。GLB 保留基础色/粗糙度图片；Blender 细纹 Bump 节点不保证跨软件完全复现。照明是一套固定的中性检查灯，未还原橙色/夜景变化。源图含压缩、色差和人物，均原样保留。

## 来源对照与未通过项

最终提供四张全尺寸渲染与直接 50% 叠图，S04 明确只作上下文；三张侧舱图各有公开状态。所有叠图直接混合完整 1920×1080 图像，未遮罩角色、未对局部扭曲、未搬动部件。物件局部裁切使用原生同坐标，另有带标签展示拼图；裁切/缩放不增加来源视角数。

手工点选唯一可辨圆风口中心（约 ±15px 选点不确定性）并投影模型同点，S01/S02/S03 当前残差分别约146/133/120px，均超出选点误差；详见 qa/source-landmark-residuals.json。单点诊断不是相机标定或全图拟合分数。

当前残差：A柱斜率与截面、顶棚/遮阳板占幅、门板分段比例、外后视镜尺寸/可见范围、风口轮廓与中心位置、开门角度和座椅边缘均未精确匹配。角色遮挡的面积差异无法作为模型误差直接解释；没有输出虚假的全图拟合分数。夜景、橙色光、玻璃反射和织物密度仍不一致。**来源验收未通过，用户尚未确认。**

普通任意方位检查 8 张，另有一张开门状态检查。外侧与俯视两台检查相机经首次看图发现构图过近，已只调宽焦距并重渲；旧图保留 qa/r03_framing_trial，不当当前检查图。所有检查使用完整共同局部模型、固定灯光，显示未知边界与背面，而非充当新的来源角度。

## 使用和复现

依次在 Blender 4.3.2 执行 scripts/build_geometry.py → scripts/refine_shared_geometry.py → scripts/fix_mirror_support.py；普通 Python 执行 scripts/generate_textures.py；再执行 Blender scripts/apply_materials.py → scripts/update_evidence_metadata.py → scripts/widen_two_check_cameras.py → scripts/qa_geometry.py → scripts/export_roundtrip.py → scripts/render_deliverables.py；普通 Python 执行 scripts/compose_comparisons.py。`refine_shared_geometry.py` 应在新生成白模上只执行一次，避免重复应用位移。脚本不联网、不安装依赖、不使用来源图作建模贴图。

主图 PNG 无损原件与完整 1920×1080 JPEG 展示副本并存；JPEG 小于 900 KiB，未缩放。Git 仅本地 scene/car-passenger-cabin，逐阶段真实当前时间提交，未推送、未新建 Issue/PR、未修改主分支或其他场景。Library 保存状态另在最终交接报告中据实际结果记录。
