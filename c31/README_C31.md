# C31：床端板中央槽独立比例修正

## 结论与边界
本候选只修正中央外槽和内嵌片过高、中心过低的既有问题。实际源场景为C29，床高、床垫厚度、支撑、两手孔、端板外轮廓、椅子及所有相机保持C29状态。C30/C30B两床高方案继续拒绝，不因槽修正自动恢复。

## 两张原生图支持的相对形状
1801.323与1804.861两帧原生1920×1080中，中央外槽高62/60px，暗透孔平均高50.5/49px；内嵌片高48/46px。外槽/透孔高约1.228/1.224，内面/透孔约0.950/0.939；外槽中心比插值两孔中心只低0.75/1px。孔外唇另行标注，不能混作暗透孔。
这两张新视角未标定、未做平面整平，不能把像素换成实测世界尺寸。每条软边约±3px，独立最坏误差给出宽比例范围，且暗透孔受孔壁遮挡。证据支持明显缩高/上移的方向，不支持精确物理尺寸。

## 实际网格改动
从端板前平面拓扑提取两个闭合孔，孔高0.0698112模型单位，中心z0.78071454。原中央外槽高0.179325，约孔高2.569倍，中心比孔低0.0547569（0.784个孔高）。
候选保留X/Y宽深，只缩放两个网格顶点的世界Z并把中心对齐孔中心：外槽高0.0855187（孔高×1.225）；内面高0.0663206（×0.95）。它们分别纵缩，保留内/外高度差，不把整个组合统一缩放。没有改变孔或端板来适应中央槽。重开两blend核验，仅这两个对象的顶点状态变化。
