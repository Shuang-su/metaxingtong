# VD2 邻面回归补充：只读，范围收口

目的只限本次叶脉沿 Z 浅嵌是否新增邻接三角面的折叠/重叠，不再扩展来源拟合或全场验收。输入仍是同一非精确重放夹具与 VD2 局部候选，没有改模型。

## 首次无效覆盖保留

`check_adjacent_faces.py` 试图从同树 BVH 相交候选筛选共顶点对，实际测试数为 0。这个结果不能用于声称邻面没有异常；JSON 和日志原样保留，不计为通过。它不推翻上一轮非共顶点自交检查，因为上一轮的目标本就排除共顶点对。

## 直接拓扑枚举

`check_adjacent_faces_topology.py` 从顶点-三角关联直接枚举每一对共享一个或两个顶点的三角面，不再依赖 BVH 是否返回接触对。每个输入的 19 管共有 50,182 对。

对非共面的面以边-面相交求候选交点；共面面以投影多边形裁剪求交集，再测交点距两面的公共顶点或公共边的距离。6 个单元夹具包括合法共边/共点、共面重叠和穿过面内的共享顶点反例。

实跑前后两版均没有超过 1e-6 模型单位容差的超公共点/边重叠。最大计算残差均为 1.718990734e-10。新旧同编号三角面的法线最大变化约 1.079225 度，无非正点积。旧折痕没有被当成新增问题。

这只是对指定三角离散网格的数值检验，不是精确算术证明、连续曲面/制造验证或原摄影验收。法线小变化也不单独证明全局映射可逆。完整源场景没有参与本轮。

## 波面数字不作为验收依据

原记录还计算了叶脉最小 Z 约 0.03226016 与原脚本波幅公式上界 0.02700001 的差，两版相同。它只是公式与几何坐标界的比较，没有使用本轮原水面网格的真实 XY 交点；不据此声称逐点水接触、无穿水或浮力正确，也不作为接受浅嵌候选的证据。

最终判断仍是有限局部技术接触候选。此前来源失败、非原件恢复、非 Boolean 焊合等边界均不改变。
