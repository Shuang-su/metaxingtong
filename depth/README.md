# MetaXingtong relative depth analysis, 2026-11-04

Real CPU inference with official Depth Anything V2 Small Hugging Face safetensors model, pinned revision 5426e4f0f36572d16453bbda7a8389317b1bef99. Exact four model-artifact sizes/hashes are in provenance/model-manifest.json; all verified before inference. No remote code execution. CPU torch 2.15.0+cpu and transformers 5.22.1 restored from official registries. Logs and exact package freeze retained. Environment and 99 MB weight cache excluded from project deliverables.

run_depth_frame.py accepts original source and metadata JSON, verifies original hash, predicts float32 raw relative inverse-depth on the model grid, and saves raw .npy/16-bit grayscale plus derived source-grid .npy/8-bit display. White/larger generally nearer, black/smaller generally farther. Per-image min/max normalization is not metric scale or cross-image distance. Derived source-grid uses bicubic align_corners=False and is not native-resolution independent depth inference.

Every production report records source BV/time/hash/pixel size/capture metadata, processor configuration, actual tensor dimensions, method/package versions, numeric range and output hashes. Conservative manually inspected exclusion regions are incomplete, not segmentation; overlap uses last drawn class. Zero means unlabelled, not certified valid. confidence-unknown all255 means no calibrated confidence, NEVER high confidence. Nonfinite mask means only numerical invalidity. Low-signal mask flags all RGB <=25 from source pixels as a caution; this luminance test is NOT the depth-generation method. Hidden/occluded geometry is unobserved.

Historical camp recovery-test is solely execution validation, not new scene or current source acceptance. Production forest outputs are independent. No generated depth establishes true distance, scale, contact, camera calibration or geometry acceptance. Dense leaves, shadows, glowing wings, fog and stylized CG are unreliable. Native source multiview and direct unwarped 50% overlays remain mandatory.
