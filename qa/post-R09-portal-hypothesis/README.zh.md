# 门框前墙平面敏感性诊断，未应用模型

固定R09现有且来源匹配FAILED的SOURCE_15_exterior相机，将独立人工像素轮廓反投影至假设前墙 y=-6.16 及±0.2平面。高暗弧在中间平面的可见点约z3.953–5.237，低厚框外边约z1.631–4.176；旧门洞上弧最高4.05、旧内金框最高4.23。这些是给定失败相机与假设平面条件下的坐标，不是实际高度，也不能证明两条弧共面。

原15局部确见高低弧之间多层远侧拱/墙纹样。直接在当前实墙上贴高弧，可能掩盖原应通视的结构，因此暂未建新实体。高弧是较高实际开口边、突出装饰带还是前后层组合，目前无法单图区分。原14天空窄带也仅证明投影层次/空隙，不能先验映射为门00或08。

脚本只读Blender原件，无模型保存、无渲染。保留所有采样和往返投影误差，不以单视反投影低误差冒充几何验证。后续需要来源层次桥或明确可检验的独立假设，不能由此暗改洞口。

## 内存开孔假说反例

另在原R09上，仅将 DOOR_00_upper 的82个下轮廓顶点Z增加1.2，原上沿5.5和旧内金框不变。此1.2是显式任意试验参数，不称测得高度。H0/H1各以同原源15相机、32samples/无去噪器渲染原像素ROI x550..800,y375..565；不保存或导出新模型。

实看H1确使较高区域通视，旧低金框呈现独立层次，但上部露出的是错位竖框/暗面，不对应原图可见多层拱纹。开孔使图更复杂并不等于正确，当前不选该试验为恢复成功。它说明仅靠增高一个前门孔无法闭合层次和相机/远侧几何问题。原R09完整失败/未验收结论不变。
