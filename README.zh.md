# 来源04六点语义审计：只读，不重拟

结论：旧六点不能作为六个可靠、同义、完整可见的3D标定对应。应撤下三项外缘→作者中心代表点的硬约束；右上圆的源中心被角色遮挡，不能硬锁。左/中两个上圆中心可辨，但不代表两个圆完整轮廓均无挡，更不足独立校准6自由度与焦距。本次只记录确切mesh表面候选，不替换旧像素、不重新优化相机、不重渲、不改模型。来源仍FAILED。

## 不变基线
source/old-fit04-unchanged.json原样保存旧六点、旧世界点、旧拟合与边界信息。source/04.webp为实际1192×671报道图原字节，不是native帧。qa/features.json保留旧source/world全记录，并用当前保存相机投影每项旧点及真实mesh候选。候选按物理面/边身份列全，不按谁残差小挑选。

## 全部旧六点的逐项分类
1. middle_apex源(465,78)不变。实际重看是中拱上外缘邻近星光，不是作者中心曲线点(0,4.32,4.23)。旧点作为实体外表面硬对应无效。真实mesh最大world-Z外缘有前顶点145=(0,4.11,4.455)与后顶点339=(0,4.53,4.455)。它们投影分别(449.48,102.51)、(451.85,102.40)，对旧源条件误差29.01、27.72px。当前图像最上mesh顶点也是339，但这是相机相关轮廓极值，不是新增固定实体标记。源前缘/后缘不可唯一辨，不能选27.72较小者当真值。
2. round_left源(321,301)不变。中心可辨，圆的下部被栏杆横穿，因此完整轮廓可见性不成立。模型W02 round diffuser0真实前cap中心由64个边界顶点均值定义，不虚构已有mesh顶点：(-1.85,3.4548,2.2)，投影(296.17,294.00)。实际first-hit命中该圆前面。旧点是圆盘厚度中点，前表面修正约亚像素量级，不解决约25.8px条件残差。
3. round_middle源(449,300)不变。中心和大部分圆轮廓清楚，邻近光效不解释成实体。真实前cap中心约(0,3.335,2.2)，投影(449.95,294.22)，first-hit命中本圆，条件残差5.86px。它可保留为较清楚的中心观察，不是已标定测量。
4. round_right源(579,303)不变。原图右上圆被人物头/躯干大幅遮挡，中心需部分弧推断，不能作为完整可见硬中心。真实模型cap中心(1.85,3.4548,2.2)，投影(602.84,291.09)，模型first-hit命中本圆，但模型没人物，所以不能据此证明源中心可见。旧像素及其隐含推断保留，不悄悄删掉后声称拟合更好。
5. upper_left源(130,230)不变。可见coping左端有多条顶/前/后边，旧(-3.85,4.0688,2.97)是作者代表点，不在对应实际外顶角，不能作已证外表面角点硬约束。W03真实外左顶角有前顶点98=(-3.975,3.8580,3.045)和后顶点147=(-3.975,4.3480,3.045)，投影(121.67,221.35)/(135.64,217.17)。不能凭哪个接近源选哪个面。
6. upper_right源(752,235)不变。同样是多条coping端部外缘，旧(+3.85,4.0688,2.97)不是确切外顶角。实际前146=(3.975,3.8580,3.045)、后195=(3.975,4.3480,3.045)，投影(770.25,217.51)/(762.36,213.59)。两种候选都保留，源像素不改；不造一个恰好落近源的中间顶点。

## 完整可见集与补充约束
在旧六点内，可靠程度较高的是左/中两发光中心的观测，而不是全部三圆；明确不挡的完整几何轮廓集合更小，不能说有六个完整可见对应。拱缘和coping端部可以作带语义/边界不确定性的轮廓诊断，不能自动升级固定3D点标定。

另有独立研究已确认源04左下圆完整外轮廓，中心约(262,420)。这是新列的独立观察，未偷偷加入旧fit。模型W08 circle0真实前cap中心投影(221.77,429.59)，条件差41.35px，first-hit先命中W06 surround03，实际圆面被遮挡。这是几何/遮挡矛盾诊断，不能为了凑够标定点直接强锁。它与此前厚度中心投影(222.70,428.60)、差40.23px不混同。

## 实际可见性检查边界
所有候选已做当前保存相机first-hit。顶点在精确轮廓边界处可能数值miss，不能把NO_HIT叫隐藏或不存在。另对实际相邻面做顶点向面中心1%插值的表面点探针，保留polygon与命中距离：前/顶表面多数命中目标点；背面可先碰同一个物体的前面，只有物体名相同不等于该点可见。qa/adjacent-face-probes.json明确比较目标与first-hit距离，阈值0.0001单位，不将对象名命中当可见通过。探针只是面内可见性诊断，不替代旧源像素，更不把源中的人物/标识遮挡自动消除。

本阶段不足以支持新相机拟合：两清楚中心不够，新增下圆又有明确模型遮挡矛盾，边缘对应尚不唯一。维持原final及r03失败历史，等更可靠物件/相机证据，不扩大bounds或增加自由度追loss。
