# 红白扭转方框厅 / 条件研究候选

R01为新的独立Blender场景，不是旧#15红金圆拱舞台换色。有限排重结论和来源缺口见docs。状态始终为 **CONDITIONAL / 未验收**。

- 来源：GameRes转载腾讯游戏学堂访谈《从NPC到虚拟偶像，《QQ炫舞》星瞳华丽变身背后的思考》，https://www.gameres.com/892357.html ，页面日期2022-01-12。演出日期、直播场次/BV、原生视频时间未知。
- 原材料a15/a16/a18是320×176发布GIF，112/108/96帧，不是原生直播导帧。key PNG为Pillow实际解码，无上采样。GIF累计毫秒不是视频时间。
- 固定a16第27帧暗洞状态；a15第110帧及a16第107帧用作条件性共同空间对照。a18亮洞状态只作辅助，不按相机暗换材质或几何。
- R01早期模型：有限舞台、真实开口和厚度的扭转方框序列、红墙屏开洞、白柱、局部上弧带及暗玻璃、倾斜红盘、礼盒和抽象地缘红饰。角色/瞬时光效不建为实体。
- 所有尺寸为无实测证据的相对模型单位。隐藏后背、顶返边、终端和完整地面范围均推定；部分开敞舞台不扩成未知整栋建筑。
- 一个共享场景，MATERIAL与WHITE材质替代层。源相机只是估计，不是标定。至少八个独立模型检查方向会在后续阶段补齐，不冒称八个源角度。
- Blender 4.3.2，CPU最多4线程。当前工具无Blender连接器；直接使用本机既有Blender。源、脚本、模型及失败版本以普通Git保存，不用LFS、不改历史。
- GLB原生导出支持几何/材质/相机，但Blender AREA灯不是glTF支持的灯，导出日志明确警告。GLB不能宣称跨软件灯光外观完全一致。真实重新导入检验将在后续阶段执行。
