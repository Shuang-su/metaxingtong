# 叶舟叶脉贴合：局部技术候选 VD2

## 结论与交付范围

在非精确重放的 20 网格夹具中，已实证的叶脉末段悬空间隙得到局部技术改善。候选保留可编辑 BLEND 和实际回导检查过的 GLB。

这不是原生产 BLEND 的恢复，不是完整湖面场景，不是新来源或新的每日场景交付。没有获得新的来源图，也没有重新通过 92 / 100 / 108 秒画面的轮廓、材质或岸林验收；原生产 R06 来源失败结论不变。完整原件恢复后的同类修改仍须对真实原件重新检测和多源验证，不能直接把本夹具替换成原件。

## 实际改变

- 仅改变 19 根叶脉管的 451 个横截面环。只有全部环顶点和边中点都高于最上层壳命中的环才移动。
- 每环只向下作 Z 平移，最大 0.014845169 模型单位。选择浅嵌目标最多 0.0005，并受该环采样首层厚度的 10% 约束；这是技术选择，非来源实测数值。目标是对采样点定义的，不能称为全连续表面的最大嵌深保证。
- X、Y 坐标逐顶点不变；截面点对距离变化小于 5e-7，是保存为浮点坐标后的误差。管截面保留，不声称对变形后中线重新求过圆截面方向。
- 主舟壳全部 world 顶点/拓扑 hash 完全不变，壳厚和两尖没有修改。主脉第 22 环至正向末端坐标不变，未按“四次交点”的误读修坏末端。
- 使用浅相交实现局部接触。20 个网格仍分别存在，没有 Boolean 焊合、合并为单实体或拓扑一体化。

## 实际复核

1. 基线保留完整报告。18 条支脉各最后两个环带及末盖的三角面对整壳最短距离为 0.006209825–0.011261454；主脉首两个环带及起盖为 0.000241267。单位是任意模型单位。
2. 候选相同 19 个选定区域的三角距离均为 0，实测出现接触/相交。18 个分支起端区域对主脉的最短距离修改前后均为 0。不是每个面都与壳接触，也不是整环连续接触的证明。
3. 三角距离用了完整顶点-面、边-边、边-面特征测试，以及可排除更远候选的半径界。候选搜索使用 Blender float32 BVH 和 1e-5 余量；不是精确算术形式证明。
4. 所有管-壳候选相交对经三角特征测试，未出现向下法线 z < -0.01 壳面的新相交对。此筛选不能推广为全底壳无穿出、全场无自交或完整实体接触证明。
5. 451 个移动环各一个最低采样点，经全壳 83648 三角面 float64 solid-angle 绕数与五向射线核查，全部判在壳内。绕数范围约 0.9999999999999969–1.000000000000004。覆盖的是这 451 个点，不是每一个管表面点。
6. 原 1e-6 射线前进步长有 3 例重复命中同一三角面，误计为偶数，原失败 JSON 和日志保留。增加三角编号的复查明确显示重复命中；1e-5 步进及独立全壳绕数一致，未因此再次改动几何。
7. 20 个网格仍无开放边、非流形边或零面积面。此结果不等同于没有自相交。主壳 hash 不变。
8. GLB 真实导出后重新导入，20 个网格名字一致，双向最近顶点最大误差为 0。中性诊断材质，不是原场景材质；GLB 不含相机、湖水或岸林。BLEND 5,184,080 字节，GLB 1,971,772 字节，均低于 100 MiB。

## 固定旧机位的回归量

使用归档侧车中四个旧相机参数，仅比较修改前后模型顶点在两次投影都位于画幅内时的位移，分辨率按 3840×2160 计算：

- 92 秒侧面：最大 4.67684 像素。
- 100 秒俯视：最大 0.05471 像素。
- 108 秒局部斜视：最大 8.23862 像素。
- 6 秒辅助背近：最大 10.06915 像素。

这些是变化量，不是来源拟合误差，也不表示小于阈值就通过验收。没有为单独机位改变几何。侧车共 13 相机，但本轮只对上述 3 主来源机位与 1 辅助机位作投影诊断，没有冒称得到 13 个来源视角。

## 两张有效局部对照图

`renders/exposure-fixed/vein-tip-contact-before.png` 与 `after.png`：1000×700，Cycles，16 samples，2 CPU 线程，denoising False。两次全部 20 网格可见性不变，镜头、光线及中性诊断材质相同，只比较候选几何。画面显示支脉 03 L 末段区域的浮离与接触差异，不含完整末盖、全舟或来源场景。

## 文件与复现

- `inputs/`：未改的非精确重放夹具、归档相机侧车及先前重放证明。
- `models/`：只含 20 体的候选 BLEND / GLB。
- `scripts/`：基线检查、限定变形、连续距离、绕数、导出及真实渲染脚本。
- `qa/`：原始失败、修正解释和实际输出，均保留。
- `BASELINE.md`：基线来源与不精确限制。

脚本在 dot 云电脑实际 `/usr/bin/blender` 4.3.2 执行，未使用外部建模服务。复现实验应在新工作副本运行；模型输出存在时构建脚本会停止，以免覆盖候选。初始射线脚本的失败是保留的数值反例，应同时阅读 winding 复核。没有更改原生产原件 SHA 守卫。

本目录使用独立真实 Git 历史，不冒充原生产历史的续写。Space 备份和私有 Git 归档须经原文件回读确认；本文不把本机冻结冒称远端已保存。
