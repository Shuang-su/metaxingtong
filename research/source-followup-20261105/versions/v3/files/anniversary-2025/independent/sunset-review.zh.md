# 峡谷圆台封面与旧沙漠营地有限排重

实际查看新sunset.jpg（1120×630宣传封面），以及旧#87沙漠白帐篷营地R08对照预览中左列两张实际来源图。旧来源BV169Y96rEo1 P1 1541.388510/1570.440870秒；此处看的是有明确source列标签的缩图，不冒充重新取得原生PNG。

旧场局部主体是巨大白色尖顶帐篷、椅/包箱、仙人掌、散岩、干草与沙地，远处峡谷；新图可见硬质直线台阶/两侧边沿和一组大型圆形地台环、近右陡峭岩壁、草灌木，没有在可见范围看到旧帐篷物件组。结构差异不只是光照颜色。不能因为都是橙色峡谷称同一场，也不能因画面没帐篷就彻底排除同大场景另一处视角。

结论：未发现与旧#87所看营地区域的直接重合，存在不同局部场景候选线索；没有证实整个环境不同，远峡谷是否复用仍未知。不应把旧desert改名就计新场，也不能用这张单封面宣布已最终排重。当前圆台大量被人物及大文字遮住，墙地边界/阶梯整体范围/反向结构不足，不能启动完整重建。

同日官方《领域展开》BV1hLtUzyEDu及8/2桥接来自producer核验，本次未独立浏览。旧29Issue快照仅能定位最相关#87，不冒称本次检查完整最新仓库所有图。下一步需要真正视频原生多角，核圆台/阶梯连续空间及是否在旧营地周围。
