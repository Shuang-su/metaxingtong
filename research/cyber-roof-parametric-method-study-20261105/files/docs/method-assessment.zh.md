# 主屋盖构造层重建方法评估：条件可定义，尚不能保证完整候选

本次只读原build.py、旧taper反例与独立源语义。未运行参数搜索，未构造候选mesh，未保存BLEND/GLB，未渲染。R05、R06b及其勘误不改。以下不是旧x场再次作用于厚mesh。

## 1. 原作者参考面与唯一待研究参数
用a表示脊宽系数，避免与原函数名h（屋顶升高H=2.5）混淆：

S_a(u,t) = (11.4*u*[a+(1-a)*abs(t)], 5.5+3*t, 6+2.5*(1-abs(t))^2+0.8*abs(u)^7*t^2)，u,t∈[-1,1]。

基线a0=0.74。只允许a改变，其他常数及所有相机/灯/非主屋盖物件固定。t=±1的作者参考边逐点不变，t=0参考脊半宽为11.4a。原build先生成这个零厚参考面再Solidify，因此不能无说明把S当原模型的中面并对称扩厚，否则a=a0也会改变原外皮位置。本次不选择a值、不扫描a范围，也不重新采用旧.55作为已批准模型。

## 2. 可以严格定义的檐管约束
完整前金檐、后金檐对象应直接保留原R05 mesh、世界矩阵、全部顶点/面/材质数据，不重算、不缩放、不旋转。这样可在浮点字节级核实其完整实体不动，不再以t=1中心线不动代替整管不动。

这只保证两条檐管本身。不自动保证新壳/瓦筋与它们接触、法向或交缝正确：S边固定但S_t和新曲面法向随a改变，壳的offset边可改变。原作者的瓦筋+0.06z、金线+0.12z也是世界竖向偏移，不是沿曲面法线的接触构造，不能假定原本处处无缝。

## 3. 不缩径的杆截面构造
45条瓦筋、1条直脊、2条侧缘，共48杆可在中心线层重建；两条完整檐管排除在此过程之外。

各杆的新中心线继续使用原离散参数站：瓦筋C_a,j=S_a(u_i,t_j)+(0,0,0.06)，侧缘C_a,j=S_a(±1,t_j)+(0,0,0.10)，脊杆C_a,j=S_a(u_j,0)+(0,0,0.12)。不可把表面高度与上述偏移同时偷偷改为另一个拟合自由度。

先从原已冻结杆网格按原中心线/拓扑识别截面环，验证平面性、中心、半径和端帽归属；不能仅猜顶点数组每8点就是一环。若无法可靠恢复环归属，先停止，不冒称保留旧截面。

对环j的每个原点p0_jk，定义
p_a,jk = C_a,j + Q_j*(p0_jk-C_0,j)，其中Q_j∈SO(3)。

Q_j只由原截面法线与新中心线切向的预先固定最小旋转规则确定，不由source像素自由调节。离散切向取相邻单位段的归一化和，端点取单边方向；零长段、反向和为零、法线反平行导致旋转不唯一等情形必须报失败，不临时加入roll拟合。截面间保持既有环连边，端帽随对应末端环同一刚体变换。

此公式保证每个已确认环内部任意点距严格保持，故原环的实际半径/非圆误差均不缩放；它不保证相邻环之间的面不扭转、自交或压短，也不保证杆与新壳接触。不能把“每截面刚性”称为整杆刚体或全管无自交。直脊缩短改变站距，这是明确设计变化，端帽形状不能跟着轴向缩扁。

## 4. 真正法向等厚只在正则光滑区域有条件保证
在t<0和t>0两片内，S_u×S_t的z分量=3*11.4*[a+(1-a)|t|]，a>0时非零，因此片内法向N_a可明确定义。若要保持原作者外皮S_a，理论中面可取M_a=S_a-0.06*N_a，内/外边为M_a±0.06*N_a；这在局部平行offset仍正则时给总0.12的法线对应间隔。若改成以S_a为中面，必须另记基线外皮改变，不能混称原位再生。

以上是片内解析条件，不是全局厚壳完成证明。还需offset距离小于局部曲率半径并小于整体reach，避免offset折叠、自交及两片/边界相撞。离散三角化之后必须检查法线测距与近邻面距离，不能只检查对应顶点长度0.12或相信Solidify参数。

关键障碍：原S含abs(t)，t=0脊线只有C0而非C1。左右S_t不同，脊线上不存在唯一几何法向。把两侧法向平均、再挤出0.12，只保证一个人为顶点偏移长度，不能称全壳沿真实法向等厚。原弯杆在离散脊折处也需要明确接头规则。

一种可研究的技术选择是两坡分别offset，再构造明确的miter接缝/脊底闭合；但接缝几何、唯一性、侧边收口、与固定檐管的连接仍需定义和验证，脊尖处“唯一法向厚度”本身没有定义。直接加连接条或靠金脊遮住缝隙不能当等厚证据。也不能为使法向唯一而悄悄圆滑屋脊，因为那会引入新的形状假说。

因此当前不能保证“从原方程直接重算即得到全域等厚、无缝、无自交且保留全部截面的成品”。可严格保证的只是固定檐管原样、被识别环的刚性映射，以及正则曲面片内的有条件offset构造。

## 5. 如未来获准，必须分开的基线控制与检查
先做a=a0的构造层控制，量化新算法与真实R05差异，区分算法重建误差与缩脊效应。若它已改变无授权区域或不能验证环/脊接头，停止；不能拿后续source变好掩盖基线不一致。旧Blender曲线离散/端帽修复与新刚体环框架不保证天然逐点相同。

后续a候选必须单独授权/预定义，仍只有一个形状参数，不同时改变高度、曲率、相机、光或云。需验证固定两檐管逐字节/逐顶点不变，截面点距/平面性/半径，杆间和杆壳接触，offset法向与最小距离、脊/侧缝、法线/闭合、自交/包含、邻物干涉，再做真实材白/GLB。上述均尚未执行。

## 6. 来源能检查和不能检查的事
11可见水平金杆外帽宽度与坡接位置支持缩脊方向的条件诊断，但圆管端与源装饰帽不同，必须分开；不能只报横向改善。原11高度差仍存在，单独缩脊不提供抬高依据，也不修左侧上挑轮廓。改杆框架可能改变极值像素，必须实际重投而非套用旧场数值。
10屋脊出画，没有对新脊宽的独立几何验证。两源粗下缘不可强认同一物理边：旧10包络见证来自后坡推断底，11来自前坡；包络落带不能代替first-hit可见性、材质可辨性和同边对应。右强光高尖、完整前金檐、背坡/深度、精确瓦筋身份仍null或未知。

保持旧全点/区段/回归，不把数学构造改进升级为native高清、来源标定、完整房间、源通过或用户验收。SOURCE仍FAILED。

## 结论
方法值得作为“构造层分解”的条件研究，但本轮不承诺完整几何可保证、不生成模型。固定完整檐管与截面刚性映射可以精确定义；全壳法向等厚在原折脊及边界接缝上尚未形成可验收保证，且source高度/多角身份缺口不变。若任务要求现在就保证所有这些条件，结论应为尚不能保证，而不是重复旧x场或直接重跑Solidify宣称成功。
