# 星瞳 × 明前奶绿《接住了》

[播放样片](caught.gif) · [逐帧图](frames.jpg) · [十张完整画面](frames/) · [112 px 连播截屏](playback-112.jpg)

星瞳伸右手等击掌，奶绿把一枝百合放在她手里。星瞳先看花，再抬眼看奶绿，停 510 毫秒，随后捧花谢幕。最后花降到画面下沿，两人从低头的姿势接回下一圈。

这是 Sunburst 完整姿势剪成的有限动画。原生第 3 到第 4 帧里，举掌和握梗的是星瞳身体两侧的手，因此重新画了张掌、递花、共同握梗和降低花枝四张姿势。最终第 4 帧两只手握住同一茎的上下两处，第 5 帧可看见奶绿已放开。为了让反应读得清楚，用单张画面的停留时长做节奏。所有画面统一裁去原始细框并铺白底；原生原件和编辑原图另外保留。

成片 768×768，10 个不同画面，2.80 秒，无限循环。每帧实测时长、道具／视线核对、图像哈希和实际提示词见[文件清单](manifest.json)。[浏览器回放](playback.json)使用独立无头 Chrome 页面按原速显示 112×112 的成片，由实际屏幕截图匹配已解码帧。缩小后，掌形、长梗百合和低头都能分辨；交接两手之间的细缝在逐帧大图里更清晰。
