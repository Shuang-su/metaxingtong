# 《接住了》的原始生成物

`duo-native.gif` 为首次 Sunburst 原生 GIF；同名 JSON 中有实际请求、帧时长和哈希。原生第 2、3 帧的举掌手与第 4 帧执花手的衣袖来自身体两侧。原件保留作对照。

以原生第 4 帧完整白底画面为附件，分别生成 `open-palm.png`、`offer.png`。以 offer 原件生成 `touch.png`，姿势正确但背景变深，再以 touch 为附件生成白底 `handoff-white.png`。另用原生第 8 帧生成 `lower.png`，补足花降出画面的动作。前三个接花姿势里，星瞳的右袖都从画面左侧横过胸前。奶绿始终用靠近画面中央的手递花。

每次编辑都是完整场景。原始中间图保留原尺寸，`touch.prompt.txt` 记录过渡稿提示词，其余提示词和成片帧号见[成片清单](../manifest.json)。
