# 三条无字幕表情的分镜

固定镜位，白底。以下是开拍前的意图；成片中实际画到哪一拍，见各片验收。停顿直接延长单幅画面的显示时间。

## 01　星瞳 × 明前奶绿《接住了》

| 拍 | 动作、眼神 | 百合与手的连续性 |
|---|---|---|
| 起 | 两人从低位起身；星瞳亮相后对奶绿张掌，期待击掌 | 掌心朝对方，另一手留在自己一侧 |
| 递 | 奶绿低眼确认那只手，认真递出一枝百合 | 手持花与头上的两朵发花分开，长梗指向星瞳 |
| 接 | 星瞳收指握梗，奶绿收回空手 | 两手在花梗的不同位置相遇，此处可以硬切到清楚的释放姿势 |
| 愣 | 星瞳先看花，再抬眼看奶绿；奶绿等她反应 | 花留在星瞳手里。这里留出最长的一拍 |
| 圆场 | 星瞳笑起来，把百合举到自己胸前，向观众谢幕；奶绿回礼 | 奶绿空手，花随星瞳的手落到画面下缘 |
| 复位 | 两人从低位接下一圈 | 花离开视野后再露出空手 |

## 02　星瞳《稳住了》

| 拍 | 完整姿势 | 剪影与帽子 |
|---|---|---|
| 亮相 | 红帽日常服，转身抬下巴，近侧肩略高 | 帽子还稳稳戴在头上 |
| 失手 | 帽向一侧滑落，先动眼睛，手还没有伸到 | 帽与发顶间出现白缝，画面中只有一顶帽 |
| 接住 | 身体向外探，手从帽沿下方接住 | 手托着帽，头顶空出，身体呈斜线 |
| 行礼 | 把接帽的手带到身前，弯腰把意外接成摘帽礼 | 帽仍在同一手，弯腰与接帽的剪影明显不同 |
| 复位 | 起身时把帽扣回头上 | 帽沿回到开场高度再停住 |

## 03　明前奶绿《给你的》

| 拍 | 完整姿势 | 花束与视线 |
|---|---|---|
| 起 | 花束遮脸，画面下方两只手拢包装纸 | 花束、纸和手构成一个能辨认的轮廓 |
| 包好 | 束住包装纸，眼睛从花纸上沿或侧边先露出来 | 双手沿同一束花移动；头饰跟头走 |
| 探头 | 歪头从纸后微笑，看向观众 | 手收在纸束下沿，脸和花分出空间 |
| 送出 | 两臂向观众伸，把「给你」落实到距离变化 | 花束逐渐遮住脸，保留同一花材与纸色 |
| 复位 | 定在包装与手的近景 | 用花束遮挡接开头的包装动作 |

验收看整圈及聊天尺寸。先辨动作意图，再看手数、视线、道具归属和首尾。若整张姿势画错，换完整画面，不对脸、手或花做变形插值。
