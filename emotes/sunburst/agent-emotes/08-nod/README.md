# 呆眼点头

[320 像素 GIF](chat.gif) · [768 像素 GIF](master.gif) · [逐帧图](frames.jpg) · [逐帧 PNG](frames/)

圆眼看向前方，随后下巴低到领口，再抬头回正。侧分短发与呆毛的回弹在白底上可辨。

成片共有 53 个不同画面，一圈 4.73 秒，无限循环。浏览器将大图缩到 112×112 原速播放，匹配到 6 个完整循环；截屏册展示连续三圈的主要姿势。[112 像素实播截屏](playback-112.jpg) · [回放数据](playback.json)

参考与制作。星瞳两条直接附真实 B 站《好欸好欸》《对对对》重画脸和九个姿势；奶绿两条沿用对应[原包版 GIF](../../original-pack-gifs/README.md)的九个原有姿势。 原画按整幅姿势切换，单格 512 像素，统一缩放后编码。

由真实 B 站《对对对》《好欸好欸》附图重新画九个主要姿势。使用全片统一的头肩裁切以清楚显示下巴和呆毛。

抽帧后剪去一次提前抬头的关键姿势，让下点、底部停顿、抬回只发生一轮。
