# 慢半拍

[320 像素 GIF](chat.gif) · [768 像素 GIF](master.gif) · [逐帧图](frames.jpg) · [逐帧 PNG](frames/)

星瞳先举手又放下，奶绿随后才敬礼；两人对视，星瞳再举手跟上，一起笑着放手。

成片共有 54 个不同画面，一圈 4.65 秒，无限循环。浏览器将大图缩到 112×112 原速播放，匹配到 5 个完整循环；截屏册展示连续三圈的主要姿势。[112 像素实播截屏](playback-112.jpg) · [回放数据](playback.json)

参考与制作。[敬礼二创](https://www.bilibili.com/video/BV1zCZ6BtEUM/)、[《夜蝶》双人 MV](https://www.bilibili.com/video/BV1dXSRBuEGv/) 和[噩梦安慰二创](https://www.bilibili.com/video/BV1igZJB8ERK/)提供情境。本轮重新编排姿势和节奏。 原画按整幅姿势切换，单格 512 像素，统一缩放后编码。
