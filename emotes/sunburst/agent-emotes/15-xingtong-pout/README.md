半垂蓝眼、双拳和鼓脸沿用奶绿的动作；银灰短发、紫发箍和浅紫外套取 B 站同套原图。两条逐帧时长一致，偏头方向与回正时机对应。

成片共有 54 个不同画面，一圈 4.56 秒，无限循环。浏览器将大图缩到 112×112 原速播放，匹配到 6 个完整循环；截屏册展示连续三圈的主要姿势。[112 像素实播截屏](playback-112.jpg) · [回放数据](playback.json)

参考与制作。星瞳取真实 B 站同套《揣手手》《老实》，对齐奶绿鼓脸的构图和每一帧时值。[视觉依据](../references/README.md) 原画按整幅姿势切换，单格 512 像素，统一缩放后编码。

逐帧沿用同批明前奶绿《鼓脸晃头》的 54 个曝光时值。星瞳形象取 B 站《揣手手》《老实》，九个动作的位置与奶绿原有姿势图相对照。
