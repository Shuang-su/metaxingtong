## 方法

在奶绿每一真实同帧上，以皮肤连通域提取两拳质心、拳峰高度，以首帧花饰颈肩区域匹配领口位移。测量与匹配分数逐帧保存在 `motion.json`。由两拳连线变化得到小幅旋转，领口位移得到平移，使用三帧三角滤波压低调色板阈值抖动。身体保持尺度 1，衣领、肩部、整只袖口和拳头使用同一个刚性变换。

星瞳头颈比例与奶绿不同，进一步用初版实际脸部最大皮肤连通域在移动颈中心处的下缘，把整块身体垂直配准到下巴，保留首帧约 4px 的皮肤重叠。该修正及最终矩阵均记录在 `motion.json`。复用仓库的原帧、`underlap.png`、`first-fists.png`、`restore_head()` 和既有跟踪，不重画眼睛或整张脸。底边使用 underlap 原有画布外像素，颈部位于后发之前，正常侧发仍在外侧。

## 可复现与云端恢复

从仓库根目录运行：

```bash
bash emotes/sunburst/agent-emotes/15-xingtong-pout/neck-follow/reproduce.sh
```

此脚本适用于装有 Python 3.12 的 GitHub Ubuntu runner：创建独立 venv、安装固定版本依赖、核验已提交输入、重建所有核心成品、重新验证并校验 SHA。无需私有密钥、图片 API 或未提交的本机素材。`generate.py` 的参数、遮罩多边形、测量算法与所有输入层都在 Git 中。浏览器播放为可选扩展，需要 Playwright、Chromium 及 Playwright FFmpeg；运行 `python playback.py` 可重新取得时序日志，日志与录像的墙钟时间不保证逐字节相同。

## 局限

这是 2D 局部图层合成，身体小幅旋转／平移，未模拟袖口独立形变和发丝物理运动。自动跟踪依赖本套素材的肤色与花饰，未声称适用于其它角色。GIF 新露出区域仍受 256 色量化影响。首帧精确保持及眼部相同的结论针对 768 成品；小尺寸版本经缩放和再次量化。
