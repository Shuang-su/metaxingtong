# 探头笑

[320 像素 GIF](chat.gif) · [768 像素 GIF](master.gif) · [逐帧图](frames.jpg) · [逐帧 PNG](frames/)

奶绿托着下巴从中间向两边探头；白手套随肩膀倾斜，珠饰和白蝴蝶结始终在原来一侧。

成片共有 52 个不同画面，一圈 4.70 秒，无限循环。浏览器将大图缩到 112×112 原速播放，匹配到 7 个完整循环；截屏册展示连续三圈的主要姿势。[112 像素实播截屏](playback-112.jpg) · [回放数据](playback.json)

参考与制作。星瞳两条直接附真实 B 站《好欸好欸》《对对对》重画脸和九个姿势；奶绿两条沿用对应[原包版 GIF](../../original-pack-gifs/README.md)的九个原有姿势。 原画按整幅姿势切换，单格 512 像素，统一缩放后编码。

为保持闭眼笑，重画中段的倾头姿势，并剪去回中时三张睁眼候选帧。
