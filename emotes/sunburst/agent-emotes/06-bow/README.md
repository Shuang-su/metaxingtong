# 扶正了

[320 像素 GIF](chat.gif) · [768 像素 GIF](master.gif) · [逐帧图](frames.jpg) · [逐帧 PNG](frames/)

白手套捏住画面右侧的条纹结尖，从垂直扶到水平；松手后结尖再次垂下来，奶绿停住斜看它。

成片共有 54 个不同画面，一圈 4.78 秒，无限循环。浏览器将大图缩到 112×112 原速播放，匹配到 4 个完整循环；截屏册展示连续三圈的主要姿势。[112 像素实播截屏](playback-112.jpg) · [回放数据](playback.json)

参考与制作。充电包简笔星瞳、白翼星瞳与白日战斗服 V3 奶绿分别使用对应[造型校样](../../pack-style-proofs/README.md)。 原画按整幅姿势切换，单格 512 像素，统一缩放后编码。

第一版的结尖在聊天尺寸下位移过小。第二版使用固定近景重画九个姿势，使条纹带从肩侧竖垂被扶到水平，再由重力垂回。
