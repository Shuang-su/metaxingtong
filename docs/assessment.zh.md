# 原壳配对同移方法：只读基线与精确定义

本轮没有缩脊模型、参数搜索或渲染。R05/R06b原件未改。

## 实际原件

原作者 build.py 构造65×33外表格网，应用默认 Solidify，thickness=.12。不是手写竖直挤出，也不是新曲面重算法向后的全局等厚壳。

真实R05主壳4290顶点可按2145对(i,i+2145)一一对应：2048外面均有反向内面；192条跨层边均连接同对，192封边四边形各包含两对。原脊是同一条外顶点行及其内配对行，未存在独立解析双坡offset接缝。

原配对向量 d_i=inner_i−outer_i 长度范围 .1199996253..1200003700；最大横向偏移 .1010494232，故不能称竖直挤出。对原离散网格顶点法向 n_i，max|d_i+.12n_i|=5.767e-7；归一化夹角最大 .000274902°。原折脊使用离散平均顶点法向，不等于两坡各自解析法向。原平滑片也不因此获得连续面最短距离保证。

使用同原外格网和默认Solidify（offset=-1,use_even_offset=false,use_quality_normals=false,use_rim=true,EXTRUDE）只在内存复建原基线，全部顶点差0；有向面循环集合完全一致，面顶点起始顺序并非逐字一致。不存在新候选模型保存。

## 可检验的单参数定义，尚未执行

a0=.74。外面参数 S_a(u,t) 沿用作者函数，仅x=11.4u[a+(1−a)|t|]变化。令 Δ_i=S_a(u_i,t_i)−S_a0(u_i,t_i)。

对真实原件两顶点一起平移：outer'_i=outer_i+Δ_i；inner'_i=inner_i+Δ_i。不分别以inner的实际y推t，不重算法向、不重新Solidify，不改任何面索引。

实数运算恒有 inner'_i−outer'_i=d_i，所以原配对向量方向、长度都保持；以原外面保留浮点残差而非直接S_a覆盖，a0时Δ=0。实际保存浮点需另测误差，不声称任意a逐字恒等。

t=±1的外面与对应内点Δ=0，因此壳的两檐端点对固定，包括内点本来不在同一y上的横偏。完整前/后金檐管则直接保留原对象数据，不触及截面。其余48杆沿此前已核环配对，每环绕原中心作旧→新同规则切向最小SO(3)旋转再中心平移；保持原微小截面偏斜，不执行绝对对齐。反平行/零切向必须显式拒绝，不能沿用遇小cross便一律I的简化分支。

## 能保证与不能保证

配对同移避免旧x场缩短/拉长厚度向量，保留已有脊封边连接，不需要新增折脊封口。因此上一轮双坡新法向offset接缝阻塞不适用于这个更弱且贴原件的定义。

但不同对的Δ不同，面边长度/夹角、面面积、相邻面法向及封边形状均可能变。管每环刚性不等于整杆刚性；环间连面可拉伸/扭曲。相邻配对向量之间夹角保持，配对向量与新面/新顶点法向的夹角通常改变。

如以后评估，需列原/新每面单位法向、每对向量对新内向顶点法向角 θ_i=acos((-d_i/|d_i|)·n'_i)、对应投影 |d_i·n'_i|；这仅局部投影，不是实际面间最短距离或全壳等厚。脊无唯一连续法向，应另列两邻面及离散顶点法向，不混称一种厚度。

拓扑索引保持只保证连接关系，不能保证几何不自交、无翻面、正体积、杆壳接触或全场无干涉。须对实际候选另核；本轮未构造任何a≠.74来冒称已通过。

来源约束仍限：11顶杆端宽可查，但y/坡接/左尖残差未消失；10脊出画不能独立验证缩脊。相机、灯、台、云、小檐均应固定。配对算法可精确定义不等于新屋盖可交付，也不等于source通过。
