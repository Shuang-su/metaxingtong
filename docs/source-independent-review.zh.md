# 2024-08-03 蝴蝶主舞台：有限来源预审

## 结论

可继续“02/05冷光展开状态的有限正面主台、可见四大蝶翼与中央塔骨架”研究，但不是完整城市或完整三维舞台的充分资料，不是来源验收通过。本轮只读原像素与旧归档，不建模、不渲染、不碰浏览器/登录，也不修改生产Git。

02是本组最适合作为主结构基准的近正面宽图；05补同类下翼、中央通道/栏状体和地面关系。01/03补局部，但应先逐项确认形态一致，不直接将它们当另外两个完整宽角。06留作同场家族、另一展示状态和低角证据，不能强行与02固定为同一几何同一材质只换灯色。POSE封面仅作官方身份桥与局部外观辅助，不算独立侧角。

## 实际所看像素及稳定线索

- 02：四块主翼围绕中轴连接，外上翼为长尖轮廓，上翼内有大块浅色瓣面与弯回的细脉；下翼外缘含尖钩、内下方有狭长垂瓣。中心银色/深色脉络密集汇合，后方竖向中塔带多圈螺旋/弧带，两条浅色长弯杆向上展开。底部是有限反光演出台、前缘浅色弧带、多枚黑色地灯；两侧低矮波状发光体、后方城市建筑与横向枝条状构件可见。
- 05：下翼的内侧垂瓣、尖三角孔/深色尖饰、浅色脉络边与02相容。中央浅色双S形栏状体、向两侧展开的低弧栏及若干竖向细条、其后反光通路清楚。不能仅凭外形给S形体指定楼梯扶手、人体通道净宽或承力功能。人物遮住中轴下部；字幕覆盖最下缘。
- 01：较近的群舞正面，主翼上部被裁，台前弧边更明显，雾与紫光强。下翼白色瓣、外尖钩和中轴汇合处与02同家族；但不能由相似性证明所有翼面处于完全相同展开参数。
- 03：近景只剩下翼局部、后方弯条与舞台地面，人物大面积遮挡。可补局部脉络/面材质表现，不提供全翼外轮廓、塔高或有效完整侧向基线。
- 06：低机位三人同框，中央塔的绕轴弧带、四主翼中轴汇合、两侧波状体、有限反光圆台与外侧枝状弧条构成同场强线索。翼面出现大片晶体状彩色岛与更明显细分脉网，内后方黄白细长瓣面显露，主翼轮廓/投影面积与02差别明显。低视角、透视、透明度/发光/表面动画、翼片转动或形变都可能参与；静态截图不能唯一分解，更不能断言只是灯变或已经证实机械形变。不得把06的晶体岛直接贴回02做“稳定固定几何”。
- POSE封面：中央人物、另外两人、蝶翼/金属脉络与舞台图案形成06的歌曲/演出桥。巨型文字、人物和裁切遮挡很重，画面倾斜可能是相机roll或封面处理，未证实另一侧观察方向，不能计为新增独立结构角。

稳定的是“蝶翼中轴汇合 + 中央绕轴塔带 + 下方有限演出台 + 两侧波状低体/横向枝条 + 远景城市”的组合，不是每张图所有边线和光斑位置。人物、飞散晶片/纸屑、亮星、雾、光束、反射花纹不自动作实体锚。

## 制作边界

建议冻结02为状态A，05作局部交叉约束；如01/03被使用，应逐部件核对后再列入，仍不能凑成三张合格宽角。可研究：
1. 可见演出台表面、前缘弧带和02/05能共同核对的中央通路/栏状构件。
2. 四主翼的可见正面外缘、主要金属脉络及内下方窄瓣，以可见遮挡顺序而非任意厚板解释层次。
3. 中塔在画面内可辨的竖向杆与螺旋弧带；塔顶被裁，不延伸编造完整塔冠。
4. 两侧有限波状体、枝状弧条和可辨地灯，注明仅局部轮廓，不猜完整安装系统。

不纳入已证范围：完整城市街区/建筑后侧、地平面与城市实距、四翼背面/准确厚度/完整连接、塔背面与完整圈数/节距/支座、台裙/台底/地下基础、全场边界、不可见坡道/台阶。城市可作明确标注的背景代理，但不能称“完整城市重建”。反光、半透明、发光材质使单张轮廓不能直接等同实体深度。

这一结论仅支持有界候选假说，不跳过原生截图、深度方法证据、共享几何多角对照/直接叠图和后续回放验证。现有图不足完成三独立有效结构角或全场高保真验收。
