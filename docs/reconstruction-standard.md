# 场景重建与归档标准

## 状态分开记录

所有场景当前均为**重建候选 / 待来源复核**。结构几何检查通过、模型格式可读取、已经发送审阅，均不代表来源忠实度通过或用户已验收。未声称每场都使用了登录后的高清截图和新增独立多角度；逐场覆盖审计另行记录。

## 空间与几何

- 室内应有有限且相接的墙、地、顶，保留墙厚、门窗真实洞口、进深、回边与接缝。
- 门扇、玻璃和洞口分开；可通行区域与物件落地、支撑、净空分别检查。
- 不把阴影、黑色纹理或透明效果误当实体结构。
- 阳台、花园、海滨、舞台等有意开放的场景保持开放；不为了闭合指标强行封口或编造整栋建筑。
- 来源观察到的结构与补齐的隐藏几何明确区分。推定范围有限，不冒充真实尺寸或唯一逆向解。

## 来源与一致性

- 记录来源 URL、片内真实秒数、截图日期及原生/解码/视口/裁切尺寸；高清播放截图不自动等于原生1080P原帧。
- 同轴缩放、同机位季节切换、重复画面、转场和混合画面不算新增独立深度基线。
- 所有来源角度共用同一套几何、材质和照明；不按相机隐藏墙、拉扯物件或局部扭曲叠图来制造一致。
- 保留来源图、模型图与直接50%叠图，并另列至少8个任意几何检查视角。剖切、俯视和中性补光要标为诊断图，不作来源证据。
- 未取得新高清或独立角度时，写明缺口，不能用重复正面图或内部检查相机补充“来源覆盖”。

## 验证

- 真实开口单独设允许域，再作密集射线、近接缝和实体厚度/法线检查。
- 导出 GLB 后实际重新导入，核对网格、世界几何、UV、贴图嵌入及材质；能打开不代表材质与主工程一致。
- 白模与材质模型几何一致；导出缺陷修订独立留档，不覆盖历史事实。
- 来源比例、物件数量、材质光照残差与几何完整性分别列为通过、失败或未验证。

## 历史、完整性与权限

- 从最早可核实快照开始，历史日期与本次归档commit日期分开；不回填提交时间，不伪造缺失文件或不存在的中间发布。
- Library版本为附件修订编号，不等于场景V编号；创建/修改时刻不自动等于聊天发送时刻。
- 每份实际二进制记录字节数、SHA256、Git blob SHA；ZIP做完整性检查，包内模型另外记录摘要。
- 连接器上传返回的Git blob SHA必须与本地完整字节按Git算法计算的SHA一致，再核对远端commit/tree的路径、SHA和大小。二进制读取接口的UTF-8限制会明确披露，不冒称完整远端二进制下载校验。
- 每场独立Issue、逐阶段评论与commit、Draft PR。缺失历史、来源覆盖不足和未验收项保持打开。
- 仓库保持私有。本轮不合并、不部署、不公开，不新增版权许可或授权声明。
