# 共享重建与归档标准

所有场景的总体状态均为重建候选 / 待来源复核。技术检查、字节完整性和几何可用性不能替代来源忠实度验收。

## 1. 空间与实体
室内应构成有限、可使用的空间；地板、墙、顶、边界有合理厚度和连续接界。门窗、拱洞、镂空栏杆必须是真实孔隙，具有洞口进深、侧壁、窗台、过梁和必要收口；不得以深色贴片冒充孔洞。合法开门、开窗、格梁间隙应保留。全屋可由多个连接的实体组成，无需强制焊成一个水密网格。装饰薄片应与建筑实体分开判断。
道具、家具、灯具、门扇和悬挂物应具有可解释的支撑、连接、尺度与间隙；检查悬浮、穿插、近接界缝隙、步行净空及开合运动范围。看不见的支撑或边界属于推定，应明确标注。
露台、花园、海滨与开放舞台应保持有意开放的空间类型；只补足声明范围内的有限结构，不凭空补成密闭房间、完整楼栋或未知相邻室内。

## 2. 来源与假设
分别记录直接可见事实、遮挡、不确定身份、工作比例、合理推定和仍未解决的残差。不得以对称性、常见建筑做法或阴影推断冒充原始工程证据；阴影不自动等于实体边。
每张来源图需记录视频URL、真实时间戳、解码分辨率、浏览器截图尺寸、视频区裁切范围、缩放与遮挡。区分原生解码帧、浏览器视口截图、旧裁图和新登录后高清播放截图。不得把视口放大称为原生高清。卡帧/时间戳不稳定的尝试不纳入有效来源。
不默认每个场景都使用了新登录后的高清来源或新增独立角度。每场应单独核实；未知就保持未知。同轴缩放、重复构图、同机位不同时间以及同一低相机族不能被计作独立平移基线。新增角度的来源有效性和新增几何约束需分别说明。

## 3. 共享状态与可复核视图
同一时段或明确声明的场景状态，应以同一组几何、物体变换、材质、灯光和环境解释全部来源机位。不得为逐机位对齐而偷偷移动道具、隐藏墙、改变照明或使用朝向相机的背景贴片。若原片确有动画/分时段变化，应独立声明全局状态和切换条件，并保留证据。
每个有效来源角度应保存来源、同机位模型渲染与直接50%叠图；允许明确记录的整幅等比缩放、裁切或补边，不用局部扭曲伪造一致。原尺寸图和比较图的对应关系应可追踪。
另提供普通水平广角、反向、侧向、任意角度和必要的外观检查。剖切、顶视、隐藏屋顶、ID图、诊断材质或射线图必须标为检查图，不能冒充默认完整模型或额外来源角度。

## 4. 几何与可移植性验证
除整体六向围护射线外，还需针对每个合法洞口进行穿透、边缘和遮挡探针，检查近表面与构件接界；记录样本范围、容差、合法出口和例外，而非仅给总通过数。检查实体闭合性、法线、非流形边、支撑接触、运动净空、UV与纹理依赖。
GLB应真实导出后重新导入，核对对象覆盖、三角数、双向顶点误差、面积、UV、法线、材质槽、节点变换、嵌入资源及白模/材质版同几何性。完整BLEND与GLB的材质、灯光和透明近似应明示；颜色导出修复与几何升级分开记录。
本次归档重新核验文件字节、SHA256、Git blob SHA1、ZIP CRC和包内模型哈希；沿用包内既有Blender/几何检查记录，不声称重新执行了那些建模检查。

## 5. 双轨验收与历史
来源忠实度：逐来源检查透视、轮廓、数量、遮挡、位置、材质及照明；稀疏锚点误差或全图RGB误差不代表全场几何精度。没有共同空间解、独立基线或足够来源时，保留待复核状态。
几何可用性：有限结构、真实洞口、厚度、连接、支撑、运动和跨格式完整性。技术项目可按所列证据分别通过或失败，但不得升级成总体来源验收通过。
历史只归档确有字节或明确文档证据的阶段。缺失模型阶段仅记证据与缺口，不重新建造过去模型、不伪造历史commit。Library条目创建/修改时间与视频时间戳、聊天发布时间、模型制作日期和新归档commit时间分列；未知时间为null。归档commit使用执行时实际日期。
原始交付包逐字节保留；即使包内旧说明含运行路径或早期判断，也不修改ZIP，而在新阶段说明中给出当前限定。仓库新说明仅使用仓库路径。相同独立文件字节仅保留一个规范路径，包内必要重复不拆改。
