# 直播3D场景重建：完整需求与交付门槛

确认日期：2026-10-10。按用户本次明确要求记录；适用于既有场景续作与后续新增场景。所有历史冻结版本保留，后续纠正另作新阶段。

## 1. 识别直播场景与有效内容

- 直播间是可运镜的3D空间。尽量完整检查每部相关回放，利用不同运镜理解同一场景的空间；记录实际检查的时间范围和未检部分，不以少数抽帧冒称完整看完。
- 跳过无实际空间信息的片头、CG、混剪等无关片段。评论中的数字可作为定位正片的线索，跳转后必须核验实际内容，评论本身不作空间结构证据。
- 同一视频可能有多个场景，也可能是一个大场景的不同部分。依据连续运镜、共享固定物、连接关系和布局分别识别；未证连通不强行拼接，多场景分开管理。
- 每场记录所属直播场次、可核实标题/日期、BV号与链接、片内时间和场景身份。日期或场景关系未知就明确写未知。

## 2. 登录后的高清来源与新增多角度

- 必须使用登录后的高清截图，并补回此前回放的高清参考；记录每张来源的实际片内时间、登录/画质证据、解码尺寸、截图尺寸、有效裁图范围。
- 后续视频中的新增多角度也必须用于确认，并先验证是否同一场景；记录搜索/检查过的回放及时间范围。没有找到有效新角度时记录已检范围与缺口，不能将“没找到”写成通过。
- 同一视频较晚时刻，不等同于“后续其他回放”；同轴缩放、同机位季节切换、重复构图、转场混合帧不计作独立空间基线。
- 1080P解码视口截图与原生1080P导出帧分别标注，不能混称。高清补采必须进入当前改模和最终叠图证据链，仅有文件不代表已经用于验证。

## 3. 空间理解、白模与纹理

- 先据真实多角度建立共享白模，再创建对应纹理贴图和材质，逐物件还原。
- 区分实体、孔洞、玻璃、材质明暗和光影制造的阴影，不能把阴影造型误建为实体，或拿黑色条纹替代真正镂空结构。
- 室内必须补为有限、完整、几何完备的房间：墙/地/顶相接，保留真实门窗开口、厚度、进深、回边、支撑、落地与通行净空。
- 原本开放的露台、花园、海滨、舞台等保持其开放性质；不要为“闭合”强行封口或扩成未知整栋建筑。
- 隐藏背面、未知相邻房间、尺度和支撑做法均明确标为推定，不能冒充来源观察或实测尺度。

## 4. 同机位对照并持续改进

- 将模型置于与每张参考图相同的相机角度，保留来源图、渲染图和直接50%叠图，对照实际差异后改进。
- 所有来源机位共用同一套几何、材质和照明状态；不得按镜头隐藏墙、变形物件、局部扭曲叠图来制造一致。
- 内部几何检查视角不能充作来源角度；另给至少8个任意方位检查图，剖切、俯视和诊断补光明确标注。
- 最终输出一张主视角图片供用户确认，连同可编辑材质模型、同几何白模、纹理/检查资料和跨软件导出；图片交付不等于用户接受。

## 5. 分开的验收门槛

- 几何：实体厚度、法线、接触与接缝、开口允许域、密集射线、通行与支撑，及真实GLB重新导入核验。
- 来源：登录后高清引用链、后续回放的同场新角度、共同空间解释、相机对齐、物件数量/遮挡/比例、材质与照明残差。
- 交付：模型/贴图/白模一致性、主视角图、清楚的未完成项和用户确认状态。
- 几何检查通过或文件可打开都不能代替来源还原通过。任何必需来源门槛未证实，状态保持“重建候选 / 待来源复核”；未收到用户验收，不写已接受。

## 6. GitHub逐场完整历史

- 私有仓库内每场独立Issue、阶段评论、真实commit与Draft PR，参照Metaflow的目标、范围、spec/plan/report、证据与限制记录方式。
- 从最早可核实版本的改动开始详细补录。保留真实旧包、版本变化、失败/撤回方案、来源链接与原始事件日期；缺失版本只记缺口，不伪造模型、旧发布或旧commit。
- 所有本次commit/Issue评论使用真实创建时间。Library附件版本与场景V编号分开，Library创建/修改时刻不自动等于聊天发送时刻。
- 冻结原包保持字节不变；每项记录大小、SHA256和Git blob SHA，ZIP做CRC检查，包内模型摘要单列。
- 已完成本地候选可先归档，但必须同步写明来源覆盖缺口。归档不授权合并、部署、公开仓库或授予版权许可。

## 7. 大文件保存与核验

当前GitHub连接的单次MCP请求体上限为16MiB，base64会放大数据。小文件原样保存；超限文件可按顺序分片保存全部原始字节，注明不是可直接打开的单包。

分片清单须保留原文件名、原大小/SHA256、原Library身份与版本、每片顺序/大小/SHA256。重组脚本不得默认覆盖同名文件，并必须本地验证重组后SHA256与ZIP CRC。读回远端commit/tree的路径、Git SHA与大小；如果二进制读取接口只支持UTF-8，明确这是内容寻址完整性核验，不冒称完整远端下载复核。
