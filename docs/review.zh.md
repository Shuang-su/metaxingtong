# 单椅一维下垂候选：拒绝，不改模型

源03/04左椅支持高背弯向较平前沿的连续吊布类别，不证明精确悬链线/受力曲率。实际读取伞final e54037d：C01布面是12条8顶点薄长方体，每条长轴直线，端中心z=.750/1.720。旧木架7杆不动。

试验仅内存，每条两端截面固定，厚度向量/宽/材质/位置/所有相机及另一椅固定，中间按原长轴参数t（0前、1上）垂直下移 a*t*(1-t)，单值a=.97。该值只为前端中轴切向水平作者假设，最大下移.2425，非像素实测。每条32段闭合实体，保留12独立条和原邻条.001重叠，不称焊合布。

结果拒绝：相同129×5×5=3225体积参数点对每木杆精确OBB内部判定，外侧00/11每条入背杆130→596，t区间[.875,1]→[.5078125,1]；入交叉B杆54→90，[.046875,.0859375]→[.078125,.1484375]。这是原穿插明显扩展，不能把它当新布安装。最初未等细分BVH面数日志保留，但不能拿面数增加直接证明穿插加重；最终baseline与候选同32细分，且实际分段线性网格体积采样复核。analytic-sampling.json是先前解析曲线采样，最大曲线/网格误差≤.000237；最终chair-curve-trial.json是实际分段网格采样，两者主计数同。

全场实际三角关系：除12条间外，只与原C01背杆/交叉B/前杆相交，没有新增旁物表面交叠。邻条11个相邻对既有交叠；非相邻条没有新增三角关系。三角无相交不排全包含，本轮全场其他物的完备包含未核；明确拒绝已由木架实际OBB包含反例成立。未进行像素优化、渲染或保存新模型；不扫更小a、不挪木框、不任意缩宽。这不证明所有弯布方案不可能。
