# 星瞳、明前奶绿与大肥鱼：先分清角色，再做能讲清一个梗的动图

上一版把「首帧像原画」当成了主要验收标准。这个标准漏掉了你最在意的部分：两只手拍合时有没有叠影，鱼竿抬起来时有没有被拉弯，以及看完一圈能不能明白角色在表达什么。**这轮从新内容和完整姿势开始。第一条做星瞳×奶绿「接住了」，随后依次做星瞳「稳住了」、奶绿「给你的」。**

## 首片与制作顺序

1. **双人《接住了》**。星瞳结束一个亮相动作，笑着摊掌等奶绿击掌；奶绿看了一眼那只手，认真放上一枝百合；星瞳看花、看她，愣半拍，顺势把花举到胸前谢幕；奶绿笑着回礼。两人鞠躬时花随手降出画面，从低位接回开场。**笑点放在星瞳接到花之后那一拍反应。** 首版无字幕，固定半身镜头。
2. **星瞳《稳住了》**。转身亮相，红帽滑落；视线先追帽子，手随后接住，最后拿帽行礼。三个姿势的身体剪影都要有区别。
3. **奶绿《给你的》**。先只看到一束花和两只忙着包装的手；奶绿从纸后探头，把花递向观众；花束靠近镜头遮住脸，自然接回开头。

首轮交付三位人物档案、来源索引、三条分镜和**第一条可播放样片**。首片优先试已经验证能运行的 Sunburst 768×768 原生 GIF。若原生结果出现双手重叠、五官漂移或花枝凭空换手，就重新生成对应的**完整姿势画面**，按分镜剪成有限动画，并注明制作方式。停顿用延长干净画面的播放时间完成，停用上一版的光流补帧、两张脸交叉淡化和局部网格拉伸。

**验收看整圈。** 每一帧都应看清两个人各有几只手、花在谁手里、两人的视线落在哪里。再缩到 96～128 像素，连续播放三圈：能看懂「等击掌 → 收到花 → 临场谢幕」，收尾接回开场也没有闪跳，才把它列为可用样片。交付时把 GIF 和逐帧图放在一起；首片通过后，再按顺序扩做后两条。

## 样片后的修订

用户要求提高帧率，同时延长每圈。三条故事各自保留上一版十个完整姿势作为对照；为交花、接帽、包花和复位绘制中间动作。动作段使用较短帧时，反应与礼毕留出停顿。检查每圈有效画面数、实际时长、平均每秒画面数以及 112 像素循环表现，将新版与旧版分别交付。
