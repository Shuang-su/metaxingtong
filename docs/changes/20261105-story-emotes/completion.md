## 核验

三片均 768×768、loop=0。Pillow 从最终文件逐帧复解，逐帧 RGB 像素与各自交付 PNG 一致；按清单校验每张 PNG 及 GIF 原件和成片的 SHA-256。FFprobe 独立读得相同的帧数、像素尺寸与总时长。原片、实际提示词、成片帧到原始画面的映射、视线和道具观察分别就近保存。

在独立 Chrome 页面以 112×112、原始速度播放最终文件。三份回放均匹配到四个完整循环，在其中连续三圈逐帧截屏核对遮挡、道具和收尾。重画保留了分拍的跳切，小尺寸下能看清动作，交接手指的细节以大图最清楚。本次复核范围为桌面浏览器与文件解码，具体聊天客户端压缩与使用者主观评价待实用反馈。
