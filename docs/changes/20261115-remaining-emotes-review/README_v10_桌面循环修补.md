## 修补方式与失败试验

使用原 GIF 第 49 帧的真实桌面像素。供体画面中被前景挡住的局部，用同帧、同一行无遮挡的桌面条带作横向缩放填补，形成可检查的独立桌面底板。当前帧的袖口、节拍器外壳与底脚轮廓覆于底板上；保留原有动作，没有复制整个人物或冻结摆针。

允许区域为原生 768 px 画面的 `[8,688,760,756)`；其中前景轮廓再保护 1 px，替换区域向内羽化 2 px。所有 `y < 688` 的像素受保护。底板、每帧允许遮罩、保护遮罩、alpha、局部 RGBA 层、参数和原件均保留。

`prototype-r0` 静态审核失败：把孤立桌沿误识别为前景，留下两处线条缺口。`prototype-r1` 要求保护轮廓连接到桌面上方的物体，修复缺口后才扩展至 5 帧。失败图与参数不删除。具体规则在 `repair_desk.py`；构建和校验脚本为 `build_v10.py`、`audit_v10.py`。无需 API 或付费依赖。
