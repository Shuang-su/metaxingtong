# 用 Agents API 并行续做 14 条表情

1. 先用《慢半拍》的真实分镜验证子代理。在领取赠额的 API 组织核对项目和可用余额，用现有 Key 创建一个 Agents API 会话，让它委派一名子代理完成敬礼动作分解。读回子代理标识、完成结果和用量，再把并发提高到最多三名。赠额耗尽后，平台可能继续使用已购余额，因此按可确认的赠额安排批次。[官方扣费顺序](https://developers.openai.com/api/docs/guides/chatgpt-api-credits#when-your-free-credits-run-out)
2. 按已选内容制作四批。绿瞳双人做《慢半拍》《夜蝶换位》《醒啦》；三套画风做《最后一枚》《星星别跑》《扶正了》；最初四张做《好欸拍手》《呆眼点头》《探头笑》《鼓脸晃头》加长版；再由星瞳和奶绿出演四条大肥鱼梗改编《还在数拍》《摸摸开工》《花太多了》《开饭撤场》。
3. 每名子代理跟完一条的分镜和关键姿势。本地程序用 Sunburst 出图、保存原件和编码 GIF，主代理复核手、道具与循环。全部任务共享最多三个在途出图请求，让一条审帧时，另一条可以继续画。
4. 沿用上一轮的交付标准。每条目标 4.3～5.2 秒、至少 46 个不同画面。以 112 像素原速核对连续三圈，交付 768 像素大图、320 像素分享版、逐帧图和实际提示词。四批分别做本地 checkpoint，结果汇总到既有 Issue #102。
