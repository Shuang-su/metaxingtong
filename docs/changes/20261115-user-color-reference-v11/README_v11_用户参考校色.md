## 颜色依据与处理

两图主体头发为暖灰褐／奶茶棕，绿色集中在刘海挑染、虹膜与叶饰。PNG 的虹膜上部为低饱和橄榄色、下缘为浅黄绿；第二份参考左眼更绿，右眼偏浅金黄。因此分别采样左右眼，未把整张图或整头头发染绿。

`reference-sampling.json` 保留所有采样框、RGB 中位数和 Lab 值。本轮对主体头发作柔和暖灰褐调整；挑染和左右虹膜分别向参考色靠近。挑染／虹膜目标按 PNG 75%、第二份参考 25% 混合；每只眼的 PNG 目标同时考虑深橄榄上部和浅色下缘。保留原有明暗结构，不把双眼统一成鲜绿。

头发在 Lab 中最多增加 10 L*，色度向 PNG 的暖灰褐采样靠近 65%；深色边缘逐渐减弱。为避免头发占据 GIF 调色板后吞掉小面积眼睛的绿色，头发只映射到整条动画各帧共有的原暖中性色，腾出的色槽单独用于挑染和虹膜。这使校色保持原像素保护，但颜色为接近参考的候选，并非严格逐色复制参考。

局部遮罩覆盖原有头发、挑染和虹膜。小型叶饰与服饰没有批量改绿，白羽饰、白花和奶白衣服保留；没有新增红颈带、文字或漂浮绿色符号。03 被左袖遮挡的深色发辫下部保留原色，避免把同色服装阴影当头发。02 第 17 帧完全遮挡时，对实际可见的头发岛单独限定区域。
