## 色彩规则与动态适配

从原包笑脸内部 3×3 像素区采得挑染 RGB `[205,209,157]`、虹膜 RGB `[205,209,180]`。这是图像采样值，不是官方色值标准。转换在 Lab 中保留原 L*，将 a*/b* 向参考的橄榄绿靠近，02 强度 0.65、03 强度 0.75，遮罩向内羽化 1.5 px。GIF 编码仅用剩余调色板位置量化遮罩内颜色，保留遮罩外原色。

- 02 识别已有浅橄榄色区域，并跟随实际挑染位置限定到奶绿头部中央。第 17 帧被完全遮挡，保持不变。没有透过星瞳补画奶绿颜色。
- 03 为正脸和偏转脸分别使用 F1、F17 作为位置参考。F34–F39 闭眼时不应用虹膜色彩；F40 已重新睁眼，已补齐该帧。最终 r2 与 r1 的 03 画面仅 F40 不同。
- 初次全帧尝试遗漏了 02 F38–F40 的部分区域，03 的斜脸模板也不适合后段正脸；这些版本已标为被修订版本。中间仅保留连通块的试验遗漏了细碎高光，亦未选用。原版、试样、遮罩、透明图层、参数和脚本全部保留。
