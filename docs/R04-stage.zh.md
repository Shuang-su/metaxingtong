# R04 密林工作域与杯花轮廓，全部来源未验收

611mesh；保持固定悬浮态，修改杯花为较宽曲面和波形瓣缘；增加远林、近树冠叶层、条向树皮噪声，有限地形工作域从半径16扩到32以修复R03明显截边。所有未证远林实例/边界/叶片为推断代理，不宣称完整植物计数。添加3047低角和3050高角条件相机。材白同几何，无按镜头隐物。

三个960预检实际看过：杯瓣比R02扁窄叶状有所改善，但仍不匹配原花形；树林枝叉过规律、地下植被/雾光密度不足，低角有前景叶遮挡与源不同。模型只是有界场景候选，不把多叶片数量当源质量。

独立3050像素复核至少11个可辨巨大花杯冠，现9株不足，2额外小疑点未确定；待邻帧身份复核，未凭颜色硬加全部疑点。九个初假设对应点进行固定几何/焦距50mm相机训练诊断，均值从111.06降51.81px，最大仍115.77px。对应身份及花中心定义不确定，±20px仅人工假设，不是统计置信区间；全部已见训练点，无盲测。三初始化同条件解并不证明唯一标定。结果保留qa/R04-camera-training.json，此阶段未修改保存模型的相机，不称源通过。
